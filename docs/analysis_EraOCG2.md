## 1. 개요

ERA OCG2는 유희왕 세계관의 ERA 스타일 조교 시뮬레이션.
Emuera 엔진 위에서 동작하며, ERB(로직) + CSV(데이터) 구조.

---

## 2. 조교 메인 루프

```
TRAIN_MAIN
  ├─→ 변수 리셋
  ├─→ 사전 이벤트
  └─→ 루프 반복:
       ├─→ 상태 표시 (SHOW_STATUS)
       ├─→ 행위 목록 표시 (SHOW_USERCOM)
       ├─→ 입력 받기 (INPUT)
       ├─→ 행위 실행 (USERCOM → COM{ID})
       ├─→ 쾌락 계산 (SOURCE_CHECK)
       ├─→ 사후 이벤트
       └─→ 반복 or 종료
```

## 3. 행위(커맨드) 시스템

### 번호 범위별 카테고리

| 범위 | 유형 | 조건 |
|------|------|------|
| 0~21 | 애무 (기본) | 필터 2+ |
| 40~99 | 도구 사용 | 필터 2+ |
| 100~189 | SM/고급 | 필터 2+ |
| 200~399 | 일상/대화 | 필터 1 (비성적) |
| 400~699 | 이동/특수 | 조건별 |

### 행위 실행 흐름

```
번호 입력 → COM_ABLE{번호}() 체크 → CAN_COM{번호}() 체크 → COM{번호}() 실행
               (기본 조건)          (추가 조건)           (효과 적용)
```

### 행위 예시: 키스 (COM20)

```
체력 -10, 기력 -50
혀사용자 특성 → 배율 1.5
긴혀 특성 → 배율 2.0
고양이혀 → 배율 0.75

→ 쾌C 계산, 쾌B 계산, 노출 계산
→ 키스 경험치 ++
→ 이성(GL/BL) 경험치 += 5
→ 더러움(STAIN) 교환
```

## 5. 쾌락 계산 공식

```
SOURCE_CALC_쾌C(대상, 실행자, 기본강도):

기초값 = 기본강도
  × 기교 스킬 보정 (최대 5배)
  × 최음제 보정 (2배)
  × 특성 보정 (음문 등)

욕정 보정:
  욕정 < Lv1: × 0.80
  욕정 < Lv4: × 1.40
  욕정 ≥ Lv4: × 1.60

감도 보정:
  × (2 + C감도) / 2

능력 보정:
  × C감각 수치 / 10

호감도 보정 (최대 3배):
  × (호감도 보정 + 100) / 100

이성 보정 (최대 1.5배):
  × (1000 - 이성) 보정

실행자 특성:
  자기애: × 1.20
  매혹: × 1.20

기력 패널티:
  기력 ≤ 0: ÷ 2

음란 보정:
  음란1: × 1.20
  음란2: × 1.50

→ 최종값을 쾌C에 가산
→ 부산물: 윤활 += 쾌C / 10
```

|------|------|

| 니플캡 | B 쾌락 |

## 10. 핵심 설계 원칙 (OCG2에서 배울 것)

1. **행위가 부위를 포함** — 부위 선택 따로 안 함
2. **다중 보정 누적** — 하나의 쾌락 값에 여러 배율이 곱해짐
3. **경험치 = 행위의 흔적** — 뭘 했는지가 수치로 남음
4. **특성이 계산을 바꿈** — 같은 행위여도 특성에 따라 결과가 다름
5. **장비 = 패시브 효과** — 장착하면 매 턴 자동 적용
6. **이벤트는 조건부 트리거** — 특정 상태 도달 시 자동 발생
