# B. 같은 카테고리 합성 — 추가 구상

## B-1. 트리거 해피 체인

```
[T1] 호전적(PT) + 자제심없음(PT 신규)
  → [T2] 난사광(CT): 매 라운드 AP 남으면 자동 추가공격(dmgMul 0.7)

[T1] 과감도(AT) + 과부하(CT) 또는 질풍(CT)
  → [T2] 자극무기(AT): 전투 공격 적중 시 대상 임의 부위 감도 +2

[T2] 난사광(CT) + 자극무기(AT)
  → [T4] 트리거 해피(CT/AT):
    - 공격 적중마다 대상 임의 부위 감도 +3 (전투→조교)
    - 대상 총 감도 합산의 일정 비율을 dmgMul에 가산 (조교→전투)
    - 양방향 루프: 때릴수록 감도↑, 감도↑ 수록 데미지↑
```

> 참고: 자극무기는 크로스 합성(AT+CT). 난사광은 PP 크로스 합성(PT+PT→CT).
> 트리거 해피는 T2+T2→T4 합성으로, T3을 건너뛰는 "점프 합성" 가능성. 혹은 중간에 T3 단계를 넣을 수도 있음.

## B-2. 추가 체인 후보 (미확정, 아이디어)

크로스 합성 티어다운에서 T1로 내린 26개가 같은 카테고리 합성의 새 재료가 될 수 있음:

**AT T1끼리 합성 예시:**
- 무조건봉사(AT T1) + 가학환류(AT T1) → ??(AT T2): 봉사하면서 쾌감을 얻고 상대의 고통에서도 쾌감. "양면봉사" 같은 트레이드오프 트레잇
- 점진침식(AT T1) + 관측자효과(AT T1) → ??(AT T2): 반복 감도 누적 + 미경험 감도 보정. "연구적 조교" 같은 효율 트레잇
- 동면조교(AT T1) + 인형조서(AT T1) → ??(AT T2): 무저항+반복 경감. "기계적 반복 조교" 빌드 초석

**CT T1끼리 합성 예시:**
- 심판관(CT T1) + 독무산포(CT T1) → ??(CT T2): 광 SPD디버프 + 광 area 지속. "광역 제압" 컨셉
- 꼬리기습(CT T1) + 사기꾼(CT T1) → ??(CT T2): 첫 라운드 AP+1 + 보상↑. "선빵 약탈자"

# F. 설계 결정 — 트레잇 티어

## 확정: 트레잇에 플레이어 표시용 티어 없음

트레잇 획득 경로가 선천/레벨업/합성뿐이고, 각 경로마다 이미 자체 게이트가 있음:
- **선천**: 유닛 풀이 게이트
- **레벨업**: 레벨이 게이트
- **합성**: 입력 재료가 게이트

트레잇 티어가 독자적으로 뭔가를 결정하는 순간이 없으므로, 플레이어에게 보여줄 필요 없음.
합성 몇 단계를 거쳤는지가 사실상의 "티어"이며 별도 라벨 불필요.

## 합성 내부 계산용 티어는 유지

합성 공식의 입력→출력 결정에만 사용. 플레이어에게 노출 안 함.

```
T2 = T1 + T1 (또는 육성 직접 — 두 경로 병존, 2026-07-17 재정정 v3)
T3 = T2 + T2 표준 (T1 혼합 허용 — 기존 체인 유지)
T4 = T3 + T2 표준 / **예외: T3 + T3 허용** (강대한 열매 소수 — 재료비 2배의 무게)
T5 = 합성 불가 — 순수 유닛의 것 (특수인·변용 종착·시그니처·상태 도달 전용) ★확정
```

> **2026-07-17 갱신 (레티어스)**: 비대칭식 채택 + T5 합성 배제 확정(원 의도 재확인 — T5=유닛 고유 결). **점프 합성 금지** — T2+T2→T4(트리거 해피 등)는 중간 T3 삽입으로 통일. 기존 A절 T4 레시피들(베이스 2 직행)도 중간 삽입 재배치 대상(synthesis_chains.csv 진행 중). 대정점(음↔양·원융·우화↔이형)의 T5 도달 문법 = 합성 아닌 상태/시그니처 결로 재설계(끝 로스터 잔여).

## 태그 겹침 → 부가 효과 (부흐/마하부흐식, 아이디어 단계)

트레잇 내부 태그(원소/시스템/작용)의 겹침은 티어가 아니라 합성 품질 보너스에 활용 가능.
겹침 많을수록 수치 강화 or 추가 효과. 미확정.

## 본 문서의 티어 표기에 대해

이 문서(C 섹션)의 T1~T4 표기는 **합성 내부 단계** 참고용.
게임 내에서 플레이어에게는 보이지 않음. 레시피 테이블의 Tier 컬럼은 합성 체인 설계용으로만 유효.
