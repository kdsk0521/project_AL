## 개요

이 게임의 조합/제작 시스템은 **4트랙**으로 구성된다.

| 트랙 | 방식 | 대상 | 상세 문서 |
|------|------|------|----------|
| 가공 | 원소 주입/해방에 의한 단일 재료 변환 | 원재료 → 조합용 소재 | 본 문서 |
| 일반 조합 | 특성 기반 자유 조합 | 소비재, 장비, 소재 | 본 문서 |
| 특수 레시피 | 고정 조합 (지정 재료 → 지정 결과) | 전설급, 스토리 아이템 | 본 문서 |
| 유닛 합체 | 인(印)×인(印) 15×15 테이블 (메가텐식) | 유닛 | system_unit_sigil.md |

본 문서는 **아이템 관련**(가공 + 일반 조합 + 특수 레시피)을 다룬다.

## 설계 원칙

> **"같은 재료라도 뭐랑 엮느냐에 따라 다른 결과가 나온다."**

- 고정 레시피 암기가 아닌, 재료 특성 조합에 의한 **판단**이 핵심
- 같은 재료여도 현재 영혼력, 유닛 상태, 도시 요청에 따라 최적 선택이 달라짐
- 조합 결과물에 파편 로어 텍스트를 부착하여 내러티브 레이어와 연결

> **"재료 수는 적게, 가공으로 깊이를 만든다."**

- 재료 종류가 많으면 "레시피 암기 게임", 적으면서 가공이 풍부하면 "판단의 게임"
- 플레이어가 전체 재료를 파악하고 있다는 느낌을 유지할 수 있는 범위
- 총 원재료 **12~16종**, 확장 포함 20종 이내

> **"억압이 있어서 자유가 있다. 자유도는 단계적으로 열린다."**

- **설비 추가 = 새로운 원소 가공 해금** → 진행 상태가 자유도의 범위를 결정
- 초기: 가마(열) + 분쇄기(위) 2종 → 후기: 6종 원소 가공 전부 개방 (자(磁)는 자성환 도입 시점 = **T2.5**, v4.5 정정)
- 초보자는 제한된 범위에서 시스템을 익히고, 숙련자는 넓어진 범위에서 깊이를 누림

## 태그 체계 (확정)

모든 재료와 결과물은 **태그**로 정의된다. 태그는 3축 4분류.

### 기능 태그 — 효과 (10종)

결과물이 "뭘 하느냐"를 결정하는 태그.

| 구분 | 태그 | 방향 |
|------|------|------|
| 소비 | 회복 | 물약, 음식 (기존 회복/강화회복/영양 통합. 등급 차이는 tier/가공이 담당) |
| 소비 | 독성 | 독, 피해 아이템 |
| 소비 | 억제 | 봉인, 디버프 |
| 소비 | 분산 | 범위 효과 |
| 물리 | 공격 | 무기 계열 |
| 물리 | 수호 | 방어구 계열 |
| 기술 | 조련 | 육성/조교 도구 |
| 마법 | 부여 | 마법 장비, 장신구, 버프 |
| 변환 | 촉매 | 물리/화학적 변환, 가공 보조 |
| 변환 | 마력촉매 | 마법적 변환. 촉매의 마력 승격판 |

### 기능 태그 — 재료성질 (4종)

소재로서의 물성을 나타내는 태그.

| 태그 | 역할 |
|------|------|
| 경도 | 단단한 계열. 장비/건축 방향 |
| 가공성 | 가공 용이한 소재. 중간 소재/다용도/범용 베이스 |
| 전도 | 마력 전달. 마법 장비/도구 방향 |
| 보존 | 내구/유지. 보존 식량, 방어구 |

### 원소 태그 (6종)

마력의 에너지적 성질. **물리학의 에너지 유형을 마력으로 재해석**. 4원소는 물리, 식·자는 신비 영역.

| 태그 | 에너지 기반 | 마력적 해석 |
|------|-----------|-----------|
| **열** | 열에너지 | 에너지가 변환되는 마력. 뜨거워지기도 차가워지기도 |
| **위** | 위치에너지 | 에너지가 축적된 마력. 눌려있다가 해방되는 |
| **광** | 빛에너지 (방출 전반) | 에너지가 방출/전달되는 마력. "방출" 전체 (단순 빛 아님) |
| **동** | 운동에너지 | 에너지가 흐르고 이동하는 마력 |
| **식** | 화학 (산화·환원) + 비현실 | 인간 지각 너머의 화학. 물질의 본질 자체가 변질되는 성질 |
| **자(磁)** | 자기 + 자전 + 관계·매혹 | 자기력(인력·척력)과 자전 + 어휘 차원의 이끌림·매혹·관계 |

#### 제5원소 "식"의 특수성

- 4원소는 에너지의 형태. 식은 **화학(산화·환원) + 비현실** — 학자가 분류 못 하는 영역의 화학
- 세계관 연결:
  - 심층에서 현실 법칙이 흐려지는 것 = 식의 작용
  - 차원 경계가 침식됨 → 방문자가 넘어오는 현상
  - 고대 문명이 심층에서 발견한/만난 것과 연결 (레이어 3 로어)
- 게임 내 운용:
  - Tier 1~2 재료에는 식 태그 거의 없음 (**예외: 약초** — 초반 복선)
  - 심층으로 갈수록 식 태그 재료 출현
  - 식 태그 재료 = 자동으로 "위험하고 특별한 것"

#### 제6원소 "자(磁)"의 특수성 (2026-05-19 신규)

- 자(磁) = **자기력**(인력·척력) + **자전** + **관계·매혹·이끌림** (어휘 차원)
- 식과 짝을 이루는 **신비 축의 두 번째 원소**. 식이 "물질 변질"이라면 자(磁)는 "끌림·회전"
- **시스템 변수 격상 X — 어휘·로어 베이스로만 운용**
  - 자(磁) 어휘 트레잇은 여러 풀에 자유 발현: 전투(자기 공격·번개) / 성격(매혹 디버프) / 성인(이끌림·호감도)
  - 합체·호감도 시스템에 자(磁) 직속 시스템 변수 격상 거부
  - 인 시스템 자체 큰 변경 없음 (12 정인 + 3 특수인 + 합체 테이블 그대로). 정인의 자(磁) 결은 도감·로어 흔적 정도
- 가공 시스템 운용:
  - 자(磁) 주입 = 가마(자-와 짝). 자(磁) 해방 = 자성환(자+와 짝)
  - 자성환의 가공 결과물 = **호감도 도구** (어휘 차원의 연결)
- 재료 분포: Tier 1 재료에 자(磁) 원소 추가 (철광석에 자(磁) 부여 권장, 또는 새 Tier 1 재료 도입 검토 — 미정)

재료 수는 적게, 가공으로 깊이를 만드는 설계.

| 구간 | 층 | Tier | 원재료 |
|------|-----|------|--------|
| 초급 | 1~5층 | 1 | **7종** (기초 재료. 태그 3축을 고루 커버) |
| 중급 | 6~15층 | 2 | 기존 재료 수급량 증가 + **신규 3~4종** |

| 심층 | 31층~ | 4+ | **신규 1~2종** (심층 전용) |

- 총 원재료 **12~16종**, 확장 포함 20종 이내
- 층이 깊어져도 기존 재료가 계속 나옴 (수급량 증가)
- 신규 재료는 새 원소 태그나 기능 태그를 여는 역할에 한정
- **채집 포인트 ≠ 형태 고정**: 수풀에서도 유기가, 수계에서도 유기가 나올 수 있음

#### 광- 후반화 문제 해결 (v4.5)

자성환이 T2.5라 광 해방을 위해 T2.5까지 가야 하는 부담 해소를 위해:
- **가마(자-)**: 독물고기 자 제거 → **식용화 가능 T1** (자기적 매혹 해소 = 독 무력화 = 식용화 정합)

- 광 해방 효과 자체는 자성환 도달 후에만 본격, 단 가마(자-)로 T1부터 자 원소 활용 가능

## 트랙 1: 가공 (원소 주입 체계)

### 핵심 구조: 가공 = 원소 주입/해방

가공은 단순한 물리 작업이 아니라 **재료에 특정 원소의 마력을 주입/해방하여 성질을 바꾸는 연금술 기술**.

각 가공 설비는 특정 원소에 대응하며, **설비 추가 = 새로운 원소를 다룰 수 있게 되는 것**.

### 가공 설비와 원소 대응 (쌍원소 구조) — 6설비 v4.5

모든 설비는 **주입 원소 + 해방 원소** 두 가지를 동시에 처리한다. 마스터 6설비 매핑 (Tier 순서 닫힘):

```
Tier 1:    가마 (열+ + 자-) + 분쇄기 (위- + 식-, 해체형)
Tier 1.5:  압축기 (위+ + 동-) — 동력 기관 제작으로 개방 (로어 힌트)
Tier 2:    증류기 (열- + 광+)
Tier 2.5:  자성환 (광- + 자+) — 호감도 도구 제작 설비. **중반 도달** (v4.5 정정)
Tier 3:    환류기 (동+ + 식+) — 연금술 펠리칸(Pelican) 차용, 자기 순환. **최후 설비**
```

- 6원소를 6설비가 1:1 슬롯으로 전부 커버 (각 원소 ±씩 12 슬롯)
- **자성환 = T2.5** (v4.5 정정): 자(磁) = 관계·매혹 어휘로 ERA 호감도 시스템과 직결 → 자성환이 너무 늦으면 호감도 도구 후반화 → 게임 진행 부담. T2.5로 앞당겨 영혼력 유지비 흐름과 자연
- **환류기 = T3 최후**: 식 = 비현실 변환의 가장 위험·고급 기술. 고대 문명이 이걸 다루다가 멸망했을 가능성 (레이어 3 로어)

### 가공 원칙 (확정 v4.4)

모든 설비는 **두 가지 원소 효과**를 동시에 발생시킨다 (쌍원소 가공). 단 분쇄기는 두 해방 결합인 **해체형**.

- **주입 효과** → **기능 태그를 변환** (설비의 주된 가공 효과)
- **해방 효과** → **형태 태그를 변환** + 재료에 해당 원소가 있으면 **원소 태그 제거**

| 설비 | 물리적 행위 | 슬롯 (주입+ / 해방-) | 결합 공정 | Tier |
|------|-----------|--------------------|----------|------|
| 가마 | 굽는다 | 열+ (주입) + 자- (해방) | 하소 + 증식 | 1 |
| 분쇄기 | 부순다 | 위- (해방) + 식- (해방) — **해체형** | 분리 + 용해 | 1 |
| 압축기 | 누른다 | 위+ (주입) + 동- (해방) | 응고 + 고착 | 1.5 |
| 증류기 | 끓여 갈라낸다 | 열- (해방) + 광+ (주입) | 증류 + 승화 | 2 |
| **자성환** | 끌어당겨 가공한다 | 광- (해방) + 자+ (주입) | 소화 + 투사 | **2.5** |
| 환류기 | 자기 순환시킨다 | 동+ (주입) + 식+ (주입) | 연화 + 발효 | 3 |

- **가마**: 열을 넣어 성질을 바꿈 → 부산물로 끌림(자)이 빠져나감
- **분쇄기**: 축적(위)을 풀어 부숨 → 구조가 깨지며 기이함(식)도 빠짐. **두 해방의 결합 = "해체형"** ("비대칭" 표현 폐기)
- **압축기**: 위치에너지(위)를 주입해 눌러 담음 → 운동(동)이 멈춤
- **증류기**: 열을 빼며 빛을 주입 → 휘발·승화 방향
- **환류기**: 동+식 두 주입으로 자기 순환 (펠리칸 환류). 정제·발효 진행
- **자성환**: 빛을 빼며 자(磁)를 주입 → 끌림·매혹 응축. 가공 결과물 = **호감도 도구**

### 12공정 1:1 매핑 (어휘 차원) ★ 신규

12공정은 **어휘**(UI는 직관, 도감·로어는 공정명). 시스템 변수는 아니며, 6원소 × 주입/해방 12 슬롯에 1:1 대응한다. 흔적 매핑(다공정-다슬롯) 없음.

| 슬롯 | 공정명 | UI 표면 어휘 |
|------|--------|-------------|
| 열+ | 하소 (calcination) | 굽기 |
| 열- | 증류 (distillation) | 끓여 모으기 |
| 위+ | 응고 (coagulation) | 굳히기 |
| 위- | 분리 (separation) | 부수기·갈기 |
| 광+ | 승화 (sublimation) | 모아 올리기 |
| 광- | 소화 (digestion) | 빛 빼기 |
| 동+ | 연화 (ceration) | 누그러뜨리기 |
| 동- | 고착 (fixation) | 멈추기 |
| 식+ | 발효 (fermentation) | 삭히기 |
| 식- | 용해 (dissolution) | 녹이기 |
| 자+ | 투사 (projection) | 끌어 모으기 |

- UI 표면 = 직관 어휘 ("굽기", "분쇄") / 도감·로어 = 공정명 ("하소", "분리")
- 12공정 = 어휘 단위. 시스템 작동은 6원소 축 그대로

#### 설계 포인트

- **가마(열 주입)**: 7종 → 7종의 다른 기능 태그. 겹침 없음
- **분쇄(위 해방)**: 형태가 전부 분말. "부수면 가루" 한 문장으로 이해. **두 해방 결합 = 해체형**
- **압축(위 주입)**: 형태가 전부 결정. "누르면 굳는다" 한 문장으로 이해
- **쌍원소 가공**: 해방 원소와 일치하는 원소 태그가 재료에 있으면 제거됨
  - 가마(자 해방): 재료에 자(磁) 태그가 있으면 자(磁) 제거 = 끌림이 부서져 발산 (v4.4 갱신)
  - 자성환(광 해방): 독물고기(광) → 광 제거 = 빛(마력 방출)이 빠져나가 해독 (구 가마 광해방 효과 이전)
  - 분쇄(식 해방): 약초(식) → 식 제거 = 기이한 성질이 부서져 소멸
  - 압축(동 해방): 슬라임핵(동) → 동 제거 = 진동이 멈추며 에너지가 루프화
- **열+열 반응**: 마력석(열)에 가마(열 주입) → 촉매가 마력촉매로 승격
- **위+위 반응**: 철광석(위)에 분쇄(위 해방) → 축적된 것을 해방
- **원소가 없는 재료**: 촉매초(—), 물(—)은 해방 효과 해당 없음 → 기능/형태만 변환

| 물 | ✓ | ✗ (액체는 분쇄 불가) | ✓ |
| 슬라임핵 | ✓ | ✓ | ✓ |

### 가공 체인: 상한 없음 (자연 순환 자기 제한)

```
철광석 → [분쇄] → 철가루 → [가마] → 철 → [분쇄] → 철가루 → ...
```

- 가공만 반복하면 태그가 순환하여 새로운 결과가 안 나옴 → 플레이어가 알아서 멈춤
- 인위적 상한 불필요. 시스템이 자연스럽게 무한 이득 루트를 차단
- **진짜 의미 있는 체인**: 가공 사이에 조합을 끼워넣을 때 발생
  - 예: 철광석 → [분쇄] → 철가루 → [조합: +마력석] → 선철 → [가마] → 강철

### 가공의 역할 (요약)

- **기능 태그 변환**: 가마로 같은 재료를 다른 용도의 소재로 전환
- **형태 변환**: 분쇄로 고체를 분말로 → 조합 시 다른 반응
- **등급 상승**: 가공 체인(가공→조합→가공)을 거치며 tier 상승 가능
- **조합 공간 확장**: 재료 7종 × 가공 2종 = 사실상 소재 14종+의 효과
- **설비 연결**: 설비 업그레이드가 가공 가능 범위를 확장 → 경영 시스템과 연결

### 가공과 다른 시스템의 연결

```
[탐사] → 원재료 획득
  ↓
[가공] → 기능 태그 변환 / 형태 변환 (설비 필요 → 경영)
  ↓
[조합] → 변환된 태그 기반으로 결과물 결정
  ↓
[경영] → 도시 투자 / 설비 업그레이드 → 새로운 가공 경로 개방
```

## 트랙 2: 일반 조합 (특성 기반)

### 핵심 구조

재료에 **특성 태그**가 붙어 있고, 조합 시 태그 조합이 결과물의 **카테고리**와 **효과**를 결정한다.

```
재료 A (회복, 식, 식물) + 재료 B (가공성, 액체)
  → 태그 조합 판정: 회복 + 가공성
  → 결과: 기초 회복 물약

재료 A (회복, 식, 식물) + 재료 C (경도, 위, 광물)
  → 태그 조합 판정: 회복 + 경도
  → 결과: 회복 효과가 있는 장비? 또는 미지의 결과물
```

같은 약초라도 상대 재료에 따라 완전히 다른 결과물이 나온다.

### 결과물 결정 로직: 태그 합산 방식

> **"결과물은 매트릭스가 아니라 태그들의 합산으로 결정된다."**
> **"각 태그가 결과물에 자기 성질을 기여하고, 전체가 합쳐져서 결과물의 정체가 된다."**

레이어 분리(기능→원소→형태)가 아닌, **4축 전체가 동시에** 결과물을 정의한다.

- **기능(효과)** → "이 물건이 뭘 하는가" (목적)
- **기능(재료성질)** → "이 물건이 물리적으로 어떤가" (물성)
- **원소** → "어떤 에너지/방식으로 작동하는가" (작동 원리)
- **형태** → "물리적으로 뭔 모양인가" (형상)

```
예시: 조련(기능) + 전도(재료성질) + 동(원소) + 유기(형태)
 → 길들이는 + 에너지가 흐르는 + 진동하는 + 살아있는 느낌의 물건
 → 플레이어 네이밍: "전동딜도" (특수 레시피가 아니므로 플레이어가 이름을 붙임)

예시: 회복(기능) + 가공성(재료성질) + 식(원소) + 액체(형태)
 → 되돌리는 + 다루기 쉬운 + 본질변환 방식의 + 마실 수 있는 물건
 → "기초 회복 물약" (기초 레시피에 매칭되면 고정 이름)
```

### 태그별 효과 사전

각 태그가 결과물에 기여하는 성질. 이것이 조합 시스템의 기초 단위.

#### 기능 — 효과 태그 (10종): "뭘 하는 물건인가"

| 태그 | 결과물에 기여하는 성질 |
|------|---------------------|
| 회복 | 되돌린다, 채운다 |
| 독성 | 해친다, 침투한다 |
| 억제 | 막는다, 봉한다 |
| 분산 | 퍼뜨린다, 넓힌다 |
| 공격 | 부순다, 깨뜨린다 |
| 수호 | 지킨다, 버틴다 |
| 조련 | 길들인다, 변화시킨다 |
| 부여 | 덧붙인다, 올린다 |
| 촉매 | 변환한다 (거시/물리적) |
| 마력촉매 | 변환한다 (미시/화학적) |

- 촉매와 마력촉매는 상하 관계가 아니라 **같은 "변환" 축의 거시/미시 버전**
  - 촉매: 물리적 변환 — 형태를 재구성. 합치거나, 깨뜨리거나
  - 마력촉매: 화학적 변환 — 성질을 바꿈. 조성이 달라지거나, 반응하거나

#### 기능 — 재료성질 태그 (4종): "물리적으로 어떤 물건인가"

| 태그 | 결과물에 기여하는 성질 |
|------|---------------------|
| 경도 | 단단하다, 견고하다 |
| 가공성 | 다루기 쉽다, 섞이기 쉽다 |
| 전도 | 에너지/마력이 흐른다 |
| 보존 | 오래간다, 유지된다 |

- 효과 태그 = 목적을 준다 (이게 있으면 "쓸 수 있는 물건")
- 재료성질 태그 = 물성을 준다 (효과와 합쳐지면 완성품, 단독이면 소재/중간재)

#### 원소 태그 (6종): "어떤 방식으로 작동하는가"

> 물리학의 에너지 유형을 마력으로 재해석. 4원소는 물리, 식·자(磁)는 신비 축.
> 6원소 모두 같은 레벨 — 식·자가 특별히 상위이거나 분리되지 않음. 단 신비 축은 "학자가 분류 못 하는 영역"이라 어거지 매핑 허용.

| 태그 | 물리학/신비 기반 | 결과물에서의 의미 |
|------|-----------|----------------|
| 열 | 열에너지 | 온도, 에너지 변환. 뜨겁거나 차갑거나, 상태가 바뀌는 |
| 위 | 위치에너지 | 압축, 해방, 축적. 눌리거나 터지거나, 무거운 |
| 광 | 빛에너지·방출 전반 (전자 방출/흡수) | 방출, 흡수. 빛나거나 어둡거나, 보이거나 안 보이는 (단순 빛 아닌 방출 전체) |
| 동 | 운동에너지 | 운동, 진동, 흐름. 움직이거나 흔들리거나 흐르는 |
| 식 | 화학(산화·환원) + 비현실 | 본질 변환. 인간 지각 너머의 화학. "상처를 상처가 아니게" |
| 자(磁) | 자기(인력·척력) + 자전 + 관계·매혹 | 끌림·회전·이끌림. 매혹하거나 밀어내거나, 회전하는 — 어휘 차원에서 호감도·매혹 연결 |

#### 형태 태그 (7종+): "물리적으로 뭔 모양인가"

| 태그 | 결과물에서의 의미 |
|------|----------------|
| 식물 | 유연한 것. 천, 섬유, 줄기, 잎 포함 |
| 광물 | 단단한 것. 장비류의 물리적 기반 |
| 액체 | 마시거나 뿌리는 것 |
| 유기 | 살아있는 것. 생물성 |
| 기체 | 퍼지는 것 |
| 분말 | 가루 |
| 결정 | 압축/응축된 것 |

### 조합 해석 규칙

#### 기본 원칙: 태그 합산

> **"재료를 넣으면 모든 태그가 합쳐진다. 합쳐진 태그 전체가 결과물의 정체."**

```
재료 A의 태그 전부 + 재료 B의 태그 전부 → 결과물의 태그 세트
```

- 각 태그가 독립적으로 효과를 기여
- 태그가 합쳐지면 **복합 동사**가 됨 ("되돌린다 + 부순다" = "부수고 되돌린다")
- 태그가 많을수록 복잡한 물건 (제작 난이도가 자연적 상한)
- 이름은 **플레이어가 붙인다** (특수 레시피만 고정 이름)
- **태그 중복은 세트 병합**: 같은 태그가 겹치면 1개로 합침 (수량/가중치 없음)
- **중복의 보상은 tier**: 중복 태그 수에 비례하여 결과물 tier 보정 ↑ (구체 수치는 밸런싱 시 확정)
  - 같은 성질의 재료를 겹쳐서 "순도를 높인다" 개념

#### 결과물 결정 흐름

```
1. 재료 A의 태그 + 재료 B의 태그 → 태그 조합 세트 생성
2. [특수 레시피 테이블 우선 확인] → 매칭되면 고유 아이템 생성 (고정 이름)
3. [일반 조합] 태그 합산 → 결과물의 정체를 태그 세트가 결정
   - 효과 태그 → 이 물건이 뭘 하는가
   - 재료성질 태그 → 물리적으로 어떤가
   - 원소 태그 → 어떤 방식으로 작동하는가
   - 형태 태그 → 물리적 형상
4. [모순 쌍 판정] → 태그 세트 내 활성 모순 쌍 수 카운트
   - 0~4쌍 → 해석 가능. 결과물 생성, 플레이어 네이밍
   - 5쌍 이상 → 해석 불가. 미지의 결과물 (태그 유지, 재가공/재조합 가능)
5. 재료 tier 평균으로 등급/수치 결정
```

#### 모순 쌍 판정 시스템 (해석 가능/불가능)

> **"태그 하나하나는 다 의미가 있다. 하지만 대립하는 태그가 너무 많이 공존하면, 하나의 물건으로 수렴하지 않는다."**

모순 쌍: 대립 관계에 있는 태그 2개가 동일 결과물에 동시에 존재하는 경우.

**모순 쌍 테이블 (총 12쌍)** — v4.5 정정: 식·자 둘 다 홀로 (모순 불참). 식↔자 잠정 쌍 폐기

| 축 | 쌍 | 대립 논리 |
|----|-----|----------|
| 효과 | 회복 ↔ 공격 | 되돌린다 ↔ 부순다 |
| 효과 | 독성 ↔ 수호 | 해친다 ↔ 지킨다 |
| 효과 | 억제 ↔ 분산 | 막는다 ↔ 퍼뜨린다 |
| 효과 | 조련 ↔ 부여 | 길들인다 ↔ 덧붙인다 |
| 효과 | 촉매 ↔ 마력촉매 | 거시변환 ↔ 미시변환 |
| 재료성질 | 경도 ↔ 가공성 | 단단 ↔ 다루기쉬운 |
| 재료성질 | 전도 ↔ 보존 | 흐른다 ↔ 유지된다 |
| 원소 | 열 ↔ 광 | 에너지변환 ↔ 에너지방출 |
| 원소 | 위 ↔ 동 | 축적/해방 ↔ 흐름/이동 |
| 형태 | 기체 ↔ 결정 | 퍼지는 ↔ 압축된 |
| 형태 | 액체 ↔ 분말 | 흐르는 ↔ 부서진 고체 |
| 형태 | 식물 ↔ 광물 | 유연한 ↔ 단단한 |

**모순 판정에 안 잡히는 태그 (홀로 서는 태그)**
- **식** (원소): 비현실 에너지. 대립할 상대가 없음 — 오히려 "말이 안 되는 걸 말이 되게" 하는 쪽
- **유기** (형태): 살아있는 것. 뭐든 될 수 있음

**판정 기준**
- 활성 모순 쌍 **0~4개**: 해석 가능 → 복합 동사로 의미가 수렴
- 활성 모순 쌍 **5개 이상**: 해석 불가 → 미지의 결과물
- **특수 레시피 매칭 시**: 모순 쌍 수와 무관하게 고유 아이템 생성

```
예시: 모순 2쌍 — 해석 가능
약초(회복,식,식물) + 철광석(공격,위,광물)
→ 회복↔공격 (1), 식물↔광물 (1) = 모순 2쌍
→ "부수고 되돌리는 단단하고 유연한 물건" — 수술도구? 해석 가능

예시: 모순 5쌍 — 미지의 결과물
회복+공격, 독성+수호, 억제+분산, 경도+가공성, 열+광
→ "되돌리면서 부수면서 해치면서 지키면서 막으면서 퍼뜨리면서
   단단하면서 다루기쉽고 온도가 변하면서 빛나는"
→ 빌어먹을 미지의 무언가
```

#### 태그 조합 해석 가이드

**효과 + 효과 (복합 목적)**
- 두 효과가 합쳐져서 복합 동사가 됨
- 예: 회복+공격 = "부수고 되돌린다" (파괴적 재건, 수술)
- 예: 독성+수호 = "해치면서 지킨다" (독갑, 독가시)
- 예: 억제+분산 = "봉하면서 퍼뜨린다" (광역 봉인)
- 태그 4개 이상도 가능: 독성+회복+공격+수호 = "면역 물약" (침투해서 부수고, 되돌리고 지킨다)

**효과 + 재료성질 (목적 + 물성 = 완성품)**
- 자연스러운 완성품 조합. 효과가 목적을, 재료성질이 물성을 결정
- 예: 조련+전도 = "길들이는 + 에너지가 흐르는" (전도성 조련도구)
- 예: 회복+가공성 = "되돌리는 + 다루기 쉬운" (마시기 쉬운 회복물)

**재료성질 + 재료성질 (물성만 = 소재)**
- 목적(효과 태그)이 없으므로 "뭘 하는 물건"이 안 됨 → 소재/중간재
- 예: 경도+전도 = 단단하고 에너지가 흐르는 소재 (전도금속)
- 예: 가공성+보존 = 다루기 쉽고 오래가는 소재 → 식재료 방향

**원소의 역할 (작동 방식 결정)**
- 같은 기능 조합이라도 원소가 다르면 완전히 다른 물건
- 조련+전도+**동**+유기 = 진동하는 살아있는 조련도구
- 조련+전도+**열**+유기 = 온도가 변하는 살아있는 조련도구
- 조련+전도+**식**+유기 = 마법적으로 작용하는 살아있는 조련도구

**형태의 역할 (물리 형상 결정)**
- 회복+가공성+식+**액체** = 마실 수 있는 회복물 (물약)
- 회복+가공성+식+**분말** = 뿌리는/먹는 회복 가루
- 회복+가공성+식+**결정** = 응축된 회복 결정 (보석형)

### 특수 조합 테이블

특정 태그 조합에서 일반 합산과 다른 결과가 나오는 경우만 별도 정의.

## 엘릭서 시스템 (v4.6 신규, 5-28 회차) ★ 특수 반응 첫 콘텐츠

### 정체성

- 엘릭서 = 도시/농장 시설 **업그레이드 재료** (신규 자리)
- niche 3분할: **물약(회복) / 엘릭서(마력촉매·변환 = 경영 성장 동력) / 현자의 돌(엔드게임 능력, 9-B 분기 합체 대상)**
- 역할: **제작 시스템 ↔ 경영 시스템을 잇는 다리** (system_economy.md v1.6 시설 업그레이드 게이팅)

### 태그 프로필 / 베이스

- 앵커 = **마력촉매(변환) 효과 태그**
- **흑화(nigredo) 베이스 레시피** = **마력촉매용액[마력촉매·가공성·열·광물·액체] + 촉매초[촉매·식물]**
  - 충돌 검사: 기존 특수레시피에 없음 (clear)
  - 촉매 ↔ 마력촉매 = 모순쌍 → 기존 "불안정한 특수 소재" = **흑화(nigredo) 불안정**과 정합
  - 원소 = 열 (식 아님) / 초반 접근 가능 (촉매초 = 온실 수급, 마력석 = 초반 광맥) / **환류기 무관**

### 두 다이얼 완전 분리 ★ 핵심

| 다이얼 | 정의 | 의미 | 가변 |
|---|---|---|---|
| **색** (마그눔 흑→백→황→적) | 모순쌍 수 (1→4) | 통합도 / 대업 단계 | 조작 어려운 구조 속성 |
| **티어** | 태그 밀도 (마력촉매 농축) | 파워 / 품질 | 가변 |

- 밀도와 색은 독립 — 밀도 올린다고 모순쌍 늘어나지 않음
- 색·티어 별개 다이얼이라 이중 관리 필요 (색 상승=대립 추가 / 티어 유지=농축)

### 구현 방식

- **특수 반응**(창발적 특수 조합)으로 구현 — 고정 특수 레시피는 **불가** (특수 우선 판정이 모순쌍을 무시하므로 색이 장식화됨)
- 5쌍 = 미지 = "대업 과욕 붕괴"
- 미지 → 정제 / 연구소 분석으로 구제 (실패 없음 원칙 유지)

### 양조 진행 (색 상승) — 반복 창발

```
현재 색 엘릭서 + [모순쌍 1개를 새로 켜는 재료] → 시스템이 모순쌍 재계산 → 다음 색
   흑화(1쌍) → +1쌍 재료 → 백화(2쌍) → +1쌍 → 황화(3쌍) → +1쌍 → 적화(4쌍, 천장)
   +1 모순쌍 = +1 색 (한 칸씩 상승)
```

- "모순쌍 추가 재료" 정의 = 현재 엘릭서에 *이미 있는 태그의 반대 태그*를 가진 재료
  - 예: 흑화에 열 있음 → 광 재료(수정나비 등) 투입 → 열↔광 쌍 활성 → 한 칸 상승
  - 동일 논리: 위↔동, 식물↔광물 등
- **흑화 = 공개/힌트 입구, 백화 이상 = 발견형** (어떤 재료가 한 칸 올리는지 탐색 = 대업 수행)
- 고정 레시피 불가 재확인 — 고정이면 모순쌍 계산이 무시되어 색이 장식화됨

### 주의

1. **재료 추가 = 고유 태그 증가 → 밀도(티어) 희석**. 색·티어 별개 다이얼이므로, 파워 유지하려면 **중간 가공으로 재농축** (색 상승 = 대립 추가 / 티어 유지 = 농축, 이중 관리)
2. **적화(4쌍) = 절벽**. 5쌍 = 미지(붕괴). 적화 양조 = 최고 리스크 (미지도 정제로 구제 가능)

### 게이팅 / 연결

- **시설 업글 게이팅 = 색(모순쌍) 기준** — 밀도는 가변이라 게이트 부적합 (치즈 방지)
- 밀도 = 게이트 아님, 효율 / 효과량 쪽
- **1-X 첫 엔딩**(도시 모든 설비 완공)과 연결 → **12공정 마스터 = 메인 엔딩 경로**
- 식 = 베이스 앵커 아님, **고티어 심층 첨가재**로 (식 = 모순 불참 → 안전 파워업 / 로어)
- 보스 드랍 = 마일스톤 열쇠(별도 층) / 공방 설비(가마 등) = 별도 재료 트랙

### 마그눔 4단계 정정 (v4.6, 5-28) ★

- **마그눔 4단계(흑·백·황·적) = 로어 스킨 only**
- **실제 메카닉 = 12공정** (system_unit_sigil.md v0.9 정합)
- 엘릭서 양조의 색 = 모순쌍 수, 마그눔 단계 어휘는 로어 색깔. 메카닉은 모순쌍 + 12공정

### 최종 조합 아이템 = 현자의 돌 (v4.6 → v4.7 분리 정정, L·5-28 회차)

- 현자의 돌 = 9-B 분기(탐사·도감 축) 합체 대상 = 전서 + 현자의 돌 → 9-B 엔딩 (system_unit_sigil.md v0.9 참조)
- 가공의 정점 자리. 디테일은 후속 회차 (G 회차 톤 + F 후속 9-X 도달 조건)

### 구현 골격 (2026-07-17 확정, 레티어스 조정 반영)

**① 색 판정식** — 혼합물 태그 집합에서 **활성 모순쌍 수** = 모순 태그 쌍 중 양쪽이 모두 존재하는 쌍의 수. 1=흑 / 2=백 / 3=황 / 4=적 / 5+=붕괴. **마력촉매 태그 보유 = 엘릭서 판정 앵커** (물약과 구분, niche 3분할 반영). 모순 태그 12쌍은 **구현 시 processing.csv `[tag_contradictions]` 섹션으로 데이터화** (현 crafting.js 하드코딩 → 오써링 규칙 4 확정성 적용. 트레잇 contradictionPairs.csv와 영역 별개).

**② 밀도** — 기존 태그 밀도 식 그대로 (tier = 총 태그 수 / 고유 태그 수, crafting.js 구현 재사용). 밀도→강화 효과량 곡선 수치 = **통합 밸런싱 패스** (잠정 자리만: 완만·선형·상한).

**③ 재농축 = 방법 비지정 ★ (레티어스 원칙)** — 양조의 "고정 레시피 불가"와 같은 결. **시스템은 밀도 식만 판정하고, 어떤 공정 경로든**(압축기 농축·동일 태그 재료 중첩·기타 조합) 동일 태그 밀도를 올리면 성립. 최적화 루트를 정해두지 않는다 — **최소 행동 수는 등가, 방법만 다르게** (등가성 검증 = 밸런싱 패스 항목).

**④ 5쌍 붕괴 = 까마귀 머리(caput corvi)** — UI 라벨 "미지 침전물"(표기 두 층 정책), 재료 소실. 회수 경로: **연구소 미지 분석**(채택 — 소량 환급+로어 파편) / **분쇄기 태그 해체 재가공**(원안, 병행 후보 — 방법 비지정 결이라 공존 검토). 절벽이되 완전 벌은 아니게.

**⑤ 아이템 스키마** — 새 타입 없이 기존 재료 스키마 연장: `{ id, tags:[...], color(태그에서 파생·캐시), density }`. 강화 실행부(economy)=요구 색 일치 엘릭서 **1개** 소모(soul_curve 검산 기준 잠정)+시공비, 밀도는 효과량 계수로 전달.

### ★ 엘릭서 ≠ 현자의 돌 (v4.7 분리 명시)

niche 3분할이 5-28 회차 단일 진실 자료:
- **물약** (회복)
- **엘릭서** (마력촉매·변환 = **경영 성장 동력**. 도시/농장 시설 업그레이드 재료 한정)
- **현자의 돌** (엔드게임 능력, 9-B 분기 합체 대상)

세 자리 모두 다름. **엘릭서 양조의 적화(4쌍, 색 천장) ≠ 현자의 돌 도달**. 엘릭서는 시설 업그레이드 게이팅(색)의 천장에 다다랐다는 의미일 뿐, 현자의 돌과는 별개 자리. 현자의 돌은 9-B 분기의 별도 트리거 (디테일 F 후속 회차).

### 미정 (후속)

- 엘릭서 ↔ 영혼력 관계 (대체 / 보강 / 티어업만) — 데맨드 결정
- 숫자: 시설 티어 ↔ 요구 모순쌍 매핑, 밀도 효율 곡선, 흑화 베이스 정확 모순쌍 수 — 밸런싱 패스
- 특수 반응 발동 트리거 정밀화 (마력촉매 앵커 + 엘릭서 발현 조건)
- 색 상승용 "모순쌍 추가 재료" 후보 목록 (어떤 재료가 어떤 쌍을 켜는지)
- **현자의 돌 도달 디테일** = 9-B 분기 합체 트리거. 엘릭서와 별개 (F 후속 회차)

[리네임]
  최초 발견 시 1회 제안 → 수락하면 도감에 해당 이름으로 등록
  거절 시 자동 생성명 유지

```

→ 태그: 변성+가공성+식물+액체 (원소 없음)
→ 자동명: "용이한 변성수"
```

### 미지의 결과물

> **재료를 넣으면 반드시 무언가 나온다. 실패는 없다.**

- 모순 쌍 5개 이상 → **미지의 결과물**
- 미지의 결과물도 태그를 가짐 → 다시 가공/조합 재료가 됨
- 미지의 결과물 + 가공 = 정제: 불명확 특성이 정리되어 쓸 수 있는 소재로 구제
- 미지의 결과물에도 로어 텍스트 부착 가능

### 초반 조합 예시 (Tier 1 확정 재료 기반)

> 아래 이름은 예시일 뿐 — 실제로는 특수 레시피가 아닌 한 **플레이어가 이름을 붙인다**.

```
[기본 조합 — 태그 합산으로 읽기]
약초(회복,식,식물) + 물(가공성,액체)
 → 태그 합산: 회복+가공성+식+식물+액체
 → 되돌리는 + 다루기쉬운 + 본질변환 + 유연+마시는 → 회복 물약 계열

촉매초(촉매,식물) + 물(가공성,액체)
 → 태그 합산: 촉매+가공성+식물+액체
 → 변환하는(거시) + 다루기쉬운 + 유연+마시는 → 효과태그 없음 = 소재 (범용 액체)

[가공 후 조합]
보존허브(보존,식,식물) + 식재료(가공성,광,유기)
 → 보존+가공성+식+광+식물+유기 → 오래가는+다루기쉬운+빛에너지+살아있는 → 식량 계열

공격소재(공격,위,광물) + 슬라임핵(전도,동,유기)
 → 공격+전도+위+동+광물+유기 → 부수는+전도+축적+진동+단단+살아있는 → 마력 구동 무기 계열

수호소재(수호,동,유기) + 철광석(경도,위,광물)
 → 수호+경도+동+위+유기+광물 → 지키는+단단+흐르는+축적 → 방어구 계열

억제소재(억제,식물) + 전도분말(전도,동,분말)
 → 억제+전도+동+식물+분말 → 봉하는+전도+진동+유연+가루 → 마력 봉인탄 계열

마력촉매소재(마력촉매,열,광물) + 증기(가공성,기체)
 → 마력촉매+가공성+열+광물+기체 → 변환(미시)+다루기쉬운+에너지변환+퍼지는 → 상위 소재

독분말(독성,광,분말) + 촉매초(촉매,식물)
 → 독성+촉매+광+분말+식물 → 해치는+변환(거시)+방출+가루+유연 → 독 농축 소재
```

### 결과물 카테고리 (2축 구조)

아이템 카테고리는 **용도축**과 **기능축** 두 개로 결정된다. 하나의 아이템이 복수의 용도/기능을 가질 수 있다.

#### 용도축 — "이 물건을 어떻게 쓰는가"

| 용도 | 설명 | 도출 조건 |
|------|------|----------|
| equipment | 유닛에 장착 가능 | 광물/유기 형태 + 기능 태그(공격/수호/부여 등) |
| consumable | 사용하면 소모됨 | 회복/독성 + 액체/식물/분말 형태 |
| material | 조합 입력 재료 | 촉매/마력촉매, 또는 다른 용도 조건 미충족 시 기본값 |
| parts | 도구 부품 (부품+재료 조합 시 부품 보존) | 부품 제작대에서 생성. 솥에서 접미사 부여 |
| tool_item | 조교 전용 아이템 (행위 해금) | 조합 또는 던전 드랍. 보유 시 대응 조교 행위 가능 |

- 복수 용도 가능: equipment + consumable = 장착 가능하면서 먹을 수도 있음 (햄배트식)
- 용도축은 주로 **형태 태그**에서 도출. 광물/유기 → equipment 가능, 액체/식물 → consumable 가능

#### 기능축 — "이 물건이 뭘 하는가"

| 기능 | 효과 방향 | 핵심 태그 |
|------|----------|----------|
| attack | 공격력 부여 | 공격 |
| defense | 방어력 부여 | 수호 |
| buff | 스탯 부여/강화 | 부여 |
| training | 조교 전용 아이템의 행위 해금 (로터/교본은 도구 시스템, system_tool_upgrade.md) | 조련 |
| heal | HP/상태 회복 | 회복 |
| poison | 대상에 독성 피해 | 독성/분산 |
| catalyst | 상위 조합 재료 역할 | 촉매/마력촉매 |
| gather | 채집량/접근 tier 증가. 기본 도구는 고정 지급, 상위 도구는 조합으로 업그레이드 | 특수 레시피 또는 태그 조합 |
| facility | 설비 부품 | 특수 레시피 |

- 복수 기능 가능: heal + catalyst = 회복 물약이면서 조합 재료로도 사용 가능
- 기능축은 주로 **기능 태그**에서 도출

#### 복합 카테고리 예시

```
고기 둔기:     용도 [equipment, consumable] / 기능 [attack, heal]
→ 장착하면 무기. 먹으면 HP 회복. 보존 태그 없으면 시간 경과로 부패?

하드택 방어구:  용도 [equipment, consumable] / 기능 [defense, heal(보존)]
→ 장착하면 방어구. 긴급하면 먹을 수 있음. 보존 태그라 부패 안 함

촉매 물약:     용도 [consumable, material] / 기능 [heal, catalyst]
→ 마시면 회복. 조합에 넣으면 촉매 역할

상위 구속구:    용도 [tool_item] / 기능 [training]
→ 조교 전용 아이템. 보유 시 구속 행위 가능 + 상위 트레잇 후보 개방
```

#### 레거시 카테고리 매핑 (하위 호환)

| 구 카테고리 | → 용도축 | → 기능축 |
|------------|---------|---------|
| equipment_weapon | equipment | attack |
| equipment_armor | equipment | defense |
| equipment_accessory | equipment | buff |
| tool_training | **폐기** → 도구 시스템(system_tool_upgrade.md)으로 이관. 조교 전용 아이템은 tool_item 용도 | training |
| tool_gathering | **폐기** → 도구 시스템(system_tool_upgrade.md)으로 이관. 채집 도구는 게이팅 시스템 | gather |
| tool_crafting | material | facility |
| consumable_potion | consumable | heal 또는 poison |
| consumable_food | consumable | heal(보존) |
| consumable_attack | consumable | poison |
| material_refined | material | catalyst |

### 등급 체계 (태그 밀도 기반 tier) — v4.3 개편

등급은 **태그 밀도**로 결정. 별도 품질/tier 메타데이터 없음. **태그가 곧 tier**.

#### 공식: 전체 태그 수 ÷ 고유 태그 종류 수 (버림)

```javascript
// tags = ['열','열','전도','동','동']
const counts = {};
tags.forEach(t => counts[t] = (counts[t]||0) + 1);
const totalTier = Object.values(counts).reduce((s,v) => s+v, 0);
const uniqueTags = Object.keys(counts).length;
const finalTier = Math.floor(totalTier / uniqueTags);
```

#### 예시

```
예1: [열, 전도]             → 열(1)+전도(1) = 2 ÷ 2 = tier 1
예2: [열, 열, 식, 전도, 치유] → 열(2)+식(1)+전도(1)+치유(1) = 5 ÷ 4 = tier 1
예3: [전도, 전도, 동, 동]    → 전도(2)+동(2) = 4 ÷ 2 = tier 2
예4: [열, 열, 열]           → 열(3) = 3 ÷ 1 = tier 3
```

#### 핵심 원칙: 집중하면 강해지고, 흩으면 약해진다

- **집중** = 같은 태그 반복 → 고tier, 단기능
- **분산** = 다양한 태그 혼합 → 저tier, 복합기능
- 플레이어 선택: 강한 단일 효과 vs 약한 복합 효과

#### 재료 드랍도 태그 밀도로 tier 표현

상위 층 드랍 재료는 **같은 태그가 더 많이 붙어서** 자연스럽게 고tier.

```
Tier 1 약초: [식, 식물]                          → 2/2 = tier 1
Tier 2 약초: [식, 식, 식, 식물, 식물]              → 5/2 = tier 2
Tier 1 철광석: [위, 광물]                         → 2/2 = tier 1
Tier 2 철광석: [위, 위, 위, 광물, 광물]            → 5/2 = tier 2
```

- 재료 자체에 tier 숫자 메타데이터 불필요 — 태그 배열이 곧 tier
- 조합 시 양쪽 태그가 합산되어 결과물 tier가 자동 계산

#### 조합 시 tier 희석 예시

```
Tier 2 약초 + Tier 1 물:
[식,식,식, 식물,식물] + [가공성, 액체]
→ 식(3)+식물(2)+가공성(1)+액체(1) = 7/4 = tier 1  (희석됨)

Tier 2 약초 + Tier 2 물:
[식,식,식, 식물,식물] + [가공성,가공성,가공성, 액체,액체]
→ 식(3)+식물(2)+가공성(3)+액체(2) = 10/4 = tier 2  (유지)
```

```
결과물 수치(효과량, 공격력 등) = 기본값 × tier 보정 계수 (밸런싱 시 확정)
```

## 트랙 3: 특수 레시피 (고정 조합)

### 핵심 구조

특정 재료 조합에서만 나오는 고유 결과물. 일반 조합 규칙보다 **우선 판정**.

특수 레시피는 **기초 레시피**와 **상위 레시피** 2층으로 나뉜다.

### 기초 레시피 (안전망 — 튜토리얼 대체) (확정 9종)

게임 시작 시 전임자의 메모로 공개. 역할은 **시스템 작동 방식을 보여주는 것** + **초반 필수 아이템 확보**.
3단계로 나뉘어 가공 없이→가마→분쇄 순서로 시스템을 단계적으로 학습.

#### 1단계: 가공 없이 (원재료끼리)

| # | 이름 | 재료 | 태그 합산 | 용도 |
|---|------|------|----------|------|
| 1 | 기초 회복 물약 | 약초 + 물 | 회복+가공성+식+식물+액체 | 전투 중 HP 회복 |
| 2 | 기초 독물약 | 독물고기 + 물 | 독성+가공성+광+유기+액체 | 전투 중 투척 |
| 3 | 기초 배터리 | 마력석 + 슬라임핵 | 촉매+전도+열+동+광물+유기 | 조합 재료 (용도는 플레이어 탐색) |

- 약초+물 = 가장 먼저 배우는 조합. 조합 시스템 자체의 튜토리얼
- 독물약 = 전투 수단이 생김. "조합으로 탐사가 쉬워진다"를 체감
- 배터리 = **"조합 결과물이 다시 재료가 된다"를 가르치는 튜토리얼**. "이건 재료다, 다른 것과 합쳐봐라"까지만 안내. 구체 용도는 플레이어가 탐색

#### 2단계: 가마 가공 후 조합

| # | 이름 | 재료 | 가공 과정 | 태그 합산 | 용도 |
|---|------|------|----------|----------|------|
| 4 | 기초 무기 | 공격광물 + 슬라임핵 | 철광석→[가마]→공격광물 | 공격+전도+위+동+광물+유기 | 유닛 장착 (공격) |
| 5 | 기초 방어구 | 수호체 + 철광석 | 슬라임핵→[가마]→수호체 | 수호+경도+동+위+유기+광물 | 유닛 장착 (방어) |
| 6 | 기초 식량(스프) | 식재료 + 물 | 독물고기→[가마]→식재료 | 가공성+가공성+광+유기+액체 | 전투 이후 유닛 컨디션 |

- 무기/방어구: **같은 재료 2종(철+슬라임)의 가공 순서로 결과가 갈린다** — 가공 의미를 체감
- 식량: 독물고기를 구워서 해독 → 식재료화. "가공이 재료를 바꾼다"를 체감
- 전투 중(물약) vs 전투 이후(식량) 사용 타이밍 분리

#### 3단계: 분쇄 가공 후 조합

| # | 이름 | 재료 | 가공 과정 | 태그 합산 | 용도 |
|---|------|------|----------|----------|------|
| 7 | ~~기초 조교도구~~ | ~~슬라임분말 + 약초~~ | — | — | **폐기** (v4.3: 도구 7종 t0 기본 지급으로 전환. system_tool_upgrade.md 참조) |
| 8 | 기초 교섭재료 | 슬라임분말 + 촉매초 | 슬라임핵→[분쇄]→슬라임분말 | 전도+촉매+동+분말+식물 | 던전 유닛 교섭/영입 |
| 9 | ~~기초 로터~~ | ~~슬라임분말 + 슬라임핵~~ | — | — | **폐기** (v4.3: 도구 7종 t0 기본 지급으로 전환. system_tool_upgrade.md 참조) |

- 교섭재료: 탐사 시스템의 조우→대화(교섭) 루트와 직접 연결 (메가텐식)
- 분쇄 설비 사용법 학습
- ~~조교도구/로터~~: v4.3에서 폐기. 도구는 게임 시작 시 7종 t0 기본 지급, 업그레이드는 부품+재료 방식 (system_tool_upgrade.md)

#### 설계 포인트

- **Tier 1 원재료 7종 전부 사용**: 빠지는 재료 없음
- **3단계 튜토리얼**: 가공없이(1~3) → 가마(4~6) → 분쇄(7~9) 순서로 시스템 학습
- **카테고리 커버**: 회복/공격/장비/식량/교섭/설비연료 (조교도구/로터는 v4.3에서 기본 지급으로 전환)
- **대칭 구조**: 철+슬라임의 가공 순서로 무기/방어구 분기
- 도구 7종(채집3+육성2+조교2)은 게임 시작 시 t0 기본 지급 (system_tool_upgrade.md)
- **판매는 아이템이 아닌 유닛**: 아이템 판매 시스템 없음

### 상위 레시피 (발견형)

파편 로어, 마일스톤, 우연에 의해 발견되는 고유 레시피.

```json
{
  "recipe_id": "SPECIAL_001",
  "name": "심연의 물약",
  "tier": "special",
  "required_materials": ["MAT_ABYSS_METAL", "MAT_ORIGIN_WATER"],
  "known_from_start": false,
  "discoverable": true,
  "discovery_hint": "LORE_042",
  "unlock_condition": { "type": "milestone", "value": "dungeon_floor_50" },
  "lore": "심층의 금속과 심연의 물이 만나면, 경계를 넘는 자를 위한 약이 된다."
}
```

발견 방식:
- **힌트형**: 파편 로어에서 재료 조합 단서 → 플레이어가 유추
- **해금형**: 마일스톤 달성 시 레시피 공개
- **우연형**: 힌트 없이 시도해서 발견 (숨겨진 레시피)

### Tier 1 숨겨진 레시피 (15종 — 기초 레시피에 미포함, 플레이어 탐색)

기초 레시피로 알려주지 않지만 확실한 결과가 나오는 특수 레시피.
Tier 1 재료 + 가공 범위 내에서 만들 수 있는 것들.

#### 소비재 — 원재료 조합

| # | 이름 | 재료 | 태그 합산 | 용도 |
|---|------|------|----------|------|
| 1 | 해독제 | 약초 + 독물고기 | 회복+독성+식+광+식물+유기 | 독 상태 해제 |

#### 소재/중간재 — 원재료 조합

| # | 이름 | 재료 | 태그 합산 | 용도 |
|---|------|------|----------|------|
| 2 | 정화수 | 촉매초 + 물 | 촉매+가공성+식물+액체 | 술의 베이스 (중간재) |
| 3 | 감로주 중간재 (가칭) | 약초 + 촉매초 | 회복+촉매+식+식물 | 감로주 재료 |

#### 소재/중간재 — 가공 후 조합

| # | 이름 | 재료 | 가공 과정 | 태그 합산 | 용도 |
|---|------|------|----------|----------|------|

#### 소비재 — 다단계 조합 (포션)

포션류는 **마력 용액(포션 베이스) + 가공된 재료** 2단계로 완성.

**용액 방향 가이드**:
- **마력 분말 용액** (촉매/물리적 변환) → **공격 계열** 포션에 사용. "물리적으로 형태를 부수고 재구성"
- **마력 촉매 용액** (마력촉매/화학적 변환) → **방어 계열** 포션에 사용. "화학적으로 성질을 바꿔 적응"
- 가이드일 뿐 강제 아님 — 반대로 넣어도 자동 생성으로 뭔가 나옴 (다른 방향의 결과물)
- 두 용액을 합치면? 촉매↔마력촉매 모순 쌍 1개 → 해석 가능하지만 불안정한 특수 소재 (자동 생성)

| # | 이름 | 재료 | 공정 | 용도 |
|---|------|------|------|------|
| 13 | 공격 강화 포션 | **마력 분말 용액** + 공격광물 | 마력석→[분쇄]→분말+물→용액, 철광석→[가마]→공격광물 | 아군 유닛 물리공격 ↑ |
| 14 | 방어 강화 포션 | **마력 촉매 용액** + 수호체 | 마력석→[가마]→촉매석+물→용액, 슬라임핵→[가마]→수호체 | 아군 유닛 물리방어 ↑ |
| 15 | 공격 약화 포션 | **마력 분말 용액** + 억제초 | 마력석→[분쇄]→분말+물→용액, 촉매초→[가마]→억제초 | 적 유닛 물리공격 ↓ (투척) |

- 가이드 방향과 다른 조합(분말용액+수호체, 촉매용액+공격광물 등)도 자동 생성으로 결과물 나옴 — 플레이어 탐색 영역
- 구체적 효과 차이는 밸런싱 시 확정

#### 소비재 — 다단계 조합 (술)

| # | 이름 | 재료 | 공정 | 용도 |
|---|------|------|------|------|
| 17 | 감로주 | 감로주 중간재 + 정화수 | 약초+촉매초 → 중간재, 촉매초+물 → 정화수 | 호감도/영입용. ERA 조교 시 보조 |
| 18 | 몽환주 | 몽환주 중간재 + 정화수 | 약초+억제초 → 중간재, 촉매초+물 → 정화수 | 조교 단계 하락용. ERA 핵심 도구 |

#### 설계 포인트

- 기초 레시피(9종)로 시스템을 배운 후, 플레이어가 **자발적으로 발견**하는 영역
- **소재 5종**: 마법강철(무기/장비), 마력용액2종(포션베이스), 가죽소재(방어구/천), 정화수(술베이스)
  - 조합 결과물이 다시 재료가 되는 패턴이 풍부함
- **포션은 2단계 공정**: 마력 용액 제작 → 용액+재료 = 포션. 용액 종류로 방향 분기 (상하 아님)
- **술은 3단계 공정**: 중간재 + 정화수. ERA 핵심 도구이므로 의도적으로 복잡
- 전투 스탯은 초반 **물리 공격/물리 방어/속도** 3종. 근접/사격 구분 없이 물리 통합
  - 속도 관련 포션은 상위 티어에서 추가
  - 원소 속성 공격/방어 포션은 전투 시스템 방어 프로필 체계 반영 후 추가 (미확정)

## 제작 판정 흐름 (통합)

### 핵심: 가공과 조합은 자유롭게 교차한다

```
가공 → 조합 → 가공 → 조합 → ... (필요한 만큼 반복)
```

#### 강철 제작 예시 (업데이트)

```
철광석 (경도, 위, 광물 / tier 1)
  → [분쇄] → 철가루 (경도, 위, 분말 / tier 1)
  → [조합: +마력석] → 선철 (경도+촉매, 위+열, 광물 / tier 2)
  → [가마] → 강철 (공격, 위+열, 광물 / tier 3)
```

#### 판정 흐름

```
[아이템을 작업대에 올린다]
       ↓
무엇을 할 것인가?
  ├─ [가공] → 설비 확인 → 가공 실행 → 기능태그 변환 or 형태 변환
  └─ [조합] → 두 번째 재료 투입
                 ↓
            [1단계] 특수 레시피 테이블 확인
                 → 매칭됨: 고유 아이템 생성
                 → 매칭 안 됨: 다음 단계로
                 ↓
            [2단계] 일반 조합 규칙 테이블 확인 (태그 기반)
                 → 매칭됨: 의도된 결과물 생성
                 → 매칭 안 됨: 다음 단계로
                 ↓
            [3단계] 미지의 결과물 생성 (실패 없음)

결과물을 다시 작업대에 올려서 추가 가공/조합 가능
```

### 실패 없는 조합

> **재료를 넣으면 반드시 무언가 나온다. 실패는 없다. 쓸모는 다를 뿐.**

- 미지의 결과물도 태그를 가짐 → 다시 가공/조합 재료가 됨
- 미지의 결과물 + 가공 = 정제: 불명확 특성이 정리되어 쓸 수 있는 소재로 구제
- 미지의 결과물에도 로어 텍스트 부착 가능

### 판정 문법의 통일: 아이템 조합 ↔ 유닛 합체 (v4.0 추가)

아이템 조합과 유닛 합체는 **동일한 판정 패턴**을 따른다.

```
[아이템 조합 판정]
재료 A + 재료 B → 태그 합산
  1. 특수 레시피 우선 참조 → 매칭되면 고유 아이템
  2. 일반 조합 (태그 합산) → 자동 생성
  3. 미지의 결과물

[유닛 합체 트레잇 판정]
소재 A 트레잇 + 소재 B 트레잇 → 전체 스캔
  1. 합성 발동 (최우선) → 합성 트레잇으로 변환
  2. 직접 계승 (남은 슬롯) → 그대로 넘어감
  3. 잠재력 계승 (나머지) → 임계점 인하
```

"재료를 합쳤을 때 결과를 판정하는 로직"이 아이템이든 유닛이든 같은 구조.
특수/우선 결과 → 일반 결과 → 나머지 처리 순서가 일관됨.

> 유닛 합체 판정 상세는 → system_unit_sigil.md, system_unit.md 참조

### 합체 텍스트 톤 (v4.4 → v4.6 메타 격상 확장)

합체 시스템은 **일상부터 게임 메타 종결까지 모두 한 자리** = L 회차 메타 격상(system_unit_sigil.md v0.9 정합).

| 차원 | 자리 | 톤 | 호흡 |
|------|-----|-----|------|
| **일상** | 일반 합체 (페르소나·여신전생식. 두 유닛 선택 → 결과 → 컨펌 → 새 유닛) | **가벼움** | ERA식 짧고 즉각 |
| **일상 내 짧은 응축** | 합성 발동 (계승 3경로 중) | 짧은 응축 한 줄 (학자→본질 노출 패턴) | 한 호흡 멈춤 |
| **교차 모먼트** | 합체 사고 (예외) — 옛 학자들의 "환희" 결 | **진한 톤** — 전수서 나레이터 반응 + 본질 색 | 응축 한 단락 |
| **분기 엔딩** ★ | **전서 + X 합체** (9-A 호문쿨루스 / 9-B 현자의 돌 / 9-C 플레이어) | **응축, 본질 색** (학자→본질 노출 최종) | 응축, 메타 서사 톤 |
| **진엔딩** ★ | **4 요소 크로스 합체** (9-Ω 전서+호문쿨루스+현자의 돌+플레이어) | **최대 응축, 메타 서사 정점** | 게임 진정한 완성 톤 |
| 각성 시스템 (별도) | 9-C 분기 메커니즘. 인 활성+호감도 사이클 (system_unit_sigil.md v0.9 참조) | 응축 한 단락 (각성 발현 시) | 사이클 반복 결 |

> **L 회차 메타 격상**: 합체 = 게임 진행의 일상부터 종결까지 모두 한 자리. 9-A 분기뿐 아니라 9-B·9-C·9-Ω 모두 합체 행위로 도달. 디테일 → system_unit_sigil.md v0.9 "합체 시스템 메타 격상" + "9-X 엔딩 = 전서+X 합체 구조" + "9-Ω 진엔딩".
>
> J 회차 진화 시스템은 L 회차에서 **각성으로 자연 정정** (system_unit_sigil.md v0.9 각성 시스템). 별도 시스템 X.

## 도구 시스템 연결 (v4.1 → v4.3 개편)

> 참조: system_tool_upgrade.md (도구 업그레이드 전체), system_unit.md (트레잇 획득), system_unit_sigil.md (인×조교)

도구 시스템은 v4.3에서 전면 개편. 도구 7종 t0 기본 지급 + 부품+재료 업그레이드 방식으로 전환.

### 채집 도구 (3종) — 게이팅 시스템

채집 도구(곡괭이, 낚시대, 채집봉)만 **게이팅**(부품 tier 평균)이 적용. 게이팅이 접근 가능 재료 tier / 채집 포인트 범위를 결정.

```
게이팅 = 전 부품 tier 합계 ÷ 3 (버림)
게이팅 0: 초급 구간 (1~5층) Tier 1 재료
게이팅 1+: 중급 이상 재료 접근 가능 (구체 수치는 밸런싱 시 확정)
```

### 조교 도구 (2종) — 연금술사 보너스

로터/교본은 트레잇 접근에 직접 영향 없음. tier 상승 시 조교/교류 행위의 **효율 보너스** 부여.

- 로터 tier ↑ → 조교 행위 시 보너스 (효율, 감도 등)
- 교본 tier ↑ → 교류 행위 시 보너스 (호감도 획득 등)

### 조교 전용 아이템 — 행위 해금 키

조교 전용 아이템(구속구, 채찍, 딜도 등)은 도구 빌드판과 **별도 체계**. 조합 또는 던전 드랍으로 획득.

- 해당 아이템이 있어야 대응하는 조교 행위가 가능 (채찍 → 채찍질, 구속구 → 구속 행위)
- 상위 전용 아이템 → 상위 트레잇 해금 후보 개방 (예: 상위 구속구 → 공포각인 계열)

### 육성 도구 (2종) — 전투 능력 성장

타격 인형/달리기 기구는 유닛 전투 능력 성장에 영향. tier 상승 시 육성 효율 보너스.

### 설계적 의미

- **조합(crafting)과 도구(tool)의 구조적 연결**: 재료를 부품에 투입하여 도구 업그레이드
- **탐사 → 재료 획득 → 도구 부품 강화 → 상위 채집/육성/조교** 루프 완성
- 도구 업그레이드는 기존 조합의 연장선 ("모든 것은 조합이다")

## 리팩토링 로드맵: 카테고리 시스템 개편 (2축 전환)

> 현재 문제: `determineCategory()`가 단일 카테고리 워터폴 구조.
> 복합 기능 태그 아이템(회복+촉매, 조련+수호 등)에서 하위 우선순위 기능이 소실됨.
> 목표: **용도축 + 기능축 2축 구조**로 전환. 하나의 아이템이 복수 용도/기능을 동시 보유.

### 1단계: determineCategory() → determineUsages() + determineFunctions() 분리

`determineCategory()`를 두 함수로 분리. 각각 배열을 반환.

```javascript
// AS-IS (단일 카테고리 워터폴)
category: 'equipment_armor'

// TO-BE (2축 배열)
usages: ['equipment'],              // 용도축: 형태 태그에서 도출
functions: ['defense', 'training']  // 기능축: 기능 태그에서 도출
```

- `determineUsages(tags)`: 형태 태그(광물/유기/액체/식물/분말/결정/기체)로 용도 판정. 복수 해당 시 복수 반환
- `determineFunctions(tags)`: 기능 태그(공격/수호/조련/회복/독성/촉매 등)로 기능 판정. 해당하는 것 전부 반환
- 레거시 호환: `category` getter를 남겨서 `usages[0]_functions[0]` 형태로 구 카테고리 문자열 반환
- 변경 범위: `determineCategory()` → 2함수 분리 + 아이템 데이터 구조 변경 + `generateEffect()` 복수 기능 대응

### 2단계: UI/시스템 복수 카테고리 대응

- 인벤토리: 용도별 탭(장비/소비/소재) + 기능 필터(공격/방어/조련/회복...)
- 장착 시스템: `usages.includes('equipment')` 체크로 장착 가능 여부 판정
- 소비 시스템: `usages.includes('consumable')` 체크로 사용 가능 여부 판정
- 납품/도시 요청: 기능축 매칭 (`functions.includes('heal')` 등)
- 조교 시스템: `functions.includes('training')` 체크로 조교도구 감지 (현재 hasTrainingTool() 리팩토링)

### 3단계: 복합 용도 상호작용 (선택)

- equipment + consumable 복합 아이템의 게임플레이:
  - 장착 중 "먹기" 액션 → 장비 해제 + 소비 효과 발동 + 아이템 소멸 (햄배트식)
  - 보존 태그 유무로 부패 여부 결정
- 카테고리 간 시너지 효과:
  - training + defense = 방어 훈련 보너스
  - heal + catalyst = 사용 시 회복 + 잔여물이 촉매로 남음
- 이 단계는 밸런싱 후 필요 시 도입

### 병행: 이름 중복 버그 수정

- `generateName()`에서 중복 태그를 deduplicate하지 않아 수식어 중복 발생
- 이름 조립 전 elements/functions/forms 배열을 Set 처리로 중복 제거
