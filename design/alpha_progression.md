# 알파 초반 진행 동선 (v0.1)

> 참조: dungeon_alpha.md (던전 구성), system_crafting.md (조합), system_economy.md (경영), system_npc_relationship.md (유닛 조우/관계), system_exploration.md (탐사)
> 범위: 게임 시작 ~ 5층 보스 격파 (= 튜토리얼 졸업)

---

## 설계 원칙

> **"시스템을 하나씩 꺼내 보여주고, 5층에서 전부 합친다."**

- 플레이어가 한 번에 하나의 시스템만 처음 접하도록 순서를 배치
- 각 시스템은 "필요한 순간"에 자연스럽게 등장 — 미리 설명하지 않음
- 5층 보스 격파 = 튜토리얼 졸업. 모든 코어 시스템을 한번씩 경험한 상태
- 5층 이후 경제 압박(유지비) 시작 → "진짜 게임"의 시작점

| 항목 | 내용 | 출처 |

- 영혼력: 0 (또는 극소량) — 납품 경험 전

- 압축기: 없음 (5층 보스 이후 제작)
- 유지비: 없음 (압축기 제작 전까지 발생 안 함)

## 진행 동선

### 1단계: 첫 탐사 (1층)

**도입 시스템: 탐사 + 전투 + 채집**

```
공방 출발 → 미궁 입구 → 1층 진입
  → F1-B (석굴/전투): 가시 임프 or 소금 슬라임 조우 → 전투
  → F1-C (석굴/채집): 철광석, 마력석 채집
  → F1-D (출구) → 귀환
```

- 전임자 유닛 1체를 편성하고 출발
- 1층은 일직선 (분기 없음) — 길을 잃을 수 없음
- 전투 → 채집 순서로 기본 루프 체험: "싸우고 줍는다"
- 귀환 시 인벤토리에 재료가 생긴 상태

#### 이 단계에서 플레이어가 배우는 것

- 탐사 진입/귀환 흐름
- 전투 (자동전투 + 소비재 개입)
- 채집 포인트 사용
- 재료 획득

---

### 2단계: 첫 조합 (귀환 후)

**도입 시스템: 조합/가공**

```
귀환
  → 공방에서 안내 트리거: "가져온 재료로 뭔가 만들 수 있다"
  → 전임자 메모 참조: 기초 레시피 제시
  → 첫 조합 실행
```

- 1층에서 가져온 재료 (철광석, 마력석, 슬라임핵 등)로 첫 제작
- 전임자 메모가 "이 재료를 이렇게 써봐" 역할 — 레시피 힌트
- 결과물이 장비/소비재 → 다음 탐사에 활용할 수 있다는 걸 체감

#### 이 단계에서 플레이어가 배우는 것

- 가공/조합 기본 흐름
- 태그 → 결과물 관계의 첫 인상
- 결과물 = 탐사/유닛에게 쓰는 것 (판매가 아님)

#### 미결정

- [ ] 첫 조합 안내 트리거의 구체 형태 (전서 코멘트? UI 힌트? 자동 이벤트?)
- [ ] 첫 조합 추천 레시피 (1층 재료 조합으로 만들 수 있는 것 중 유용한 것)

---

### 3단계: 유닛 영입 (2~3층)

**도입 시스템: 유닛 조우/교섭**

```
2층 탐사 → 첫 분기 등장 (석굴 루트 vs 수계 루트)
  → 전투 노드에서 유닛 조우
  → 튜토리얼 조우 이벤트: 교섭 흐름 안내
  → 영입 성공 → 유닛 2호 합류
```

- 2층에서 처음으로 구역 선택이 등장 — "어디로 갈까"의 첫 판단
- 조우 시 대화/전투/도주 선택지 체험
- 영입 튜토리얼: 교섭 흐름을 안내하는 이벤트

#### 이 단계에서 플레이어가 배우는 것

- 던전 분기 (구역 선택)
- 유닛 조우 → 교섭 → 영입 흐름
- "적도 동료 후보다"는 핵심 원칙

#### 미결정

- [ ] 튜토리얼 조우 대상 유닛 (어떤 유닛이 첫 영입 대상?)
- [ ] 영입 튜토리얼의 구체 연출 (강제 이벤트? 힌트 제공?)
- [ ] 영입 실패 시 세이프티넷 (튜토리얼 조우는 실패 불가?)

---

### 4단계: 도시 배치 (유닛 2~3체 보유 시점)

**도입 시스템: 도시 시설 + 유닛 배치**

```
유닛 2~3체 보유
  → 도시 시설 안내 트리거: "탐사에 안 데려갈 유닛은 도시에 둘 수 있다"
  → 유닛 배치 → 시설 가동 (기초 재료 자동 수급 시작)
```

- 파티 슬롯 제한 (초기 2인)으로 "여분의 유닛"이 자연 발생
- 여분 유닛의 쓸모 = 도시 배치 → 시설이 뭔가를 해준다는 걸 체감
- 우물(물 수급) 등 초기 시설에 배치

#### 이 단계에서 플레이어가 배우는 것

- 도시 시설의 존재와 역할
- 유닛 배치 = 장기 투자 (탐사에 못 씀)
- "유닛을 어디에 쓸까" 판단의 시작

#### 미결정

- [ ] 첫 배치 가능 시설 (우물? 다른 초기 시설?)
- [ ] 배치 안내 트리거의 구체 형태
- [ ] 초기 도시 시설 건설 비용 (영혼력 0 상태에서 무료 건설? 아니면 시설이 이미 존재?)

---

### 5단계: 보스 + 경제 루프 개시 (5층)

**도입 시스템: 납품 + 영혼력 + 유지비**

```
5층 보스 (거대 슬라임) 격파
  → 스프링 획득
  → 마법강철 확보 (채집/가공 루트)
  → 압축기 제작 (Tier 1.5 설비)
  → 유지비 시작 알림: "이제부터 설비 유지에 영혼력이 필요하다"
  → 납품 시스템 해금/안내: "유닛을 전서에 납품하면 영혼력을 얻는다"
```

- 보스 격파 → 설비 업그레이드 → 유지비 발생 → 납품 필요성 자연 도입
- "영혼력이 줄어간다" → "벌어야 한다" → "유닛을 납품한다" 순서로 체감
- 여기서 처음으로 **유닛의 4방향 용도**(납품/배치/합체/탐사)가 전부 열림
- = **튜토리얼 졸업**

#### 이 단계에서 플레이어가 배우는 것

- 보스전 (기믹 없는 순수 스탯전 → 준비의 중요성)
- 설비 업그레이드 루프 (재료 → 설비 제작)
- 유지비의 존재 → 경제 압박의 시작
- 납품 = 유닛을 잃고 영혼력을 얻는 선택
- "이 유닛을 어디에 쓸 것인가"가 진짜 시작됨

#### 미결정

- [ ] 압축기 제작 전 사전 경고의 구체 형태 ("만들면 유지비 나간다" 안내)
- [ ] 첫 납품 유도 대상 (전임자 유닛? 영입 유닛? 새로 잡은 유닛?)
- [ ] 납품 안내 트리거의 구체 형태

## 5층까지의 시스템 개방 요약

| 층 | 도입 시스템 | 트리거 | 플레이어 상태 변화 |
|----|-----------|--------|-----------------|
| 1층 | 탐사, 전투, 채집 | 게임 시작 | 유닛 1체, 재료 획득 |
| 귀환 | 조합/가공 | 재료 보유 | 장비/소비재 제작 가능 |
| 2~3층 | 유닛 영입, 구역 선택 | 던전 분기 도달 | 유닛 2~3체 |
| 도시 | 도시 배치 | 여분 유닛 발생 | 기초 자원 자동 수급 |
| 5층 | 보스, 설비, 납품, 유지비 | 보스 격파 → 압축기 | 경제 루프 시작, 4방향 선택 전부 개방 |

## 5층 이후: "진짜 게임"

5층 클리어 시점에서 플레이어가 가진 경험:

- [x] 탐사 가봤다
- [x] 전투 해봤다
- [x] 채집 해봤다
- [x] 조합 해봤다
- [x] 유닛 영입해봤다
- [x] 도시에 배치해봤다
- [x] 보스 싸워봤다
- [x] 설비 만들어봤다
- [x] 납품해봤다 (또는 납품의 필요성을 인지)

이후 6~15층은 이 시스템들이 **간섭하면서 복잡해지는** 구간:

- 유닛 합체 (소재 2체 소멸의 무게)
- 조교/육성 깊이
- 도시 확장 판단
- 더 깊은 층의 리스크/리워드
- 이머전트 이벤트 발생
