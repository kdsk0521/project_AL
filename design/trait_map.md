### 1-1. 합성 정점 배분 v2 (2026-07-17 잠정 — 커버리지 모델 + 전투·신체 몰드 정합)

**노출면 모델**: 정점 소비처는 카테고리별로 다름 — CT=전투 로테이션 ~5 / PT=시설 배치·관계 ~10 / AT=조교 병행 ~4 / BT=로스터 패시브 ~12 → 회차 정점 도달 ≈ 12 → **전체 끝 30~40 = 재플레이 존(커버 25~50%)**. 구조 = **이층**: T4 정점층(넓이 — 서로 다른 방향의 강화) + T5 대정점(무게 — 카테고리 0~1, 회차 프로젝트급, 특수인·9-X 결 후보).

**갈림 정점 정책 (2026-07-17 확장 채택, 레티어스)** — 한 정점 자리에 두 끝:

- 근거: 모순쌍(통합/분열)·변용(4루트 수렴)이 이미 이 문법. 사다리·뿌리는 공유하고 잎만 2배 = 저작 대비 재플레이 신선도 최고 효율. 잎 많아지는 건 허용(아이템 제작류 대비 적정 규모 — 레티어스).
- 적용: **T5 대정점 3 = 기본 갈림** / **PT T4 6 = 모순쌍 승격이라 통합·분열 갈림 구조 내장(자동)** / 나머지 T4 = 방향 대비가 서사적으로 강한 자리에 갈림 허용 — 단 **CT 공격 3은 제외**(이미 속성군 변주). 갈림 자리 ≈ 12~16 → **잎 총량 ≈ 36~40**.
- 분기 결정 = 기존 문법 재사용, 명시 선택 UI 없음: **조건 분기**(유닛 상태가 가름 — 모순쌍 splitWhen 방식) 또는 **재료 분기**(마지막 합성 재료가 가름 — "준비가 결정" 결). 자리별로 어느 쪽인지 로스터에서 지정.
- 명명 지침: 파라켈수스 결 — *같은 물질의 두 얼굴, 용량이 약과 독을 가른다*. 갈림 잎 한 쌍 = 같은 뿌리의 밝은/어두운(또는 정/편) 대비로 짓는다.
- CT 정점이 [오버라이드]를 가지면 우선순위 사다리(변용 종착 > 합성 > base)의 자리를 로스터에서 명시.
- 모델 가정(실플레이 검증 대상): 트레잇 획득 ~1개/월/유닛 · 정점 도달 = 유닛당 회차 1~2개.

> 축 1~4만 완결. **5·6이 편입+설계로 닫을 수 있는 근거리**, 7~10은 게임설계 결정 필요(끝 로스터 다음 회차).
