## 던전 로어

이 던전은 **고대 연금술 기계(대연성기)**가 폭주하며 형성된 공간이다. 원래 하나의 장치였던 것이 공정별로 분리·확장되면서, 각 연금술 과정이 물리적 환경으로 발현되었다. 석굴은 소성/하소(煅燒·calcination)의 잔해, 수계는 용해(溶解)가 넘쳐흐른 결과, 독림은 발효(醱酵)가 자생한 영역, 결빙은 응고(凝固)가 과잉 작동한 구간. 기관부는 기계 본체가 아직 남아있는 핵심부.

**12공정 (system_crafting.md v4.4) 중 자연 발생 6공정 + 기관부 핵심부**가 알파 범위에 존재한다. 알파에서는 5구역(소성·용해·발효·응고 + 기관부 핵심) + 결빙 변형이 있고, 나머지 자연 발생 공정(분리·증류·승화·소화·연화·고착) 및 인공 공정(투사·증식)은 후속 회차에서 확장 구역으로 예약. **자(磁) 원소 = 환경 자리 없음** — 자(磁)는 인공·가공(자성환·인-합체 어휘)에만 발현하며, 자연 던전 환경으로는 출현하지 않음.

유닛들이 특정 구역에 서식하는 이유는 "해당 연금술 공정과 친화성이 높아서" — 하지만 이것은 경향이지 제한이 아님. 어떤 인(印)의 유닛이든 어느 구역에서든 만날 수 있고, 단지 빈도에 차이가 있을 뿐. 실질적 게이팅은 구역이 아니라 **층 깊이(=유닛 레벨)**에 의해 이루어짐.

---

## 설계 원칙

- 구역은 **드랍 테이블 + 조우 풀의 구분 단위**. 환경 적응/속성 보정 같은 전투 메커니즘은 넣지 않음
- 같은 층에 여러 구역이 공존 → 탐사 시 어디로 갈지 선택
- 구역 이름은 연금술 공정(로어) + 지형(플레이어 직관)의 혼합
- 보스는 구역 전환점에 배치 (게이트키퍼 역할)
- 인(印) 제한 없음 — 모든 구역에서 모든 인의 유닛을 만날 수 있음. 구역은 빈도 경향만 제공
- 레벨이 실질적 진행 게이트. 깊은 층 = 높은 레벨 유닛

## 노드 맵 구조

### 데이터 모델

```json
{
  "id": "F1-B",
  "floor": 1,
  "zone": "석굴",
  "type": "combat",
  "connections": ["F1-A", "F1-C"],
  "encounter": ["가시 임프", "소금 슬라임"],
  "collect": null,
  "note": ""
}
```

**필드 정의**

- `id`: `F{층}-{알파벳}`. A는 항상 입구, 마지막 알파벳은 항상 출구
- `zone`: 해당 노드가 속한 구역. 입구/출구는 `null`
- `type`: 노드 유형 (아래 참조)
- `connections`: 이동 가능한 인접 노드 ID 목록 (양방향)
- `encounter`: 해당 노드에서 조우 가능한 유닛 목록 (전투/보스 노드만)
- `collect`: 채집 가능한 재료 (채집 노드만)

### 노드 유형

| 유형 | 설명 | 발생 | 안전 |
|------|------|------|------|
| entrance | 층 입구. 이전 층 출구에서 연결 | 층당 1개 고정 | O |
| exit | 층 출구. 다음 층 입구로 연결 | 층당 1개 고정 | O |
| combat | 전투 조우 발생 노드 | 층당 1~3개 | X |
| collect | 채집 포인트. 전투 없음 | 층당 1개 이상 | O |
| rest | 휴식 노드. HP/상태 회복, 편성 변경 가능 | 층당 0~1개 | O |
| chest | 상자/보물 노드. 1회성 보상 (재탐사 시 빈 노드) | 층당 0~1개 | O |
| event | 이벤트/대화 발생. 전투 없음 | 특정 층만 | O |
| boss | 보스 전투. 격파 시 다음 구간 해금 | 5/10/15층 | X |

> **안전 노드 원칙**: 모든 층에 최소 1개의 안전 노드(collect/rest/chest/event)를 배치. 입구/출구 제외. 플레이어가 층 내부에서 쉬거나 전투 없이 행동할 수 있는 지점이 항상 존재해야 함.

### 알파 맵 구성 원칙

- 층당 4~5노드. 알파에서는 소규모 유지
- 입구(A)→출구(마지막) 사이 최소 경로 = 노드 2~3개 통과
- 분기가 있으면 구역 선택지를 의미 (석굴 루트 vs 수계 루트)
- 보스 노드는 분기 없이 단일 경로 (회피 불가)
- **모든 층에 최소 1개 안전 노드** (collect/rest/chest/event). 층 내에서 비전투 행동 보장
- 보스 층(5/10/15)은 보스 직전에 휴식 or 상자 배치 — "준비할 기회"
- 채집 노드는 반복 방문 가능, 상자 노드는 1회성 (재방문 시 빈 노드)

## 보스 배치 (알파)

보스는 교섭 불가 적(슬라임)의 **변형**. 유닛 보스는 알파 이후 확장 콘텐츠로 예약 — 유닛을 보스로 내면 "교섭 가능한가?" 등 선택지가 늘어나므로, 알파에서는 순수 전투 관문으로 유지.

| 층 | 보스 | 기믹 | 역할 | 드랍 |
|----|------|------|------|------|
| 5층 | 거대 슬라임 | 없음. 순수 스탯전(HP↑, 물리 특화) | 첫 보스. 석굴→심부 해금 | 슬라임핵(대량) + 스프링 |
| 10층 | 변이 슬라임 | 기믹 1: 분열(HP 일정 이하→소형 2체) | 중반 관문. 위험/경계 해금 | 슬라임핵(대량) + 스프링 |
| 15층 | 폭주 슬라임 | 기믹 2: 분열 + 속성 변화(라운드마다 내성 순환) | 알파 최종. 16층+ 예고 | 슬라임핵(대량) + 스프링 |

**보스 드랍**: 슬라임핵(대량) + **스프링** (보스 고유 소재, 가칭). 스프링은 2티어 제작기(압축기) 제작에 필요한 핵심 재료.

**압축기 레시피**: 스프링 ×1 + 마법강철 ×1 → 압축기 (2티어 제작기)

> 스프링 = 보스 드랍, 마법강철 = 채집/가공 루트 (구체 경로 미정, 매직넘버)
> 보스 1체만 잡으면 스프링은 확보 → 마법강철 준비가 실질적 관문

| 드랍 방식 | 설명 | 테스트 필요 사항 |
|----------|------|----------------|
| 매회 확정 | 보스 잡을 때마다 1개 확정 드랍 | 반복 파밍 가능. 수량 조절이 밸런스 |
| 초회 한정 | 해당 보스 첫 격파 시에만 드랍. 이후 미드랍 | 보스 재도전 동기가 줄어듦 |
| 확률 드랍 | 매회 도전 시 일정 확률로 드랍 | 반복 동기↑, 운 의존도↑ |

> **알파의 큰 목표**: 보스 격파 → 스프링 획득 + 마법강철 확보 → **압축기 제작**. 여기까지가 알파 진행의 최종 도달점.

```
슬라임 파밍 → 슬라임핵 축적
      ↓
보스 도전 (5/10/15층)
      ↓
스프링 획득 + 마법강철 확보
      ↓
압축기 제작 (2티어 제작기) ← 알파 최종 목표
      ↓
Tier 2 재료 가공 가능 → 상위 연금술 루트 개방 (확장 콘텐츠)
```

> 보스 격파 → 마일스톤 → 새 구역/기능 해금 (system_exploration.md 참조)

## 적 유닛 (교섭 불가)

알파 범위에서 교섭 불가 적은 **슬라임 1종**만 존재. 나머지 전투 조우는 전부 교섭 가능한 유닛.

| 이름 | 출현 구역 | 출현 비율 | 확정 드랍 | 비고 |
|------|----------|----------|----------|------|
| 슬라임 | 전 구역 공통 | 전투 노드의 ~20% | 슬라임핵 (Tier 1, 확정+수량 보정) | 교섭 불가. 전투만 |

**드랍 구조**

- 유닛 전투에서도 슬라임핵·기타 채집 재료는 랜덤 드랍됨 (확률적)
- 슬라임 전투 = 슬라임핵 **확정** 드랍 + 수량 보정. 안정적 파밍 루트
- 슬라임핵은 Tier 1 기초 재료 중 하나. 연금술 기초 소재

**알파 진행 루프**

```
슬라임 반복 파밍 → 슬라임핵 축적
        ↓
보스 도전 (5/10/15층)
        ↓
보스 고유 소재 획득
        ↓
2티어 제작기 제작 (연금술 장비 업그레이드)
        ↓
Tier 2 재료 가공 가능 → 상위 연금술 루트 개방
```

> Tier 2 재료 도입 시 별도의 적 유닛 추가 예정 (알파 이후).
