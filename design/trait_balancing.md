## 1. 토호 노말 실측 앵커 (ERB 추출)

| 항목 | 토호 실측 |
|---|---|
| **능력(ABL: 감각·순종·기교 등)** | **0~5 레벨** |
| 능력 레벨업 비용(구슬) | **1 / 20 / 400 / 5000 / 20000** (레벨당 ×~20, 지수) |
| 비용 트레잇 보정 | 민감 ×0.8 · 둔감 ×1.2 · 음란 ×0.8 (효율 변동) |
| PALAM 커맨드 상승 | 50~3000/커맨드 → 구슬(JUEL) 변환 누적 |
| 호감도 | 0~**7500+** (큰 카운터) |
| **단계(함락/음란)** | **단일 바 아님 — 다중 조건 게이트** |
| 연모 조건(예) | 순종 lv3↑ + 봉사경험 200↑ + 호감도 1000↑ |
| 친애 조건 | 순종 lv5↑ + 애정경험 200↑ + 호감도 5000↑ |
| 음마/최심 조건 | 감각합 13↑ + 순종/욕망 lv5 + 기교·봉사 3↑ + 마조끼 3↑ … |

**핵심 결**: ① 능력 0~5 지수 비용(초반 빠름·후반 그라인드) ② 단계 = 능력+경험+호감 조합 게이트 ③ 깊이 순서 연모<친애·복종<낙인<예속/음마.

## 3. 진행 페이스 목표 (토호 노말 체감)

- **얕은 단계(연모/음란 도1~2)**: 빠르게 — 역가 저레벨 + 침염 2~5. 초반 몇 세션.
- **중간(복종/낙인 도2~3)**: 능력+경험+호감 누적 필요. 중반 그라인드 시작.
- **최심(예속/음마/재구성 도4)**: 깊은 그라인드(침염 14, 역가 고레벨). 토호 음마급.
- 지수 비용이 자연스러운 "초반 빠름·후반 묵직" 곡선 형성.

## 3.5 변용 도 = 경량 조합 게이트 (확정 2026-05-31)

토호 단계가 "능력+경험+호감 조합"이었던 결을 살리되 복잡도는 낮춤: **변용 도 상승 = 침염 임계(주) + 루트별 보조 조건 1개**.

| 루트 | 주(침염) | 보조 조건 (도 상승 동반) |
|---|---|---|
| 애착 | 연모 침염 2/5/9/14 | **호감도 단계** ↑ (도2 친밀 / 도3 신뢰 / 도4 유대) |
| 예속 | 복종 침염 | **역가.숙련** ↑ (도2 ≥2 / 도3 ≥3 / 도4 ≥4) |
| 탐닉 | 음란 침염 | **감도** ↑ (도2 ≥40 / 도3 ≥60 / 도4 ≥80) |
| 붕괴 | 공포+반감 침염 | 보조 없음 — 부정 스파이크 누적만으로 무너짐(가장 쉽게 미끄러짐) |

→ ① 한 축만 스팸 못 함(토호 정합) ② 루트별 빌드 텍스처(애착=관계·예속=조교·탐닉=감도) ③ 붕괴=나쁜 조교의 자연 귀결.

**ΔS 검증**: 절정당 +15 → 50 ≈ 4세션, 90 ≈ 8세션 (초반 빠름·후반 묵직 정합).

## 3.6 전투·조교 공식 수치 (확정 2026-05-31, 잠정값)

### 역가 비용곡선 (행위 누적 → 레벨)
| Lv | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| 증분 | 3 | 10 | 25 | 60 | 150 |
| 누적 | 3 | 13 | 38 | 98 | 248 |
×~2.5 확정. lvl3(38)=중반 의미 임계 · lvl5(248)=엔드.

### 전투
- 데미지 = **ATK × (ATK/(ATK+DEF)) × 배율** (비율식). 스킬 배율 ×0.8~1.5.
- 역가 전투 보정 = **레벨당 +5%** 배율·명중 (0~5 → 최대 +25%).
- 다리 [수]: 변용 종착 +10~20%(도3/도4) · S성향 +10% · 합성 시그니처 강함(광전사 +25%·불굴 DEF×2).
- 다리 [가]: 행동 가중 합=1.0 기준, 보정 **+0.2~0.3**.
- **敵対心(어그로)**: base by 대분류(인조 탱커형 높음). 도발 = +100%/4턴(blue_resort 앵커), 수호/위압 = +어그로. 타겟 가중 = 敵対心 × 성격보정(잔혹×2·신중×1.5·충의×2·호기심×1).

### 조교 쾌감 공식
- **절정 임계(세션) = 100 + 내성Lv×20**
- **쾌감/행위 = 도구출력(base 20~40) × (감도/100) × (1 + 숙련Lv×0.1)**
- 기준(감도100·숙련0·내성0): **~3~5 행위/절정**. 감도↓·내성↑이면 길어짐.
- 절정 → 지배 글로벌5 **+15**·보조 **+5**, 스파이크 시 침염 +1.

### 지식/직업 (역가형 층, 2026-05-31 채택)
- **적성(트레잇)** = 타고난 적합성 — **신체(BT)**: 손재주·체력(단조·약초·연금·요리·수영·낚시·조련) / **성격(PT)**: 기질·지능·예술(고귀→경영·사교·호기심→연구·예술감각·학구열→역사·魔物).
- **지식 레벨** = **0~5**(역가형, 행위로 레벨업, 비용곡선 역가와 동일 3/10/25/60/150). 가공(調合·錬金)·경영·탐사(魔物)·시설 게이팅.
- **적성 → 지식 레벨업 속도 +20%**(gainMult 1.2). "왜 이 캐릭이 연금 잘하나 = BT 연금적성 + PT 호기심 + 연금지식 레벨."
