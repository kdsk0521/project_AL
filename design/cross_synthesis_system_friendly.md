## 시스템 기준 (있는 것 / 없는 것)

### 있는 것 (v4.5/v1.5 갱신 — 2026-05-20)
- **전투**: ATK, DEF, SPD, AP(SPD 기반), 원소 방어 프로필(physical + **열/위/동/광/식/자**, 7슬롯), damageMultiplier, target(single|area), buffs[]
- **조교**: 6부위(mouth/chest/v/c/anal/skin) × 감도/경험치/마일스톤, 24개 행위(강도1~5), 글로벌 상태(연모/복종/음란/공포/반감), 해금 조건, 반복 페널티/전환 보너스
- **경제**: **16시설** (자원 수급 5: 우물/온실/낚시터/슬라임농장/수정나비양식장 + 자원 관리 2: 주방/식량저장고 + 기능 9: 가공소무색/조교공방/전서관리소/탐사경비/광장/유닛거처/훈련장/관측소/연구소), soulPower, **식량**, 재료, 유닛 배치, 시설 레벨 1~3, **대분류 적성 매칭**(정령3·야수3·인조3·요괴3·환상3·무색1)
- **탐사**: 노드 기반 이동, 층 시스템, 메인/자유 행동 이원 구조 (스태미나 폐기)
- **가공**: **6설비** — 가마(열+자-, T1)/분쇄기(위-식-, T1, 해체형)/압축기(위+동-, T1.5)/증류기(열-광+, T2)/**자성환(광-자+, T2.5)**/환류기(동+식+, T3), 재료 태그 변환, **12공정 1:1 매핑** 어휘

### 없는 것 (이걸 참조하는 효과는 변환 필요)
- ~~위치/넉백/밀치기~~ → 데미지/AP/area로 변환
- ~~체급/무게~~ → HP 비례로 변환
- ~~회피/명중률~~ → DEF/SPD 보정으로 변환
- ~~상태이상(독/마비/수면 as 독립 메커니즘)~~ → SPD/ATK/DEF 디버프로 변환 (향후 구현 시 활성화 주석)
- ~~은신/투명화~~ → 선제 확률/첫 라운드 AP 보정으로 변환
- ~~부활/되살리기~~ → 삭제
- ~~이동 속도~~ → SPD로 통합
- ~~크리티컬 히트~~ → damageMultiplier 보정으로 변환
- ~~골드~~ → soulPower/재료로 변환
- ~~마나~~ → 없음
- ~~질병 시스템~~ → 없음
- ~~방 크기/대열~~ → 없음

### 스케일다운 기준
- damageMultiplier 상한: 일반 T3 = 1.5배, T4 = 2.0배 (원본 500% 같은 건 삭제)
- 즉사 효과 → 저체력 보너스로 변환
- "무적" → 피격 경감 or DEF 대폭 상승
- "영구 동결/영구 0" → 비율 감소로 변환 (텐션 유지)
- 100% 반사 → 50% 이하로 제한

## C-1. 전투(CT) × 성격(PT)

### C-1-1. 잠복본능 (암습 + 소심) → CT T3
**원본**: 은신 선제공격 데미지 2배. 비전투 탐사 시 기습 회피 +30%
**문제**: 은신/회피 없음
**조정**: 탐사 전투 시 첫 라운드 AP +1. 첫 공격 damageMultiplier 1.8. 탐사 기습전투 회피는 → 기습당할 확률 감소(선제 확률 +25%)

### C-1-2. 공생결박 (결속사 + 의존) → AT T4
**원본**: 속박 조교 시 감도 공유(쌍방 쾌감 동기화). 속박 해제 시 의존도 +5
**조정**: ✅ 호환. 속박(discipline) 계열 조교 시 대상 쾌감 증가분의 30%가 조교자에게도 적용. 세션 종료 시 연모(love) +3

### C-1-3. 위압장 (포효 + 지배욕) → CT T3
**원본**: 전투 개시 시 적 행동속도 -20%. 배치 시 sound(저주파 울림) 태그
**조정**: ✅ 거의 호환. 전투 첫 라운드 적 전체 SPD -20% (AP 계산 반영). sound:"저주파 울림" 풍경 태그

### C-1-4. 자기희생 (재생 + 헌신) → CT T4
**원본**: 동행 유닛 피격 대신 흡수 후 재생. 호감도 비례 재생량 증가
**문제**: 대신 피격 메커니즘 없음
**조정**: 아군이 area 공격을 받을 때 자신의 HP에서 아군 피해의 30% 흡수. 라운드 종료 시 HP 재생(maxHp×0.05). 연모(love) 50↑ 시 재생량 2배

### C-1-5. 감언독 (독무 + 교활) → AT T3
**원본**: 조교 시 쾌감 누적량 비례 저항 감소 (쾌감 50당 저항 -10%)
**조정**: ✅ 호환. 조교 시 쾌감 50 누적마다 반감 상승량 -10% (최대 -50%)

### C-1-6. 분석안 (섬광참 + 호기심) → CT T3
**원본**: 전투 중 적 약점 1개 노출, 해당 부위 크리티컬 +30%
**문제**: 크리티컬 없음
**조정**: 전투 시작 시 적의 원소 방어 중 가장 낮은 속성 감지. 해당 속성으로 공격 시 damageMultiplier +0.3

### C-1-7. 동토의 고요 (냉기방사 + 냉정) → PT T4
**원본**: 배치 시 temperature(한랭)+visual(서리) 풍경 태그. 주변 유닛 반감 -3/턴, 욕정 상승 억제
**조정**: ✅ 호환. temperature:"한랭", visual:"서리" 풍경 태그. 배치 구역 유닛 반감 -2/월, 욕정 상승 속도 -30%

### C-1-8. 구속애착 (마비촉수 + 밀착) → AT T3
**원본**: 속박 행위 감도 보정 +50%. 속박 중 호감도 상승 가속
**조정**: ✅ 호환. discipline 계열 행위 시 해당 부위 감도 보정 ×1.5. 세션 중 연모(love) 상승 +3/회

### C-1-9. 한계돌파 (과부하 + 완고) → CT T4
**원본**: HP 20% 이하 시 전투력 +40%. 전투 종료 후 1턴 행동불가(반동)
**조정**: HP 20% 이하 시 ATK +40%. 해당 전투 종료 후 다음 전투 첫 라운드 AP -2 (반동)

### C-1-10. 변이적응 (위장 + 변덕) → BT T3
**원본**: 환경 속성저항 자동 전환. 탐사 시 지형 페널티 반감
**문제**: 환경 위장 없음
**조정**: 매 전투 라운드 시작 시 원소 방어 프로필을 적의 주 공격 속성에 맞춰 자동 조정(해당 속성 내성 +20%). 탐사 스태미나 소비 -25%

## 재료 오류 정정 (2건)
- 동결점액/부식방벽: 병합문서에서 "같은 재료" 합성 분기로 기재했으나 실제 재료 다름 (냉기방사+점액체 vs 용해액+점액체) → 독립 레시피로 복원
- 수원의 정령: Gemini가 수원지(시설)를 BT 재료로 사용 → 점액체(BT)로 교체

## 합성 분기 (1건)
- 용해체질 + 점액체 → 용해융합(Claude, AT) vs 점액 산란(Gemini, BT)
