## 네이밍 원칙 (J 클러스터에서 검증된 레지스터)

1. **관형구+명사** 꼴: 밤에 푸는 직녀 / 인과의 직공 / 업화의 인살 급.
2. **종족어 유지**: 슬라임·골렘·임프·거미·여우 등은 남김(UI에서 대분류 직감) — 관형구만 서사로.
3. **개념체는 예외**: 환상·합체전용급은 종족어 없이 순수 서사명 가능(결계석, 인 해월).
4. 이름이 미스터리 슬롯과 얽히면 장치 내장 가능(우데미아 방식).

판정: **개명** = 추천 / **옵션** = 취향 / **유지** = 현행이 이미 좋음.
