## 개요

경영 시스템은 **비어있는 미궁도시를 유닛으로 채워가는 도시 복원 시뮬레이션**.
아이템 판매는 없다. 수입원은 오직 **유닛 납품(전서 포인트)**이며,
조합한 물건은 유닛에게 주거나 탐사에 쓰는 **상호작용 수단**이다.

```
[탐사] → 재료 수집 + 유닛 획득
       ↓
[조합/가공] → 장비, 소비재, 도구 제작
       ↓
[육성/조교] → 유닛 가치 상승
       ↓
[선택] → 유닛을 전서에 납품 (영혼력 획득)
       → 유닛을 도시에 배치 (시설 가동, 장기 투자)
       → 유닛을 탐사/합체에 사용 (전력 유지)
       ↓
[도시 성장] → 기초 재료 자동 수급, 새 기능 해금, 아이템으로 유닛과 상호작용
       ↓
[공방 확장] → 더 깊은 던전, 더 넓은 제작 범위
       ...순환
```

---

## 설계 원칙

> **"경영의 핵심은 유닛을 어디에 쓸 것인가의 판단이다."**

- **아이템 판매 없음**. 조합한 물건은 팔지 않고 사용한다
- 수입원은 오직 **유닛 납품 = 전서 포인트(영혼력)**
- 유닛의 가치는 **합체 소재 가치 + 조교/육성 결과**로 결정
- 조합물은 유닛에게 주는 **투자**이자 탐사의 **소비재**
- NPC 제로: 도시의 모든 기능은 **배치된 유닛이 운영**
- 경영의 재미 = "누구를 키워서, 어디에 쓸 것인가"

## 통화: 전서 포인트 (영혼력)

### 개념

공방을 가동하고 도시를 운영하려면 **영혼력**이 필요하다.
유닛을 전서에 납품하면 해당 유닛의 영혼력이 전서 포인트로 전환된다.

- 미궁도시의 공방은 영혼력으로 구동되는 설비 (로어와 연결)
- 왜 영혼력인지, 왜 도시가 비어있는지는 세계관/로어에서 다룸

### 영혼력 획득

유일한 정규 수입원 = **유닛 전서 납품**.

```
영혼력 = 기본 레벨값 + 트레잇 가산 + 육성 이력 보너스 + 인(印) 보정
```

#### 인(印) 보정의 구성 (v1.1 추가 — system_unit_sigil.md 참조)

**1. 인 기본 배율 (고정, 소폭)**
- 대부분의 정인: ×1.0 (보정 없음)
- 특수인 (염/수은/유황): ×1.15~1.2 (희소성 반영)

**2. 월별 수요 보정 (달력 연동)**
- 매달 2~3개 인(印)의 수요가 상승
- 해당 인 납품 시 영혼력 추가 보정 (예: ×1.2)
- 플레이어가 "이번 달에 뭘 납품할까" 판단하는 근거
- 키워둔 유닛이 이번 달에 비싸면 "팔까?" = 감정적 판단 포인트

**3. 인-트레잇 일치 보너스**
- 유닛의 인에 어울리는 트레잇 → 추가 보정
  - 백양 인 + 전투 특화 트레잇 = "순수한 하소체" → 보너스
  - 백양 인 + 성인 특화 트레잇 = "변형된 하소체" → 보너스 없음
- 인에 맞게 키우면 납품가 상승
- 인을 거슬러 키우면 납품가는 낮지만 합체 소재로 독특한 가치

**4. 인-원소 어휘 보정 (v1.4 신규 — 자(磁) 포함)**
- 6원소 어휘(열·위·광·동·식·자) 트레잇은 자유 발현 — 인 시스템 변수 격상 X
- 자(磁) 어휘 트레잇(매혹·이끌림·자기력)을 가진 유닛 = 호감도 도구·교류 시설 방향에서 가치 상승 (어휘 차원의 결)
- 인-원소 결합은 **흔적 정도의 영혼력 보정**으로만 작동 (정밀 규칙은 미정)

> 인 보정 구체 수치는 미확정.

- 잘 키운 유닛일수록 영혼력이 높음
- 합체를 거친 유닛은 소재 유닛의 이력이 반영되어 더 높을 수 있음
- 호감도가 높은 유닛을 납품하면? → 이머전트 이벤트 (감정적 비용)
- **"이 유닛을 납품할 것인가, 남길 것인가"가 매 순간의 판단** (ERA식)

#### 납품 결정 시 텍스트 호흡 (v1.4 — 신체 → 객체화 패턴)

납품 결정은 **신체 → 객체화** 교차 모먼트의 대표 자리. 일상 메뉴는 가벼움(ERA식)이지만, 호감도가 일정 이상인 유닛을 납품 결정하는 순간은 응축된 텍스트 한 단락이 발생한다.

| 호감도 구간 | 텍스트 호흡 |
|------------|------------|
| 낮음 | 가벼움 (행위→수치→짧은 플레이버) |
| 중간 | 짧은 응축 한 줄 (가격 + 흔적 묘사) |
| 높음 | 응축 한 단락 (전수서 나레이터 본격 등장) |

> 단계별 톤 예시·메시지 풀은 후속 회차 `tone_guide.md`(가칭)에서 정밀화.

### 영혼력 지출

| 지출 유형 | 설명 | 시작 시점 |
|----------|------|----------|
| 공방 유지비 | 설비 규모에 비례하는 고정 지출 | **Tier 1.5** (압축기 건설 시점부터) |

- **이후**: 설비/도시가 커질수록 유지비 증가 → 계속 유닛을 키워서 납품해야 유지

## 도시 시스템: 유닛 배치와 시설

### 핵심: 비어있는 미궁도시를 유닛으로 채운다

플레이어는 미궁도시의 시설에 유닛을 배치하여 도시를 복원한다.
배치된 유닛이 시설을 운영하고, 시설이 게임 기능을 제공한다.

- NPC는 없다. **배치된 유닛이 곧 NPC 역할**
- 도시 시설은 전서 포인트로 건설/확장
- **대분류는 시설 적성·기본 보너스(메인)를 결정 — 권장이지 강제 아님** (요괴=상업/교류, 정령=자원/채집, 인조=공방/제작, 야수=경비/탐사, 환상=연구/특수). 자유 배치 OK (적성 외 배치 시 보너스 작음·페널티 없음, v1.4 정정)
- **개별 트레잇이 해당 시설에서의 추가 보너스를 결정** — 트레잇 카테고리형 아님 (잠정 v1.4. 트레잇이 4 덩어리만 있어 카테고리형 보너스 부적절)
- → 대분류 = "어디에 잘 어울리나(권장·기본 보너스 메인)", 개별 트레잇 = "추가로 얼마나 보너스 붙나"
- 시설 유형-대분류 매칭은 초안. 시설 체계 확정 후 조정 필요
- **운영 가벼움**: 도시 시설 운영 텍스트 톤 = ERA식 짧고 즉각, 일상 시스템 (메시지 양 적음)

### 도시 시설 16종 (v1.5 H 회차 — 디자인 차원 확정, 밸런스 후속)

**대분류 분포 균형**: 정령 3 / 야수 3 / 인조 3 / 요괴 3 / 환상 3 / **무색 1 (가공소 예외)** = 5 대분류 각 3종 균등.

#### 핵심 시설 정체성 풀이 (v1.5)

- **조교 공방** (인조): 자(磁) 정체성의 도시 발현. 자성환(T2.5) 가공 + 호감도 도구 + 직설 성인 용품 제작 + 조교 보너스. 어휘 차원의 호감도 연결 + 시설 차원의 조교 제작 한 자리에 응축
- **광장** (요괴): 매매 행위 아님. **유닛-아이템-호감도-영혼력 교환** — 시장에 배치된 유닛에게 아이템 건넴 → 호감도·다른 아이템 답례 / 영혼력 지불 → 호감도 획득. NPC 제로 원칙의 거래
- **연구소** (환상): 1대1 조합 제약 깸. 미지 결과물 = 단순 폐기·재활용 X — **가공 정제(기존) OR 연구소 분석(신규)** 두 경로. 신규 경로 = 제작 외의 특수 아이템 체계 발생 자리
- **관측소** (환상): UI 확장 + 인 보너스 적용. 월별 활성 인·달력 이벤트. 자(磁) 인 활성화 추적
- **가공소 무색** (예외): 적성 시스템 외. 기초 가공 = 모두의 공통 활동. 모든 대분류 동등 기본 보너스

### 도시 배치와 상호작용

배치된 유닛에게 **아이템을 줄 수 있다** — 이것이 조합 결과물의 주요 사용처.

| 아이템 유형 | 효과 |
|------------|------|
| 장비 | 유닛 성능 강화 (탐사 유닛 / 도시 배치 유닛 공통) |
| 물약/소비재 | 탐사 소비재 / 도시 유닛 회복·강화 |
| 음식 | 탐사 소비재 / 도시 유닛 선물 (호감도) |
| 술 | 유닛 교섭/호감도 도구. 관계 이벤트 트리거 |
| 조교 전용 아이템 | 조교 행위 해금 (채찍→채찍질 등). 도구 빌드판(로터/교본)은 별도 시스템 (system_tool_upgrade.md) |

- 유닛에게 좋은 아이템을 주면 → 시설 효율 상승, 호감도 상승, 이벤트 발생
- 유닛이 답례로 재료/복합태그 물품/정보를 돌려줄 수 있음
- **물건을 파는 게 아니라, 물건이 유닛과의 상호작용 수단이 되는 구조**

### 도시 유닛의 요청 (주문서 대체)

기존 "손님 주문" 시스템은 폐지. 대신 **도시에 배치된 유닛이 요청을 발생**시킨다.

- 배치 유닛이 특정 아이템을 요청 (필요 태그/형태 조건)
- 조건 충족 아이템을 주면 보상 (시설 효율 증가, 호감도, 특수 보상)
- 요청 내용은 시설 유형, 유닛 트레잇, 시즌에 따라 달라짐
- → 기존 "손님이 뭘 원하는가"의 판단이 "내 유닛이 뭘 필요로 하는가"로 전환

## 설비/시설 시스템

경영의 성장감은 **공방 설비 확장 + 도시 시설 확장**의 이중 축.

### 공방 설비 (가공/제작용)

| 설비 유형 | 역할 | 예시 |
|----------|------|------|
| 가공 설비 | 가공 방식 해금 / 가공 범위 확장 | 가마, 분쇄기, 압축기 |
| 제작 설비 | 조합 가능 카테고리/등급 확장 | 기초 작업대 → 고급 작업대 |
| 저장 설비 | 인벤토리/창고 용량 | 상자 → 창고 → 대형 창고 |

### 설비 업그레이드 구조

- 설비는 **조합으로 제작** (제작 도구 카테고리)
- 설비 등급이 올라가면:
  - 새로운 가공 경로 개방
  - 상위 tier 아이템 제작 가능
- 설비 업그레이드 자체가 **마일스톤 트리거**가 될 수 있음
- **Tier 1.5 이상 설비부터 공방 유지비(영혼력) 발생**

## 자금(영혼력) 순환

### 수입원

- **유닛 전서 납품**: 유일한 정규 수입. 유닛 가치에 비례
- **도시 유닛 답례**: 비정기, 소량. 재료/물품 형태 (영혼력은 아님)
- **특수 거래**: 마일스톤/노드 분기에서 발생하는 특별 거래 기회

### 지출처

#### 고정 지출 (Tier 1.5부터)

- **공방 유지비**: 가동 중인 설비 규모에 비례. 영혼력으로 월말 차감
  - 설비를 늘릴수록 유지비 증가 → "지금 확장할 여유가 있나?" 판단
  - **Tier 1 초반에는 유지비 없음** — 학습 구간 보호

#### 선택 지출

- **도시 시설 건설**: 새 시설 설치 (영혼력)
- **전서 유닛 구매**: 유닛 재구매 (영혼력)
- **설비 제작/업그레이드**: 재료 + 영혼력
- **탐사 비용**: 소비 아이템, 장비 소모 (재료 비용, 영혼력 아님)

### 자금 흐름의 긴장감

- Tier 1.5 이후 **고정 지출이 존재하므로 가만히 있으면 영혼력이 줄어든다**
- 유닛을 키워서 납품해야 유지 → "누구를 키워서 팔 것인가"
- 도시에 배치하면 장기 투자지만 당장 영혼력은 안 들어옴
- 합체에 쓰면 더 좋은 유닛이 나오지만 소재가 소멸
- **4방향 선택의 긴장**: 납품(수입) vs 배치(투자) vs 합체(강화) vs 탐사(전력)
- 이 긴장감이 경영 시스템의 재미이자 다른 시스템과의 간섭 지점

## 식량 압박 시스템 (v1.5 H 회차 신규) ★

자연 압박 두 축의 하나. 영혼력(돈)과 짝을 이룬다.

### 시스템 작동 흐름

```
재료 (약초·독물고기·촉매초 등)
     ↓ [주방] 가공 자동
   식량
     ↓ [식량 저장고] 보관 (부패 방지)
     ↓
도시 배치 유닛 월말 자동 소비 (유닛 수 비례)
     ↓
부족 시:
  단기 — 호감도↓·시설 효율↓
  장기 — 이탈·반란·0-X 배드 엔딩(도시 붕괴) 가능
또는 영혼력 보충 (높은 비용)
```

### 핵심 디자인 요소

| 요소 | 정의 |
|---|---|
| **소비 주체** | 도시 배치 유닛 (월말 자동, 유닛 수 비례) |
| **생산 주체** | 주방 (재료 → 식량 자동 변환). 시설 등급으로 효율 |
| **저장** | 식량 저장고 (보관량·부패 방지) |
| **시작 시점** | **압축기(T1.5)부터** — 영혼력 유지비와 동일. 자연 동시 압박 시작 |
| **압박 강도** | 시설·유닛 늘어날수록 식량 압박 증가 |
| **부족 결과** | 단기: 호감도↓·시설 효율↓ / 장기: 이탈·반란·**0-X 배드 엔딩** 가능 |
| **보충 수단** | 영혼력 지불 (높은 비용) |

### 식량 종류 (기존 레시피 활용, system_crafting.md)

- 기초 식량 (스프) — 식재료(독물고기→가마) + 물
- 회복 스프 — 식재료 + 약초
- 보존식량 — 식재료 + 보존허브 (오래감)
- 상태이상 해제 식량 — 식재료 + 억제초

### ERA 결 정합

- **영혼력**(돈) + **식량**(생계) 두 축 압박
- 영혼력 위주 플레이 vs 식량 위주 플레이의 다른 전략 가능
- 두 자원 균형 게임 = 게임 진행감의 핵심

### 게임 진행감 두 축

- **초반 (T1)**: 압박 없음. 시스템 학습. 자유 진행
- **압축기 도달 (T1.5)**: 두 축 압박 시작. 유지 압력
- **도시 시설 확장**: 압박 증가. 자원 균형 게임
- **모든 설비 완공 (1-X 첫 엔딩)**: 자원 흐름 안정 = 게임 기본 엔딩

### 미정 / 후속 회차 (밸런스 영역 — 계산 LLM)

- 식량 소비량·생산량·부족 임계점 구체 수치
- 영혼력 보충 비용 공식
- 시설별 식량 생산·저장 효율 보너스
- 부패 진행 곡선·식량 저장고 등급별 보관량

## 엔딩 구조 (v1.5 F 회차 흡수)

### 1-X 첫 엔딩 = 도시 모든 설비 완공 ★ (게임 기본 엔딩)

|---|---|---|

## 유닛의 4가지 용도 (경영 관점)

하나의 유닛을 두고 항상 4방향의 선택이 존재한다.

| 용도 | 효과 | 대가 | 인(印)과의 관계 |
|------|------|------|---------------|
| **전서 납품** | 영혼력(전서 포인트) 획득 | 유닛 소멸 | 인-트레잇 일치 → 납품가↑, 월별 활성 인 → 수요 보정 |
| **도시 배치** | 시설 운영, 기초 재료 수급, 도시 성장 | 탐사/합체에 못 씀 | 대분류→시설 적성·기본 보너스(권장, 강제 X), **개별 트레잇→추가 보너스 (카테고리형 X, 잠정 v1.4)** |
| **합체 소재** | 더 강한/특수한 유닛 생산 | 소재 유닛 2체 소멸 | 인이 합체 테이블 키, 특수인은 계승 특수 효과 |
| **탐사/전투** | 던전 공략, 재료 확보 | 부상 리스크, 시간 투자 | 인에 맞는 육성 → 빠르게 강해짐 |

- 잘 키운 유닛일수록 모든 방향에서 가치가 높음 → 선택이 어려워짐
- 호감도가 높은 유닛을 납품/합체하면 → 이머전트 이벤트 (감정적 판단)
- **"이 유닛을 어디에 쓸 것인가"가 게임 전체를 관통하는 핵심 판단**

## 시간 구조

### 기본 단위: 월 (프린세스 메이커 참고)

게임의 시간은 **월 단위**로 흐른다.
한 달 안에서 플레이어는 매일 **메인 행동 1개**를 선택하고, **자유 행동**은 제한 없이 수행한다.

```
[월 시작]
  - 도시 유닛 요청 갱신
  - 달력 이벤트 확인 (고정 이벤트, 시즌 이벤트)
  - 영혼력/재고 상태 확인
       ↓
[매일 — 메인/자유 이원 구조]
  - 메인 행동 1개 선택 (하루 통째로 소비):
      탐사 → 던전 진입, 채집/전투/조우
      교류 → 유닛 조교/교류/육성
  - 자유 행동 (제한 없음, 메인 행동 전후 자유):
      조합/가공, 도시 관리/배치 변경, 전서 열람/구매, 설비 제작, 도구 관리
  - 메인 행동 완료 or 하루 넘기기 → 하루 종료
       ↓
[월 말 (한 달치 일수 경과)]
  - 고정 지출 차감 (공방 유지비 — Tier 1.5 이후)
  - 도시 시설 산출물 정산 (자동 수급 재료 획득)
  - 이벤트 판정 (이머전트 이벤트, 마일스톤 체크)
       ↓
[다음 월 시작] → 반복
```

### 행동 구조: 메인/자유 이원 구조 (v0.7 — 스태미나 폐기)

~~스태미나 수치 방식 폐기~~. 소모량 차이가 크면 제약이 느슨해져서 "오늘 뭐 하지?"의 선택 무게가 사라짐.

**메인 행동** = 유닛과 시간을 보내는 것. 하루 1개.
- 탐사: 던전 진입. 채집/전투/조우
- 교류: 유닛 조교/교류/육성 (ERA식)

**자유 행동** = 작업대 앞 작업. 제한 없음.
- 조합/가공
- 도시 관리/배치 변경
- 전서 열람/구매
- 설비 제작
- 도구 관리

- **"오늘 뭐 하지?"가 매일 의미 있는 선택**: 탐사 vs 교류의 트레이드오프가 핵심
- 경영 압박과 연동: 하루 = 1일 소비 → 월말 유지비 접근. 시간이 곧 비용
- 기절 유닛 회복이 하루 단위 → 메인 행동 선택과 자연스럽게 연동 ("오늘 탐사 갈 수 있나?")

### 달력 시스템

월 단위 시간 구조 위에 **달력**이 존재한다.
1년 = 12개월, 1개월 = 30일 (확정)

#### 고정 이벤트 (시즌 이벤트)

- **시즌별 도시 유닛 요청 변화**: 시기에 따라 유닛이 원하는 아이템이 달라짐
- **축제/행사**: 특수 이벤트, 한정 거래 기회, 보너스 보상
- **계절 던전**: 특정 시기에만 열리는 던전 구역이나 채집 가능 재료
- **연중 이벤트**: 기념일, 유닛 관련 이벤트 (생일 등 — 관계 시스템 연결)

#### 달력과 인(印) 연동 (v1.1 추가)

매달 **활성 인 2~3개**가 순환. 1:1 고정 대응이 아닌 느슨한 보정.

- 해당 인 유닛의 조교 반응 전체에 소폭 보정 (예: 전 항목 +0.1x)
- 해당 인 유닛 납품 시 영혼력 추가 보정
- 해당 인의 유닛이 던전에서 조우 확률 상승 (?)

> 월별 활성 인 순환 테이블, 구체 효과/수치는 미확정.
> 달력×인 연동 상세는 → system_unit_sigil.md 참조

#### 달력과 다른 시스템의 연결

```
[달력 → 경영] 시즌별 유닛 요청 변화 → "이번 달엔 뭘 만들어줘야 하나" 판단
[달력 → 경영] 월별 활성 인(印) → "이번 달에 비싸게 팔 수 있는 유닛은?" 판단
[달력 → 탐사] 계절 한정 재료/던전 → "이 시기에만 갈 수 있는 곳" 탐사 동기
[달력 → 관계] 유닛 이벤트 → 호감도 상승 기회
[달력 → 이머전트] 시즌 조건이 이벤트 트리거에 추가됨
```

## 경영과 다른 시스템의 간섭

```
[경영 → 탐사]
  - 부족한 재료(약초/철광석/마력석)가 탐사 목표를 결정
  - 탐사 장비/소비재는 조합으로 제작
  - 도시 시설이 기초 재료를 대체하면 → 더 깊은 층에 집중 가능

[경영 → 조합]
  - 설비 등급이 제작 가능 범위를 결정
  - 도시 유닛 요청이 "뭘 만들까"의 방향을 제시
  - 조합물 = 유닛에게 주는 투자 수단

[경영 → 유닛/관계]
  - 유닛 납품 = 영혼력 획득 + 관계 변동 (이머전트 이벤트)
  - 도시 배치 = 유닛의 새로운 역할 부여
  - 아이템 선물 = 호감도/효율 상승
  - 영혼력 부족 → 유닛 납품 압박 → 감정적 판단

[경영 ← 탐사]
  - 던전에서 얻은 재료가 조합의 원료
  - 던전에서 획득한 유닛이 도시/납품/합체 자원
  - 탐사 실패(부상/소실)가 경영에 타격

[경영 ← 유닛/관계]
  - 유닛 트레잇이 도시 시설 효율에 영향
  - 유닛 이탈 시 도시 기능/전력 감소
  - 배치 유닛의 답례가 보조 수입
```
