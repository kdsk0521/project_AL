## 구조 (확정 방향 2026-05-31)

- **이산 트레잇 base**: 성격 = 개별 트레잇. **합성이 주체**이므로 이산 유지(현행 PT 50 + 합성 레시피 정합).
- **대립 성격 = 모순쌍 등록**: crafting/엘릭서의 **모순쌍 메커니즘 재사용**(새 양극축 시스템 X). 소심↔대담, 솔직↔츤데레 식.
- **모순쌍 공존 = 합성 발동 조건**: 보통 한 극만 보유. 둘 다 가지면 → 합성 발동. **결과 방향은 레시피가 정함**:
  - **통합형**: 모순 끌어안아 상위 성격 트레잇 (음양합일·메르쿠리우스 결, 긍정).
  - **분열형**: 모순에 찢겨 불안정 → **변용 붕괴 트리거** (부정/루트).
  - 조건(다른 트레잇·변용 도·맥락)이 방향 가를 수도.
- **공존 획득 경로**: 합체(상속 섞임)·변용(상태가 반대 성격 발현)·이벤트 — 일부러 노리는 귀한 자리.
- **메타 정합**: 마그눔 모순→통합/와해, 메르쿠리우스 음양합일, 9-Ω 분리↔통합. *모순 품은 캐릭터*가 테마적 의미.

## 효과 영역 (성격 = 가장 교차적)

| 영역 | 작동 |
|---|---|
| 관계 | 호감도 반응·관계 이벤트 트리거 |
| 조교 (§7 피조교 성격) | 글로벌5 dynamics·변용 진행 속도 |
| 전투 (다리) | 일부 성격 → AI 행동/스탯 (겁없음→공격성, 경계심→회피) — 자동전투 패시브 |
| 생활 | 도시 배치·일상 효율 (근면/게으름·청결 등) |
| 이벤트 | 트리거 가중치 |

> 카테고리 역할(슬롯 상한·습득결·가독성)은 유지, 효과는 안 가둠(교차 영향).

## 대립 모순쌍 (예시 — 수확 블렌드, 우마 0~22 + 토호)

| 모순쌍(축) | 극 A | 극 B | 공존 창발(예, 잠정) |
|---|---|---|---|
| 담력 | 소심 | 대담(겁없음) | 통합→위기감지 / 분열→공황 |
| 솔직함 | 솔직 | 츤데레 | 통합→일관 / (츤데레 자체가 합성 결과 가능) |
| 전망 | 낙관 | 비관 | 통합→평정 / 분열→정서 불안 |
| 감정 | 감성적 | 둔감 | 통합→감정 제어 / 분열→감정 해리 |
| 자기상 | 자신감 | 자격지심 | 통합→자긍 / 분열→자기파괴 |
| 사교 | 사교적 | 내향 | 통합→처세 / — |
| 근면 | 근면 | 게으름 | (생활 효율 직결) |
| 지향 | 호기심 | 보수적 | 호기심→습득 빠름 / 보수→변용 느림 |

> 극 = 각각 이산 트레잇. 쌍 = 모순쌍 등록. 공존 시 합성 레시피 발동.

## sub-그룹 (era taxonomy 차용)

- **기본 기질** (토호 10~19, 우마 0~9): 담력·전망·감정·자기상.
- **사교** (eraAS 130~149, 우마 11): 사교태도·처세.
- **마음가짐** (토호 30~39): 억압/해방·정조·저항.
- **성관련** (eraAS 150~176) → **§7 피조교 성격**(소악마·즉각타락·경계심·부끄럼·호기심 등).
- **생활** (우마 12~17): 청결·시간·식습관·근면·소비·신체.
