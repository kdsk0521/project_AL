# 변용(變容) 4루트 — 칸별 트레잇 (콘텐츠 v0.1)

> 작성: 2026-05-31
> 정본 골격: system_trait_synthesis.md v0.4 (침염→변용), trait_era_transform.md C절. 수확: trait_adult_harvest.md.
> 모델: eraAS 대인소질 도(度) 카운터(1→2→3) + 토호 사다리 블렌드.
> 성격: **콘텐츠 초안**. 침염 임계 수치·印색 이름은 잠정. 칸 이름 = 작업명(한자), 印·색 번역은 후속 패스.

---

## 공통 규칙 (C절 정합)

- **루트 = 도(度) 카운터**: 지배 침염 누적 → 도 1→2→3→4 상승. 칸마다 **시그니처 트레잇** 영구 획득.
- **칸 수 = 루트당 4칸** (레티어스 확정).
- **단방향**: 도는 안 내려감.
- **수렴 잠금 = 도 2** (레티어스 확정): 한 루트가 도 2 도달 시 타 루트 도 상승 잠금. → 도 1은 여러 루트 맛보기 가능, **도 2에서 운명 결정**.
- **길항 = 루트 경쟁**: 침염 종류 섞이면 수렴 둔화. 침염 관리 = 운명 조타.
- **종착(도 4) = 유닛 엔딩 7-X**. (각성 9-C는 변용과 별개 라인 = 인 활성+호감도 사이클. 루트에 일괄로 묶지 않음 — 각성 연결은 유닛별 authored.)
- **다리(교차) = 자동전투 패시브 보정만** ★: 전투가 **자동전투 시스템**이므로 다리 트레잇은 *패시브 스탯/행동 가중치/상태 저항* 같은 것만 의미 있음. **지시 강화·명령 즉응 류 폐기**(자동전투엔 수동 지시 없음).
- 침염 임계: 각 칸 X1<X2<X3<X4 (수치 잠정).

## 수치 매핑 (v0.1, 잠정 — 레티어스 조정용 참고 곡선)

**글로벌5 스케일 = 0~100** (정식화 2026-05-31. 합성 레시피 "복종 50·음란 90" 참조와 정합. → system_unit_sigil 글로벌 상태 섹션에 0~100 명시 필요).

### 침염 스탬프 = 절정(climax) 앵커 ★ (포화 회피)
- **스탬프 조건**: **절정 도달한 세션마다**, 그 세션에서 *가장 강하게 오른 글로벌5 종류*로 **침염 +1**.
  - 0~100 캡 + "세션당 +ΔS 상승" 방식은 상태 포화 시 침염이 멈춤 → **절정 기준으로 디커플링**(절정은 세션마다 새로 발생).
- **보조 조건(절정 없는 세션)**: 절정 없이도 한 종류가 ≥ **ΔS=+15**(잠정) 오르면 침염 +1.
- 침염은 종류별 **누적·영구**. (휘기=시간 흐름의 트레잇 후보와 별개 트랙 — 침염은 한 세션의 도장.)
- 도4(침염 14) ≈ 한 종류로 치우친 깊은 절정 세션 ~14회 = 길고 의도적인 육성.

### 루트 ↔ 침염 종류
| 루트 | 지배 침염 |
|---|---|
| 애착 | 연모 |
| 예속 | 복종 |
| 탐닉 | 음란 |
| 붕괴 | 공포 + 반감 (**합산**) |

> 글로벌5(연모·복종·음란·공포·반감) → 4루트: 부정 둘(공포·반감)이 붕괴로 합쳐져 5→4 매핑 완성.

### 도 상승 = 경량 조합 게이트 (확정 2026-05-31, 토호 앵커)
침염(주) + **루트별 보조 조건 1개** (variationRoutes.csv coReq 컬럼):
- 애착: + **호감도 단계** (도2 친밀/도3 신뢰/도4 유대) · 예속: + **역가.숙련** (도2≥2/3≥3/4≥4) · 탐닉: + **감도** (도2≥40/3≥60/4≥80) · 붕괴: 보조 없음(가장 쉽게 미끄러짐).
→ 한 축 스팸 방지 + 루트별 빌드 텍스처. 상세: trait_balancing.md §3.5.

### 도 임계 (지배 침염 누적, 누적 곡선)
| 도 | 침염 누적 | 비고 |
|---|---|---|
| 1 | **2** | 첫 칸 |
| 2 | **5** | ★수렴 잠금 발동 |
| 3 | **9** | |
| 4 | **14** | 종착(7-X 엔딩) |

### 지배·길항 (루트 경쟁)
- **지배** = 침염 카운트 최다 종류의 루트가 진행.
- **길항**: 2위 종류 침염이 1위의 **70% 이상**이면 도 상승 보류(섞임) → 한쪽으로 몰아야 진행.
- **수렴 잠금**: 도 2(침염 5) 도달 시 타 루트 침염은 계속 쌓이되 **도 상승만 잠금**(기록은 유지).
- **붕괴 특례**: 공포+반감 합산. 분산되면 균열(도1)에 머무름 → 집중 붕괴 조교 필요.

> 조정 레버: ΔS(스파이크 난이도), 도 임계 곡선(2/5/9/14), 길항 비율(70%). 전부 잠정 → **통합 밸런싱 패스에서 다른 시스템 수치와 함께 일괄 결정**(틀 먼저, 수치는 전반 감각 잡힌 뒤 한꺼번에).
