## 개요

트레잇 합성은 유닛이 보유한 트레잇들을 조합하여 상위 트레잇을 생성하는 시스템.
조합 시스템(아이템)의 "태그 합산 → 특수 레시피 우선" 문법과 동일한 패턴을 따른다.

합성은 **단일 유닛 육성 중**에도, **합체 시 트레잇 계승 판정**에서도 발동할 수 있다.

> **K 회차 정합 (2026-05-21)**: 트레잇 획득 자체(레벨업·경험 → 트레잇 습득)는 K 회차의 **두 트랙 분리 + 행위 sub 점수 + 후보 풀** 시스템이 담당. 본 문서의 합성 시스템은 그 위에 얹힌 **이미 보유한 트레잇들 → 상위 트레잇 변환** 트랙. 두 트랙 별개로 작동.

## 층 모델 (v0.4 — 5층 + 침염) ★ 핵심

> **표기 규약**: **새 연금술명(한자, 익숙한 말)** — 예: 침염(浸染, 각인). 명칭은 전부 **잠정**.
> 용어 점유 사전: `텍스트기반의 게임만들기/연금술_용어은행.md` · 설계 경위: `trait_era_transform.md` 7·8절.

유닛 = "연성 중인 물질". 한 행위가 동시에 여러 층에 산출을 남긴다 (에라 4층 분리의 확장).

| 층 | 결 | 휘발 | 역할 | 기존 이름 |
|---|---|---|---|---|
| 경험치 | 固 | 영구 | HP | 누적 경험치 |
| 휘기(揮氣) | 揮 | 소비 | 트레잇 후보 진입 (시간 누적) | sub 점수 |
| 트레잇 | 魂 | 영구 | 질적 정체성·**영역 교차** | 트레잇 |
| 역가(力價) | 力 | 영구 | 행위 숙련·**영역 고정** (Abl) | (신설) |
| 침염(浸染) | 固 | 영구 | 한 순간 각인 → 변용 사다리 엔진 | 각인(Mark) |

### 한 행위 → 三 산출
한 번의 행위가 동시에 ① 경험치(固→HP) ② 휘기(揮→트레잇 후보) ③ 역가(力→그 행위 숙련) 누적. 분담 명확, 겹침 없음.

### 트레잇(魂) vs 역가(力) — 교차/고정 비대칭 ★
- **트레잇 = 영역 교차**: 조교/훈련으로 얻은 트레잇이 전투에 영향, 전투로 얻은 트레잇이 조교에 영향 (선순환). 카테고리(전투/성격/성인/신체)는 ①습득 결 ②UI 가독성 ③**카테고리별 슬롯 상한**(총량 억제)용 — **효과 영역은 안 가둠**.
- **역가 = 영역 고정**: 전투 역가는 싸워서, 조교 역가는 조교해서만 오름.
- **다리(bridge) 트레잇** = 전투+조교 효과 필드 동시 보유. *획득 카테고리 슬롯 1칸*만 먹으며 2영역 효과 → 귀한 자리. 밸런스 위해 **일부만 지정**.

### 역가(力價) 두 얼굴
- **전투**: **속성별(물리+6원소=7) 공격·방어 숙련** → 행동 배율·명중·회피 보정. (base 공/방/속도 = 장비 유지, 역가는 보정만. 무기군 아님)
- **조교**: 우마 床技에서 **받는 쪽만 유닛 역가** — 숙련(熟, 받는 효율) / 내성(耐, 절정 견딤). **기술(技, 주는 효과) = 도구(가공 제작)가 패시브 제공** (AL은 조교자 누적 능력치 없음 → 도구가 대체).
- 역할 분담: 트레잇(魂)=*어떤 행동이 열리나* / 역가(力)=*얼마나 잘하나*.

### 침염(浸染, 각인) 층
- **트리거**: 한 행위 중 조교 글로벌 상태(연모·복종·음란·공포·반감)가 **임계 폭증** → 그 종류 침염이 영구히 찍힘. (휘기=시간 흐름의 소비 / 침염=한 순간의 고정 — 揮/固 대비 반복)
- **종류**: 연모·복종·음란·공포·반감 (+ 에라식 고통 침염 추가 검토).
- **효과 = 변용(變容, 유닛 변성 사다리) 엔진**:
  - 밝은 가지(유대 → 9-C 각성): 연모·복종·음란 침염 누적.
  - 어두운 가지(붕괴): 공포·반감 침염 누적.
- **흐름**: 가변 상태(글로벌5) → 한 순간 폭증 → 영구 도장(침염) → 사다리 진행(변용) → 종착(각성/붕괴).
- ※ 흑화/백화/황화/적화는 **마그눔 색-축 전용**(엘릭서·시설·계승). 변용 사다리에 재사용 금지.

### 조교 행위 엔진 (床技 풀 — 우마식 차용) ★ v0.4

> 부위6·글로벌5 정의: system_unit_sigil.md "성인 조교 수치 체계". 본 엔진은 역가(力) 조교 얼굴이 그 위에서 도는 방식.
> **입자도 = 풀**(레티어스): 부위별 숙련·내성 전부 분리.

**역가 조교 얼굴 = 받는 쪽 2종 (유닛이 발달)**
- **숙련(熟)** — *대상 부위별* 역가 (부위6 각각: 입·가슴·V·C·애널·피부). 그 부위가 쾌감을 얼마나 잘 받나.
- **내성(耐)** — *대상 부위별* 역가 (부위6 각각). 그 부위의 절정 견딤.
→ 풀 = 숙련(6) + 내성(6) = 12 레벨값. **조교 영역 고정**, *받는 유닛*이 발달.

**기술(技, 주는 쪽) = 도구** — 행위 타입별(키스·구강·유방·수음·삽입·신체·가학) 효과는 **조교 공방에서 제작한 도구(가공 시스템)가 패시브 제공.** AL은 조교자 누적 능력치를 두지 않음(에라식 플레이어 스탯 폐기) → 도구가 그 자리. 유닛이 조교자가 되는 **조수 역할**은 미래 옵션(그때 유닛 기술 역가 재도입).

**감도 ≠ 숙련 (다른 층)**: 감도 = 부위의 *현재 민감 상태*(가변, 트레잇·조교 진행으로 변동) / 숙련 = 그 부위 받는 *레벨업 역가*. 둘 다 부위별 공존.

**수치 모델 (몰드 — 숫자는 통합 밸런싱 패스로 일괄)** ★
- 부위6 각각 **3값**: 감도(상태 0~100) + 숙련Lv + 내성Lv(역가).
- **레벨업**: 그 부위 조교 행위 → 부위 경험 누적 → 숙련/내성 레벨업(레벨당 상승). = 한 행위 三 산출의 역가 몫.
- **쾌감 출력 = 도구(기법 출력) × (감도/100) × (1 + 숙련Lv 보정)**.
- **절정 = 누적 쾌감 ≥ 임계**; 임계 = 내성Lv이 올림(견딤).
- **절정 → 글로벌5 상승 + 침염**(절정 앵커, trait_variation_routes.md).
- ※ 레벨당 상승폭·감도 스케일·임계 곡선·도구 출력값 = **전부 잠정, 통합 밸런싱 패스에서 일괄 결정**(틀 먼저, 수치는 전반 감각 잡힌 뒤 한꺼번에).

**조교 1회 해결 흐름**
1. 행위 = [조교자(플레이어/주인)가 *도구(기법 T)*를 대상 *부위 P*에].
2. **쾌감 출력 = 도구(기법 T 출력) × 감도(P, 상태) × 숙련(P, 역가)**. (기술=도구가 담당)
3. 쾌감 누적 → **절정**(임계). **내성(P)** = 임계 견딤 → 세션 더 깊게/비용 경감.
4. 행위 결(주는/받는)·맥락·트레잇·기법 종류 → **글로벌5 변동** (합의 결→연모·복종·음란↑ / 강압·고통 결→공포·반감↑).
5. 한 세션서 글로벌5(또는 고통) 한 종류 **임계 폭증 → 침염** → 변용(C) 진행. 절정은 폭증 트리거 가속.
6. 행위 누적 → **三 산출**: 경험치(固) + 휘기(揮, 트레잇 후보) + 역가(力, 기술·숙련·내성 소폭 레벨업).

**부위 "조교완료" 종착 = 부위 시그니처(名器)**: 한 부위의 감도+숙련이 조교완료 임계 → **부위 시그니처 트레잇** 영구 획득 + 그 부위 침염 가속. 부위판 "종착"(변용 루트 종착의 부위 버전). 받는 쪽. 우마 名器(50~57)+음란한X(60~65) 블렌드.

| 부위 | 시그니처(작업명) | ID | 효과(몰드 — 수치 잠정) |
|---|---|---|---|
| 입 | 농밀한 입술 | AT_SIG_MOUTH | 입 쾌감 출력↑·쾌감상한↓(절정 쉬움)·키스/구강 강화 |
| 가슴 | 무르익은 가슴 | AT_SIG_BREAST | 가슴 쾌감 출력↑·쾌감상한↓·비유(모유) 시너지 |
| V | 명기(明器) | AT_SIG_V | V 쾌감 출력↑·쾌감상한↓·윤활 가속 |
| C | 깨어난 음핵 | AT_SIG_CLIT | C 쾌감 출력↑·쾌감상한↓·즉발성↑ |
| 애널 | 길든 뒤뜰 | AT_SIG_ANAL | 애널 쾌감 출력↑·쾌감상한↓·확장 |
| 피부 | 눈뜬 살갗 | AT_SIG_SKIN | 전신 촉각 쾌감↑·애무 전반 강화 |
| 전신 | 쾌락의 그릇 | AT_SIG_ALL | **전부위 조교완료** 시 — 전 쾌감상한↑·정체 시 쾌감 누적(강철의의지 결) |

- **공통 틀**: 트리거=부위 조교완료 임계 / 효과=부위 쾌감 출력↑ + 쾌감상한↓(절정 쉬움) + 패시브(정체 시 그 부위 쾌감) + 부위 고유.
- **탐닉(변용) 시너지**: 부위 시그니처 = 음란 침염 가속 → 탐닉 루트 음화와 맞물림.
- **주는 쪽 名器(신의손·신의발=수음/다리 기술)** = AL은 도구/조수 자리 → **보류**(받는 부위 시그니처 아님).
- 수치(쾌감 출력 배율·쾌감상한 변화폭·조교완료 임계) = 통합 밸런싱 패스.

**가학기술 ↔ 고통 침염**: 가학(SM) 기법은 고통을 쌓음 → **고통 침염**(글로벌5 + 고통 = 침염 6종으로 확장 검토). 고통 침염 루트 매핑(탐닉/붕괴) 미확정.

**미확정**: 기술 행위타입 최종 목록 / 쾌감·절정 수치 공식 / 절정의 HP·피로 비용 여부 / "조교완료" 임계·보상 트레잇 목록 / 고통 침염 채택·루트.

### 두 트랙 완전 분리 ★ 핵심

| 트랙 | 출처 | 휘발 | 용도 |
|---|---|---|---|
| **누적 경험치** | 모든 행위 (전체 합산) | **X 영구 누적** | **HP 결정** |
| **행위 sub 점수** | 영역별 행위 (sub 분류) | **O 휘발 (소비)** | 트레잇 후보 풀 진입 |

같은 행위에서 동시 발생하지만 작동 결 분리.

### 스탯·상태 결정 자세

| 자리 | 결정 |
|---|---|
| **HP** | 누적 경험치 (휘발 X) |
| **공격력·방어력** | **장비(장착 아이템)만** |
| **호감도** | 별도 시스템 (관계 차원) |
| **트레잇 효과** | 행동·이벤트·상태·성격 결. **스탯 직접 박지 않음** |

트레잇 = 시뮬 결의 다양성·이벤트 트리거·성격 표현·특수 행동. ERA식.

### 행위 카테고리 7 + 영역 매핑

| 카테고리 | 메인 | 보조 | 발생 자리 |
|---|---|---|---|
| 전투 행위 | combat | body | 던전 탐사 중 |
| 조교 행위 | adult | personality | 조교 공방·자성환 도구·호감도 도구 |
| 탐사 행위 | combat | body | 던전 진입·이벤트·미지·환상 종족 조우 |
| 관계 행위 | personality | adult | 호감도·광장 교환·NPC 거래·거처 이벤트 |
| 도시 활동 | personality | body | 시설 자동·훈련장·식량 풍요/결핍 |
| **시간 경과** | **관측소 매개 → 활성 인 → 매핑 영역** | — | 월말 정산·인 활성기·달력 |
| 합체 | (별도 시스템: 합성 매칭표·계승 3경로) | — | 합체 시도·합체 사고 |

- **body는 항상 보조** (신체 트레잇은 부수적, 전용 카테고리 없음)
- **시간 경과 = 관측소 매개** (인-속성 매핑 활용. 관측소 정체성 강화)

### Sub 카테고리 분류 (각 카테고리 내 세부)

- **전투**: 공격형·방어형·회피형·치명형·승패
- **조교**: 도구별(자성환계/호감도/직설 성인 용품)·행위 결(주는/받는)·강도
- **탐사**: 깊이(얕은/심층)·발견(이벤트/미지/환상 조우)·전멸·회수
- **관계**: 호감도 경로(대화/선물/시간)·광장 교환·NPC 납품·거처 이벤트
- **도시 활동**: 시설 종류별·훈련장 자동 육성·식량 풍요/결핍
- **시간 경과**: 활성 인별 (15 인 매핑)·달력 이벤트
- **합체**: 일반 합체·합체 사고·계승 경로별

### 트레잇 발현 방식 = 조건부 + 선택 혼합 ★ 핵심

```
행위 발생
   ↓
영역별 sub 점수 누적
   ↓
트레잇 조건 (sub 수치) 충족
   ↓
"발현 가능 후보 풀"에 트레잇 등록 (상한 3개)
   ↓
자동 모드 (기본): 즉시 자동 습득 → 그 시점 sub 점수 감소(소비)
수동 모드 (보강): 월말·플레이어 원할 때 → 선택 시 sub 점수 감소(소비)
   ↓
트레잇 취득
미선택 후보 = 휘발 (sub 점수 유지)
취득한 트레잇은 후보 풀 재등장 X (중복 방지)
```

### 트레잇 조건 분류

| 결 | 조건 | 예시 |
|---|---|---|
| **단일 조건** | 한 sub 수치 도달 | `CT_QUICK_DODGE` ← 회피형 50 |
| **다중 조건** | 여러 sub 조합 수치 도달 | `CT_COUNTER_STRIKE` ← 공격형 30 + 회피형 30 |
| **시그니처** | 깊은 다중 조건 + 인 활성기 등 | `CT_BERSERKER` ← 공격형 80 + 패배 누적 + 열(熱) 활성기. **L 회차 각성 트리거 자리와 연결**: 각성 발현 시 추가되는 트레잇 = 시그니처 트레잇 자리로 채울 수 있음(잠정). 디테일은 D-3 미정 위임 |

다중 조건 트레잇 = 사용자가 의도해서 sub 행위 조합 누적 → 노릴 수 있는 자리.

### 가중치 추첨 = 가장 점수 높은 sub 메인 매칭

영역 임계 도달 시, 최근 누적된 **가장 점수 높은 sub와 매칭되는 트레잇**이 우선 후보로 진입.

### 휘발 방식 = 감소 (소비, 비용 차감)

| 트레잇 | 비용 | 효과 |
|---|---|---|
| 단일 조건 (회피형 50) | 회피형 -50 | 그 영역만 차감 |
| 다중 조건 (공격형 30 + 회피형 30) | 공격형 -30, 회피형 -30 | 조합 차감 |

리셋(0으로) 아닌 **점수 소비 결** = 자원 관리 자세. 행위 누적이 헛되지 않음.

### 슬롯 상한·후보 상한

- **후보 풀 상한 = 3** (선택 피로 방지)
- **트레잇 슬롯 상한 = 영역별** (combat·personality·adult·body 각 별도, 기존 박힘)

### E 가이드라인 — 신규 트레잇 생성 규칙 (노가다 인스턴스용)

| 항목 | 규칙 |
|---|---|
| **ID 체계** | AT_/CT_/PT_/BT_ SNAKE_CASE (body 신설 = `BT_` 권장) |
| **조건 디자인 결** | 단일 조건 / 다중 조건 / 시그니처 셋 중 명시 |
| **메인/보조 sub 태그** | 각 트레잇 발현 조건의 sub 카테고리 명시 (가중치 추첨용) |
| **풀 영역 배치** | combat / personality / adult / body 중 어디 |
| **희귀도 결** | 일반 / 시그니처 / 환상 트레잇 (호문쿨루스 결) 중 |
| **합성 매칭표 영향** | 신규 트레잇이 합성 결과로도 등장 가능한지 검토 |
| **신성·종교 결 어휘 회피** | 어휘 톤 원칙 적용 (메타 원칙 9) |

## 합성 규칙

### 카테고리

트레잇은 4개 카테고리로 분류:

- **전투**: 스킬, 전투 행동, 전투 수치 보정
- **성격**: AI 행동 가중치, 관계 반응, 이벤트 트리거
- **성인**: 부위 감도, 상태 수치, 조교 반응
- **신체**: 대분류 기초 스탯 보정, 방어 프로필 보정 (미확정)

### 카테고리 교차 허용

- **같은 카테고리 합성**: 전투+전투, 성격+성격, 성인+성인 — 기본
- **교차 카테고리 합성**: 전투+성격, 성격+성인, 전투+성인 — **허용**
- **합성 결과 카테고리는 재료에 종속되지 않음**:
  - 전투+전투 → 전투 (유지)
  - 성격+성격 → 성인/성격/전투 모두 가능
  - 성인+성인 → 성인/성격/전투 모두 가능
  - 교차 합성 → 어떤 카테고리든 가능

### 합성 발동 조건

1. **단일 유닛 육성**: 하나의 유닛이 필요한 트레잇들을 모두 보유 + 합성 조건 충족 → 자동 발동 판정
2. **합체 시**: 소재 A와 B의 트레잇이 교차하여 합성 조건 충족 → 합성 발동 (계승 3경로 중 최우선)
3. 합성 발동은 **레시피 참조** — 특정 트레잇 조합이 특정 합성 트레잇을 생산

### 발견 방식 (v0.2 — K 회차 정정)

- 초기: 합성 레시피 **미공개** (플레이어는 존재를 모름)
- **합성 발동 (재료 트레잇 조합 충족)**: 두 트랙 분리에서 명시 — 트레잇 획득 자체는 K 회차 시스템(행위→sub 점수→후보 풀), **합성은 별도 트랙**(이미 보유한 트레잇들 조합 시 발동)
- ~~행위 기반 우연 발견~~ **폐기** — K 회차 성장 루트와 충돌 (행위는 sub 점수만 누적, 트레잇 획득은 후보 풀 자동/수동 선택)
- 전서 기록: 한번 발견하면 전서에 레시피 등록 → 이후 의도적 재현 가능
- 힌트: 파편 로어, 전서 나레이터 논평 등으로 힌트 제공 가능
