## 개요

트레잇 합성은 유닛이 보유한 트레잇들을 조합하여 상위 트레잇을 생성하는 시스템.
조합 시스템(아이템)의 "태그 합산 → 특수 레시피 우선" 문법과 동일한 패턴을 따른다.

합성은 **단일 유닛 육성 중**에도, **합체 시 트레잇 계승 판정**에서도 발동할 수 있다.

> **K 회차 정합 (2026-05-21)**: 트레잇 획득 자체(레벨업·경험 → 트레잇 습득)는 K 회차의 **두 트랙 분리 + 행위 sub 점수 + 후보 풀** 시스템이 담당. 본 문서의 합성 시스템은 그 위에 얹힌 **이미 보유한 트레잇들 → 상위 트레잇 변환** 트랙. 두 트랙 별개로 작동.

## K 회차 트레잇 시스템 (v0.2 신규 — 획득 규칙면)

> 디테일은 마스터 노트 영역 8 / K 회차 리비전 노트 참조. 본 섹션은 합성 시스템과의 정합을 위해 요약.

### 두 트랙 완전 분리 ★ 핵심

| 트랙 | 출처 | 휘발 | 용도 |
|---|---|---|---|
| **누적 경험치** | 모든 행위 (전체 합산) | **X 영구 누적** | **HP 결정** |
| **행위 sub 점수** | 영역별 행위 (sub 분류) | **O 휘발 (소비)** | 트레잇 후보 풀 진입 |

같은 행위에서 동시 발생하지만 작동 결 분리.

### 스탯·상태 결정 자세

| 자리 | 결정 |
|---|---|
| **HP** | 누적 경험치 (휘발 X) |
| **공격력·방어력** | **장비(장착 아이템)만** |
| **호감도** | 별도 시스템 (관계 차원) |
| **트레잇 효과** | 행동·이벤트·상태·성격 결. **스탯 직접 박지 않음** |

트레잇 = 시뮬 결의 다양성·이벤트 트리거·성격 표현·특수 행동. ERA식.

### 행위 카테고리 7 + 영역 매핑

| 카테고리 | 메인 | 보조 | 발생 자리 |
|---|---|---|---|
| 전투 행위 | combat | body | 던전 탐사 중 |
| 조교 행위 | adult | personality | 조교 공방·자성환 도구·호감도 도구 |
| 탐사 행위 | combat | body | 던전 진입·이벤트·미지·환상 종족 조우 |
| 관계 행위 | personality | adult | 호감도·광장 교환·NPC 거래·거처 이벤트 |
| 도시 활동 | personality | body | 시설 자동·훈련장·식량 풍요/결핍 |
| **시간 경과** | **관측소 매개 → 활성 인 → 매핑 영역** | — | 월말 정산·인 활성기·달력 |
| 합체 | (별도 시스템: 합성 매칭표·계승 3경로) | — | 합체 시도·합체 사고 |

- **body는 항상 보조** (신체 트레잇은 부수적, 전용 카테고리 없음)
- **시간 경과 = 관측소 매개** (인-속성 매핑 활용. 관측소 정체성 강화)

### Sub 카테고리 분류 (각 카테고리 내 세부)

- **전투**: 공격형·방어형·회피형·치명형·승패
- **조교**: 도구별(자성환계/호감도/직설 성인 용품)·행위 결(주는/받는)·강도
- **탐사**: 깊이(얕은/심층)·발견(이벤트/미지/환상 조우)·전멸·회수
- **관계**: 호감도 경로(대화/선물/시간)·광장 교환·NPC 납품·거처 이벤트
- **도시 활동**: 시설 종류별·훈련장 자동 육성·식량 풍요/결핍
- **시간 경과**: 활성 인별 (15 인 매핑)·달력 이벤트
- **합체**: 일반 합체·합체 사고·계승 경로별

### 트레잇 발현 방식 = 조건부 + 선택 혼합 ★ 핵심

```
행위 발생
   ↓
영역별 sub 점수 누적
   ↓
트레잇 조건 (sub 수치) 충족
   ↓
"발현 가능 후보 풀"에 트레잇 등록 (상한 3개)
   ↓
자동 모드 (기본): 즉시 자동 습득 → 그 시점 sub 점수 감소(소비)
수동 모드 (보강): 월말·플레이어 원할 때 → 선택 시 sub 점수 감소(소비)
   ↓
트레잇 취득
미선택 후보 = 휘발 (sub 점수 유지)
취득한 트레잇은 후보 풀 재등장 X (중복 방지)
```

### 트레잇 조건 분류

| 결 | 조건 | 예시 |
|---|---|---|
| **단일 조건** | 한 sub 수치 도달 | `CT_QUICK_DODGE` ← 회피형 50 |
| **다중 조건** | 여러 sub 조합 수치 도달 | `CT_COUNTER_STRIKE` ← 공격형 30 + 회피형 30 |
| **시그니처** | 깊은 다중 조건 + 인 활성기 등 | `CT_BERSERKER` ← 공격형 80 + 패배 누적 + 열(熱) 활성기. **L 회차 각성 트리거 자리와 연결**: 각성 발현 시 추가되는 트레잇 = 시그니처 트레잇 자리로 채울 수 있음(잠정). 디테일은 D-3 미정 위임 |

다중 조건 트레잇 = 사용자가 의도해서 sub 행위 조합 누적 → 노릴 수 있는 자리.

### 가중치 추첨 = 가장 점수 높은 sub 메인 매칭

영역 임계 도달 시, 최근 누적된 **가장 점수 높은 sub와 매칭되는 트레잇**이 우선 후보로 진입.

### 휘발 방식 = 감소 (소비, 비용 차감)

| 트레잇 | 비용 | 효과 |
|---|---|---|
| 단일 조건 (회피형 50) | 회피형 -50 | 그 영역만 차감 |
| 다중 조건 (공격형 30 + 회피형 30) | 공격형 -30, 회피형 -30 | 조합 차감 |

리셋(0으로) 아닌 **점수 소비 결** = 자원 관리 자세. 행위 누적이 헛되지 않음.

### 슬롯 상한·후보 상한

- **후보 풀 상한 = 3** (선택 피로 방지)
- **트레잇 슬롯 상한 = 영역별** (combat·personality·adult·body 각 별도, 기존 박힘)

### E 가이드라인 — 신규 트레잇 생성 규칙 (노가다 인스턴스용)

| 항목 | 규칙 |
|---|---|
| **ID 체계** | AT_/CT_/PT_/BT_ SNAKE_CASE (body 신설 = `BT_` 권장) |
| **조건 디자인 결** | 단일 조건 / 다중 조건 / 시그니처 셋 중 명시 |
| **메인/보조 sub 태그** | 각 트레잇 발현 조건의 sub 카테고리 명시 (가중치 추첨용) |
| **풀 영역 배치** | combat / personality / adult / body 중 어디 |
| **희귀도 결** | 일반 / 시그니처 / 환상 트레잇 (호문쿨루스 결) 중 |
| **합성 매칭표 영향** | 신규 트레잇이 합성 결과로도 등장 가능한지 검토 |
| **신성·종교 결 어휘 회피** | 어휘 톤 원칙 적용 (메타 원칙 9) |

## 5Tier 체계

| Tier | 획득 방식 | 설명 |
|------|----------|------|
| T1 | 초기 보유 | 유닛 생성 시 기본 보유 트레잇 |
| T2 | 육성 해금 | 경험치 풀 + 임계점 + 확률 판정으로 해금 (system_unit_sigil.md 트레잇 획득 참조) |
| T3 | 합성 | 2~3 트레잇 합성. 재료 Tier 무관 (T1+T1도 가능) |
| T4 | 합성 | 2~3 트레잇 합성. T3 재료 가능하지만 **필수 아님** |
| T5 | 특수 합성 | **특수인(염/수은/유황) 소재 필수**. 최종 트레잇 — 합성 불가 (재료로 사용 불가) |

### Tier 구분 원칙

- T3과 T4의 구분은 **결과물 강도/희귀도 기준** (유동적)
- T3: 충분히 유용하지만 특화 성능은 아닌 수준
- T4: 빌드 핵심이 될 수 있는 강력한 트레잇
- T5: 게임 내 최고 수준, 특수인 소재라는 명확한 비용 존재
- 합성 체인: **있되 얕게** (T3→T4 재료 허용, 필수 아님)

## 합성 규칙

### 카테고리

트레잇은 4개 카테고리로 분류:

- **전투**: 스킬, 전투 행동, 전투 수치 보정
- **성격**: AI 행동 가중치, 관계 반응, 이벤트 트리거
- **성인**: 부위 감도, 상태 수치, 조교 반응
- **신체**: 대분류 기초 스탯 보정, 방어 프로필 보정 (미확정)

### 카테고리 교차 허용

- **같은 카테고리 합성**: 전투+전투, 성격+성격, 성인+성인 — 기본
- **교차 카테고리 합성**: 전투+성격, 성격+성인, 전투+성인 — **허용**
- **합성 결과 카테고리는 재료에 종속되지 않음**:
  - 전투+전투 → 전투 (유지)
  - 성격+성격 → 성인/성격/전투 모두 가능
  - 성인+성인 → 성인/성격/전투 모두 가능
  - 교차 합성 → 어떤 카테고리든 가능

### 합성 발동 조건

1. **단일 유닛 육성**: 하나의 유닛이 필요한 트레잇들을 모두 보유 + 합성 조건 충족 → 자동 발동 판정
2. **합체 시**: 소재 A와 B의 트레잇이 교차하여 합성 조건 충족 → 합성 발동 (계승 3경로 중 최우선)
3. 합성 발동은 **레시피 참조** — 특정 트레잇 조합이 특정 합성 트레잇을 생산

### 발견 방식 (v0.2 — K 회차 정정)

- 초기: 합성 레시피 **미공개** (플레이어는 존재를 모름)
- **합성 발동 (재료 트레잇 조합 충족)**: 두 트랙 분리에서 명시 — 트레잇 획득 자체는 K 회차 시스템(행위→sub 점수→후보 풀), **합성은 별도 트랙**(이미 보유한 트레잇들 조합 시 발동)
- ~~행위 기반 우연 발견~~ **폐기** — K 회차 성장 루트와 충돌 (행위는 sub 점수만 누적, 트레잇 획득은 후보 풀 자동/수동 선택)
- 전서 기록: 한번 발견하면 전서에 레시피 등록 → 이후 의도적 재현 가능
- 힌트: 파편 로어, 전서 나레이터 논평 등으로 힌트 제공 가능
