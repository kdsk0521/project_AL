## 풍경 태그 구조 (안)

트레잇에 선택적으로 `landscapeTags` 필드를 추가하는 방식.
배치된 유닛의 트레잇 landscapeTags를 합산 → 해당 장소의 풍경 텍스트 생성에 입력.

```
"landscapeTags": {
  "smell": "허브 냄새",      // 후각
  "sound": "끓는 소리",      // 청각
  "visual": "녹색 얼룩",     // 시각
  "temperature": "따뜻함",   // 온도감
  "texture": null             // 촉각 (없으면 null)
}
```

- 모든 트레잇에 필수가 아님. 풍경에 영향을 주는 트레잇만 태그 보유
- 주로 body 직업 적성 + 일부 combat/personality에서 사용
- 여러 유닛의 태그가 겹치면 밀도 단계 상승 (톤 논쟁 결과의 이중 레이어)
- null 채널은 무시
