# 도구 업그레이드 시스템 설계 (v0.1)

> 상위 문서: game_blueprint.md / system_crafting.md
> 관련 문서: system_exploration.md (채집), system_trait_synthesis.md (육성/조교)

---

## 개요

도구는 연금술사(플레이어)의 **빌드 시스템**이자 **패시브 능력판**이다.
도구에 장착된 부품이 채집 범위, 전투 패시브, 육성 방향을 결정한다.

> **"유닛은 장비를 입고, 연금술사는 도구를 장착한다."**

---

## 설계 원칙

- 도구 업그레이드는 별도 시스템이 아니라 **기존 조합의 연장선** ("모든 것은 조합이다")
- 도구는 **영구 사용**, 내구도 없음
- 성장감은 도구 부품의 접미사 tier 상승으로 직접 체감
- 접미사 테이블은 전 도구 공통 문법, 효과 해석만 맥락별 분기

---

## 도구 구조

### 도구 = 골격 + 부품 3슬롯

```
[도구 골격] — 도구 종류를 결정 (곡괭이, 낚시대, 채집봉 등)
  ├─ [슬롯 1] — 부품 A
  ├─ [슬롯 2] — 부품 B
  └─ [슬롯 3] — 부품 C
```

- 3슬롯은 **동등** (위계 없음)
- 부품은 **합체 아이템** (조합으로 제작)
- 부품은 조립 UI에서 **탈착 가능**, 빼낸 부품은 부품 전용 인벤토리에 보관
- 도구 간 부품 호환 없음 (전부 전용)

## 도구 목록 (7종)

### 채집 도구 (3종) — 탐사 시스템 연결

| 도구 | 대응 채집 포인트 | 파츠 1 | 파츠 2 | 파츠 3 |
|------|----------------|--------|--------|--------|
| 곡괭이 | 광맥 | 머리 | 자루 | 손잡이 |
| 낚시대 | 수계 | 바늘 | 줄 | 막대 |
| 채집봉 | 수풀 | 끝장식 | 봉체 | 보석 |

- 특수 채집 포인트 폐지, 기존 3종으로 전부 커버
- 채집봉은 마법 도구 (연금술사 세계관 부합, 꿀/열매 등 확장 가능)

### 육성 도구 (2종) — 유닛 전투 능력 성장

| 도구 | 육성 방향 | 파츠 1 | 파츠 2 | 파츠 3 |
|------|----------|--------|--------|--------|
| 타격 인형 | 공격 (스킬 트레잇) | 팔 | 몸통 | 받침대 |
| 달리기 기구 | 속도 (신체 트레잇) | 벨트 | 프레임 | 바퀴 |

- 방어는 장비 + 속성 프로필로 처리, 별도 육성 도구 없음

### 조교 도구 (2종) — ERA식 육성

| 도구 | 조교 방향 | 파츠 1 | 파츠 2 | 파츠 3 |
|------|----------|--------|--------|--------|
| 로터 | 성인 트레잇 (ERA식) | 모터 | 표면 | 손잡이 |
| 교본 | 성격 트레잇 (교류) | 표지 | 내지 | 잠금장치 |

### 조교 전용 아이템 (별도 체계)

구속구, 채찍, 딜도 등은 도구 빌드판(연금술사 패시브)이 **아닌** 별도 조교 장비.

- 조합으로 제작하거나 던전 드랍으로 획득
- 조교 행동 시 사용하는 장비 — 조교 가능 범위를 확장
- 상위 트레잇 해금의 열쇠 역할
- 연금술사 패시브가 아니라 **조교 씬에서 사용하는 아이템**

## 접미사 시스템

### 접미사 = 재료속성 × 원소 교차

재료속성 4종 × 원소 5종 = **최대 20종** 접미사.

| | 열 | 위 | 광 | 동 | 식 |
|---|---|---|---|---|---|
| **경도** | 작열하는 | (미정) | (미정) | 공명하는 | (미정) |
| **가공성** | (미정) | (미정) | (미정) | (미정) | (미정) |
| **전도** | (미정) | (미정) | (미정) | 진동하는 | (미정) |
| **보존** | (미정) | (미정) | (미정) | (미정) | (미정) |

> 접미사 20종의 구체적 이름과 효과는 **밸런싱 단계에서 확정**.

### 접미사 tier 상승

같은 태그 조합의 재료를 중복 투입하면 해당 접미사의 **tier가 상승**한다.

```
곡괭이 머리(t0) + [경도×열] 재료 → "작열하는 곡괭이 머리" (t1)
"작열하는 곡괭이 머리" (t1) + [경도×열] 재료 → "작열하는 곡괭이 머리" (t2)
```

- tier 상한 없음, **비용 급증으로 자연 제한**
- 높은 tier일수록 필요 재료의 등급/수량이 급격히 증가

## 게이팅 (도구 파워)

### 공식: 전 부품 tier 합계 ÷ 3 (버림)

```
부품A(t3) + 부품B(t2) + 부품C(t1) → 게이팅 = (3+2+1) ÷ 3 = 2
부품A(t2) + 부품B(t2) + 부품C(t2) → 게이팅 = (2+2+2) ÷ 3 = 2
```

- **태그 종류 무관** — 순수 tier 평균으로 계산
- 어떤 방향으로 특화했든 게이팅 자체는 공평
- 접미사 종류는 게이팅이 아니라 **효과 방향**을 결정
- 도구 슬롯이 연금술사의 패시브를 결정 (전투 이득, 탐사 이득 등)

### 게이팅 적용 예시

| 맥락 | 게이팅 역할 |
|------|-----------|
| 채집 | 접근 가능 재료 tier / 채집 포인트 범위 |
| 전투 | 연금술사 패시브 강도 |
| 육성 | 육성 효율 / 접근 가능 트레잇 tier |
| 조교 | 조교 효율 / 접근 가능 트레잇 tier |

## 효과 분기 (같은 문법, 다른 해석)

접미사 테이블은 전 도구 공통이지만, **맥락에 따라 효과가 달라진다**.

```
"작열하는" (경도×열) 접미사:

  채집봉에 장착 → 채집 시: 열 계열 식물 채집 효율 증가
                 → 전투 시: 매턴 소량 열 대미지 추가

  곡괭이에 장착 → 채집 시: 열 계열 광석 접근
                 → 전투 시: 연금술사 방어력 보정

  로터에 장착   → 조교 시: 열 속성 성인 트레잇 자극

  타격 인형에 장착 → 육성 시: 열 속성 스킬 트레잇 해금 확률 증가
```

> 구체적 효과 수치/내용은 **밸런싱 단계에서 확정**.

## 제작 흐름

### 게임 시작 시

- 도구 7종 전부 **t0 상태로 기본 지급** (제작 불필요)
- 기본 부품이 장착된 상태에서 시작

### 업그레이드

```
[솥/작업대]
  장착된 부품 + 재료(원재료 or 가공 소재) 투입
  → 재료의 태그가 접미사로 반영
  → 동일 태그 중복이면 tier 상승
  → 가공한 재료 사용 가능 (태그 기반)
```

### 방향 전환 (리빌드)

```
1. 조립 UI에서 기존 부품 탈착 → 부품 인벤토리에 보관
2. 부품 제작대에서 새 t0 부품 제작
   - 만들 부품 선택 → 재료 소비 → t0 부품 생성
3. 솥에서 새 부품에 원하는 방향으로 접미사 작업
4. 조립 UI에서 새 부품 장착
```

- 기존 부품은 보관되므로 투자 보존
- 방향 전환 비용 = 새 t0 부품 제작 비용 + 새 접미사 재료 비용

### 부품 제작대

- t0 틀 **전용** — 접미사 부여는 솥에서 별도 진행
- 만들 부품을 **선택**하는 방식 (같은 재료로 다른 부품 제작 가능)
- 재료는 소비됨

> 부품 제작대 레시피의 구체 재료 조합은 **미확정** (중반 리빌드 비용으로 밸런싱 시 변경 가능)

## 빌드판 총괄

### 도구 7종 × 파츠 3개 = 21슬롯

```
[채집]
  곡괭이:    [머리]   [자루]   [손잡이]
  낚시대:    [바늘]   [줄]     [막대]
  채집봉:    [끝장식] [봉체]   [보석]

[육성]
  타격 인형: [팔]     [몸통]   [받침대]
  달리기 기구:[벨트]  [프레임] [바퀴]

[조교]
  로터:      [모터]   [표면]   [손잡이]
  교본:      [표지]   [내지]   [잠금장치]
```

- 21개 파츠 이름 전부 고유 (겹침 없음)
- 각 파츠의 접미사 조합이 연금술사의 전체 빌드를 결정
- 던전 전 세팅 교체로 상황별 빌드 운용 가능

## 미결정 사항

### 밸런싱 단계

- [ ] 접미사 20종의 구체적 이름
- [ ] 접미사별 효과 테이블 (채집/전투/육성/조교 맥락별)
- [ ] tier별 비용 급증 곡선
- [ ] 게이팅 수치별 접근 가능 범위 (tier 1 게이팅 = 몇 층까지?)
- [ ] 부품 제작대 레시피 확정 (중반 리빌드 비용)

### 콘텐츠 설계 단계

- [ ] 조교 전용 아이템 종류 및 제작 레시피
- [ ] 조교 전용 아이템의 트레잇 해금 매핑
- [ ] 육성 도구 파츠별 구체적 전투 패시브

### 세부 규칙

- [ ] 접미사 중복 시 정확한 tier 상승 규칙 (재료 tier가 부품 tier보다 높아야 하는지 등)
- [ ] 부품 탈착 시 추가 비용 여부
- [ ] 교본과 교류 시스템의 구체적 연동 방식
