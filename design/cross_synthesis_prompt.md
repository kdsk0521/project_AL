## 전송 프롬프트

```
이 게임의 트레잇 합성 시스템에서 **교차 카테고리 합성 레시피**를 설계해야 한다.

[합성 시스템 기본 규칙]
- 유닛이 보유한 2개 트레잇을 조합 → 상위 트레잇 생성
- 같은 카테고리든 다른 카테고리든 합성 가능
- 결과 카테고리는 재료에 종속되지 않음 (전투+성격 → 성인도 가능)
- T3(유용하지만 특화는 아님) ~ T4(빌드 핵심급) 범위
- 이미 같은 카테고리 합성 30개 확정 (전투×전투 10, 성격×성격 10, 성인×성인 10)
- 이번에는 교차 조합 6쌍 × 10개 = **60개** 레시피 필요

[6개 교차 쌍]
1. 전투(CT) + 성격(PT) → 10개
2. 성격(PT) + 성인(AT) → 10개
3. 전투(CT) + 성인(AT) → 10개
4. 전투(CT) + 신체(BT) → 10개
5. 성격(PT) + 신체(BT) → 10개
6. 성인(AT) + 신체(BT) → 10개

[6원소 체계 — v4.5 갱신, 2026-05-20]
전투 속성은 6원소로 분류된다 (4 물리 + 2 신비):
- 위(危, danger): 축적·압력·물리적 위협. 찌르기, 속박, 과부하
- 열(熱, heat): 온도·에너지·발열/냉각. 냉기방사, 업화, 내열벽
- 광(光, light): 빛·방출 전반·감각. 섬광참, 광선, 감각 자극. (※ 독은 더 이상 광이 아님 — 자(磁)로 이전)
- 동(動, motion): 움직임·속도·위치 변환. 돌진, 질풍
- 식(蝕, erosion): 화학(산화·환원) + 비현실. 부식장, 용해액, 산호침식. 인간 지각 너머의 화학
- **자(磁, magnetism)**: 자기(인력·척력) + 자전 + **관계·매혹·이끌림**. 자기 공격·번개·매혹 디버프·이끌림·독(자기적 매혹으로 끌어들이는 독). 신비 원소

가공 장비도 같은 6원소 체계 (6설비 v4.5):
- 가마(furnace, T1): 열 주입 → **자 해방**
- 분쇄기(crusher, T1): 위 해방 + 식 해방 (해체형, 두 해방 결합)
- 압축기(compressor, T1.5): 위 주입 → 동 해방
- 증류기(distiller, T2): 열 해방 + 광 주입
- **자성환(magnetic ring, T2.5)**: **광 해방 + 자 주입** (호감도 도구 제작 설비)
- 환류기(refluxer, T3): 동 주입 + 식 주입 (최후 설비)

[시설 체계]
도시에 배치 가능한 시설:
- 공방(workshop): 유닛 배치 → 월말 자동 가공. 단조적성(BT_FORGE_AFFINITY) 연결
- 슬라임 농장(slimeFarm): 슬라임핵 자동 수급. 조련적성(BT_TAMING_AFFINITY) 연결
- 탐사 경비 시설(expeditionHQ): 탐사 전투 지원. 경비적성(BT_GUARD_AFFINITY) 연결
- 양어장(fishery): 물고기 수급처
- 수원지(waterSource): 물 수급처
- 재배원(garden): 약초 외 식물 수급처

[조교 체계 — 감도 매핑]
신체 부위: skin(피부), chest(가슴), mouth(입), c(클리), v(질), anal(항문)
각 행위는 부위별 배율로 감도에 영향:
- 강도 1: 쓰다듬기(skin=1.0), 포옹(skin+chest), 손잡기(skin)
- 강도 2: 키스(mouth=1.0), 가슴 주무르기(chest=1.2), 클리 자극(c=1.3), V 손가락(v=1.2)
- 강도 3: 딥키스(mouth=1.5), 유두 핥기(chest=1.5), 클리 핥기(c=1.8), 로터류(도구 필요)
- 강도 4: V 삽입(v=2.0, c=0.8), A 삽입(anal=1.8)
- 강도 5: 격렬 삽입(v=2.5, c=1.0, anal=0.5), 조련(전부위)
경험치 키: caress, kiss, stimulate, toy, lick, insert, discipline

[감정/상태 수치]
- 쾌감: 감각적 쾌락 누적
- 욕정: 성적 흥분도
- 수치: 수치심 누적 → 반감 or 굴복 분기
- 봉사: 헌신/복종 계열 행동 누적
- 굴복/복종: 저항 포기 수치
- 고통: 통증 누적 → 마조/반감 분기
- 반감: 적대감 (높으면 관계 악화)
- 연모/호감도: 긍정적 관계 수치
- 음란: 전반적 성적 각성도 (높을수록 감도 상승 가속)

[기존 같은 카테고리 합성 예시 — 톤 참고용]
```
