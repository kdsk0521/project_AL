## 개명 미리보기 (추천 레퍼런스 채택 시의 방향 감각 — 확정 아님)

- A(용궁 설화): 심해 용궁녀→「시간 잠긴 용녀」 / 수련 요정→「수면 위 정원사」 / 거품 슬라임→「용궁 거품 막내」
- B(성냥팔이): 잿빛 무녀→유지 / 서리 도마뱀 소녀→「불을 버린 도마뱀」 / 슬래그 골렘→「식지 않는 골렘」
- C(메두사): 석상 소녀→「마주본 소녀」(시선 원전) / 결계석→유지 or 「굳히는 시선」 / 소금 슬라임→「녹다 만 슬라임」
- D(프랑켄슈타인): 진흙 인형→「첫 번째 인형」 / 야드 스파이더→「잔손 거미」 / 해부인형→「스스로 열리는 인형」
- E(라파치니): 약초 요정→「해독사 요정」 / 독나비→유지 / 공생균 소녀→「정원이 된 소녀」
- F/I(모이라이+아라크네): 수정 거미→「잣는 거미」 / 침식 거미→「끊는 거미」 / 직공·서기관·여우들 유지
- H(돈키호테 구조): 철벽 기사→「교대 없는 기사」 / 결정 기사→「벗지 못한 기사」
