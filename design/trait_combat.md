# 전투(CT) 카테고리 몰드 (콘텐츠 v0.1)

> 작성: 2026-05-31
> 정본: system_exploration.md (전투 스탯·AP·7슬롯·비율식), system_trait_synthesis.md v0.4 (역가·다리). 허브·지도: trait_era_transform.md §0.
> 특이점: **CT는 가장 큰 기존 카테고리(73)이자 에라 수확 최소** — 우리 가장 오리지널. 에라(조교 sim)는 전투가 가벼워 차용 거의 없음.
> 성격: 몰드. 수치=통합 밸런싱.

## 전투 시스템 전제 (system_exploration)

- **base 공/방/속도 3종 = 장비 의존** (유닛 자체는 대분류 기초값). 물리 통합.
- **속도 → AP**(라운드 2~4), 스킬마다 AP 코스트(1~3).
- **7슬롯 방어 프로필**: 물리/열/위/동/광/식/자 (주/부 원소 내성).
- **敵対心(어그로)**: 보조 스탯 — 타겟 가중 추첨의 base (blue_resort 차용). 수호·위압·도발·예속·인조 탱커가 올림.
- **비율식 데미지**: ATK×(ATK/(ATK+DEF))×스킬배율. 스킬=배율(×0.8~1.5)로만 차별.
- **자동전투** (★): 수동 지시 없음. AI가 AP·가중치·상황으로 행동 선택.

## 구조 — 3층

| 층 | 정체 | 비고 |
|---|---|---|
| **base 공/방/속도** | 장비 | 확정. 역가·트레잇이 안 건드림 |
| **스킬 = CT 트레잇** | 능동 행동(AP cost·배율·속성·효과) + 패시브(스탯/행동 보정) | 73개 기존 |
| **역가 전투 얼굴** | 숙련 층(레벨업) — **장비 base는 안 건드리고 행동별 보정만** | 신설 확정(F) |

### 역가 전투 얼굴 (조교 床技와 대칭) — 단위 = **속성별 7** (확정 2026-05-31)
- 조교: 유닛=받는 쪽 → 숙련·내성(부위6별) 발달 / 주는=도구.
- **전투: 유닛=주는 쪽 → 공격 숙련이 유닛 자체에 발달** (도구 아님).
- **단위 = 속성별 (물리 + 6원소 = 7)** — 무기군 아님(AL은 물리 통합·무기 클래스 약함). **부위6 ↔ 속성7 대칭**, 7슬롯 방어와 정렬, 스킬 속성이 숙련군을 자동 커버.
  - **공격 숙련(속성7, 주는)**: 그 속성 스킬 사용 → 레벨업 → 그 속성 행동 배율·명중↑.
  - **방어 숙련(받는)**: 회피(전역) + 속성별 경감 보정. base 경감=장비(7슬롯) 위에 역가 보정.
- 한 행위 三 산출의 역가 몫 = 전투 행위 → 그 **속성 숙련** 레벨업.

## 자동전투 AI = 다리의 수신처 ★

자동전투라 **트레잇의 전투 발현 = AI 행동 가중치·패시브**로만 의미. 전투는 **조교·성격·신체에서 빚은 교차 영향(다리)이 모두 모이는 곳**.

| 출처 | 다리 → 전투 발현(패시브/가중치) |
|---|---|
| AT 변용 | 애착→동석 ATK/DEF↑ / 예속→자기보존 무시(공격 가중) / 음마→매혹 오라(적 명중↓·AI 교란) / 붕괴→무공포·HP낮을수록 ATK↑ |
| AT S성향 | 가학→공격성·약점 타격↑ |
| PT 성격 | 겁없음→공격 가중 / 경계심→회피 가중 / 호전·소심 등 AI 성향 |
| BT 신체 | 체격→회피/방어·종족외형→속성 약점/저항(7슬롯) |

→ **전투 자체 트레잇(CT 73)** + **수신 다리** = 전투 빌드. *조교로 빚은 기질이 전투를 먹여 살린다*(레티어스).

### 자동전투 AI — 확정 규칙 (2026-05-31, exploration AP 흐름 + Dual Brain 노트 굳힘)

**행동 결정 흐름 (라운드, AP 체계)**
1. **조건부 오버라이드**: 특정 트레잇+조건 충족 → 행동 강제. (심약+HP<30%→방어/철수 90%, **예속→자기보존 무시 돌격**, **붕괴→무공포 돌격** 등 — 다리 트레잇의 큰 자리.)
2. **행동 유형 가중치 추첨**: 성격 base 가중치(공격/방어/회피/스킬) + **다리 보정** + 파티 시너지 미세보정. (공격적: 공격80/방어10/스킬10, 소심: 방어60/회피20/공격20 …)
3. **스킬 선택**: 정한 유형 내 AP 맞는 스킬 중, **역가 숙련·속성 효율 높은 것** 우선.
4. **AP 소진까지 반복**.

**타겟 선택 = 가중 추첨 (敵対心 + 성격)** [업그레이드 2026-05-31, blue_resort 어그로 차용]:
- **타겟 피격 가중 = 敵対心(base) × 성격 보정(공격자가 그 타겟에 두는 배율)**.
- **敵対心(어그로) 소스**: 장비(도발) · 트레잇(수호·위압·도발 → 어그로↑) · 대분류(인조 탱커형 base↑) · 변용 예속.
- **성격 보정(배율)**: 잔혹/가학→저HP·약점 ×2 / 신중·경계→고위협 ×1.5 / 충의·애착→주인·아군 노린 적 ×2 / 호기심→균등(×1).
- **강제 도발(hard taunt)** = 敵対心 거대 배율 또는 override → 몇 턴 표적 고정.
- 결과: **탱커 역할(어그로) + 성격 위협(잔혹은 어그로 뚫고 다이브) 둘 다 성립.** (Dual Brain 긴장선 안 = 이 가중에 흡수.)

**수치 보정 (가중치 아님)**: 역가(공격 숙련→배율·명중↑ / 방어 숙련→회피·경감↑) + 패시브 트레잇(공격적 ATK+%·DEF−%) + 다리 패시브(위 표).

**파티 시너지 (환경 엔진 대신)**: "트레잇→환경태그→AI변동" **환경 엔진 폐기**(블랙박스 2개·인과 너무 김 — Dual Brain 결론). 살릴 것 = **파티 조합이 성격 AI 가중치를 미세 보정**(확정된 성격 AI 안에서, 단순·읽힘).

**원칙**: "준비가 전투를 결정"(편성·장비·트레잇·소비재 세팅이 핵심) / 전투 중 = 자동 + 최소 개입(소비재·속성부여·철수·관계전환) / 성격 AI = **상황 따라 선택**(고정 시퀀스 아님).

> system_exploration.md "자동전투 AI (AP 체계)" 정합 — 이 표/규칙으로 확장·확정.

## 다리 수신 집계표 (AT·PT·BT → CT, 2026-05-31)

AI 기제: **[오]**=조건부 오버라이드(행동 강제) / **[가]**=행동 가중치 / **[수]**=수치 보정(패시브) / **[타]**=타겟 선택 / **[특]**=특수(적 디버프·상태 저항).

| 출처 | 트레잇 | 전투 발현 | 기제 |
|---|---|---|---|
| AT 변용·애착 | 상애/반려 | 주인·특정 유닛 동석 시 ATK/DEF↑ | [수] |
| AT 변용·예속 | 예속 | 자기보존 무시 — 회피·방어 가중치 0·전 AP 공격 | [오] |
| AT 변용·탐닉 | 색정 | 매혹 오라 — 적 명중↓ | [특] |
| AT 변용·탐닉 | 음마 | 적 AI 교란 | [특] |
| AT 변용·붕괴 | 광기 | 공포 상태이상 저항↑ | [특] |
| AT 변용·붕괴 | 와해 | 피격 시 행동 방해 무효 | [특] |
| AT 변용·붕괴 | 재구성 | 무공포 + HP 낮을수록 ATK↑ | [오]+[수] |
| AT S성향 | S기질 | 가학 → 공격 데미지↑ | [수] |
| AT S성향 | 가학각성 | 적 약점 타격↑ | [수]+[타] |
| PT 성격(합성) | 광전사 | ATK+25%·방어 행동 선택 불가 | [수]+[오] |
| PT 성격(합성) | 위기감지 | 기습 무효·선제↑ | [특] |
| PT 성격(합성) | 불굴 | HP30%↓ DEF2배 | [수](조건) |
| PT 성격(합성) | 충의 | 호감도 유대 시 ATK/DEF+15% | [수](조건) |
| PT 성격(base) | 겁없음/경계심 등 | 공격/회피 행동 가중 | [가] |
| BT 신체 | 소체형/대체형 | DEF·회피 보정 | [수] |
| BT 신체 | 종족외형(인분·체모·결정…) | 7슬롯 속성 약점/저항 | [수](방어 프로필) |

### 충돌·스택 규칙
- **[수] 수치 보정 = 누적(스택)**. 단 같은 변용 루트 내 동석 보정(상애10%→반려20%)은 **최종 칸만 적용**(상위 대체).
- **[가] 행동 가중치 = 합산 후 추첨**.
- **[오] 오버라이드 = 우선순위**: **변용 종착(예속·재구성) > 합성 성격(광전사) > base 성격(심약)**. 동시 충돌 시 상위 적용.
- **[타] 타겟 = 최우선 성격 다리 1개**.
- **[특] = 독립 적용·누적**.

### ★ 수렴 잠금의 선물
**변용 다리는 한 유닛에 한 루트만**(수렴 잠금 도2 덕). → **변용 다리끼리는 충돌 없음**. 충돌 점검 대상은 *변용 1 + S성향 + PT + BT* 조합뿐.
- 대표 충돌: 예속(공격 올인) vs 심약(방어/철수) → 예속 우선. 광전사(방어 선택 불가) + 경계심(회피 가중) → 광전사 오버라이드가 회피 무력화.
