## 2. 에라토호(환상향의 왕) 특성 해부

토호는 **고전 Emuera 4층 분리**가 명확하다. 우리 두 트랙의 원형.

### 4층 데이터 분리 ★ 핵심 구조

| 층 | 파일 | 성격 | 개수 | 우리 대응 |
|---|---|---|---|---|
| **소질 Talent** | Talent.CSV | ON/OFF **질적** 트레잇 | 229 | = 우리 **트레잇**(CT/PT/AT/BT) |
| **능력 Abl** | Abl.CSV | **레벨업** 수치 (감각·순종·기교·중독) | ~30 | 우리엔 약함 — sub 점수가 일부 대응 |
| **경험 Exp** | Exp.CSV | **누적 카운터** (행위별) | ~60 | = 우리 **누적 경험치 / sub 점수** |
| **각인 Mark** | Mark.CSV | **임계 도달 시 찍히는** 도장 | ~10 | = 우리 **각인**(메모리에 존재) |

→ **우리 두 트랙(경험치/sub점수)은 토호의 Exp 한 층을 둘로 쪼갠 것**. 토호엔 Abl(레벨 능력)이 별도로 있는데 우리는 이 자리를 sub 점수+트레잇 효과로 흡수. **Abl을 별도 층으로 둘지(=감도·순종 같은 연속 수치)** 검토할 가치 있음 → 5절 F 참조.

### 소질 분류 체계 (12계열) — 우리 4 카테고리보다 훨씬 잘게

성격 / 성에 대한 관심 / 마음가짐 / 체질 / 기술 / 결벽도 / 정직도 / 성애성 / 매료 / 신체특징 / 함락 / 음란 / 종족특성 / 창관

→ 우리는 4개로 묶었지만, **계열 = 하위 sub 분류로 흡수 가능**. 토호의 12계열을 우리 personality·adult의 **sub 태그 사전**으로 직접 차용 가능(노가다 단축).

### 토호의 강점 메커니즘 (가져올 후보)

- **함락 진행 체인**: 연모→망신→복종→낙인→예속 (호의 사다리) / 정신붕괴→괴뢰→괴조인격 (붕괴 사다리). **상호배타·단방향 진행 상태**. → 우리 **흑화 입구 / 적화 절벽**과 정확히 같은 결.
- **음란 진행**: 음란→(부위 개발)→**음마**(최상위, 취득 제한 해제). → 각성/9-C 연결.
- **변천(835)**: "특정 소질이 조건부로 다른 소질로 변한다". → 우리 **합성/진화 트레잇**의 원형.
- **종족특성 트레잇**(요정·흡혈귀·사토리·오니…): 종족이 트레잇으로 박혀 PALAM 보정·특수 커맨드 해금. → body 카테고리 + 환상 종족 조우.
- **상성 강제(거절 830, SpellCard 833)**: 특정 트레잇이 관계 수치를 강제 고정. → NPC 관계 시스템 훅.

### 톤 주의

토호는 무녀·현인신·신령·부처 등 **신성/종교 어휘가 트레잇 이름에 직접** 박혀 있음. 우리는 메타 원칙 9(신성·종교 어휘 회피). **차용 시 인(印)·색·학자 어휘로 번역 필수.**

## 3. 에라우마 특성 해부

우마는 **현대적·수치적으로 정제**된 버전. 토호보다 세련된 설계 패턴이 여럿.

### 데이터 층 (토호와 유사하나 더 정돈)

| 파일 | 성격 | 우리 대응 |
|---|---|---|
| Talent.csv (79) | **不可升级** 특성 | 트레잇 |
| Abl.csv (52) | **可升级** 레벨 기술 | (우리 약한 자리) |
| Skill.csv | 습득완료/가능 + **상속 인자** | 합체 계승 |
| Mark.csv (6) | 1회 조교 중 인자 누적 임계 → 각인 | 각인 |
| Status.csv (71) | **리셋되는** 임시 상태 | (우리 미정 자리) |

### 우마의 세련된 패턴 (가져올 후보) ★

1. **양극 축 트레잇 (1 / -1)** — 한 슬롯에 정반대 성격 양극을 압축.
   예: `감정활동` 1=감성적 / -1=둔감함. `자신감` 1=자격지심 / -1=자만심. `미래기대` 1=비관 / -1=낙관.
   → 성격 트레잇 **슬롯 폭발을 막는 강력한 도구**. 단, 우리 합성(이산 트레잇 조합)과 충돌 검토 필요 → 5절 B.

2. **3층 床技 분리**: 기술(주는 쪽 공격력) / 숙련(받는 쪽 데미지 가산) / 내성(절정 시 정력 피해 감소). → adult 조교에 **전투 같은 깊이** 부여.

3. **부위 조교 단계 척도 (-4 ~ 2)**: -4 둔감 / 0 정상 / 1 천성 민감 / 2 **조교완료**(→ 名器급 영구 보너스). 부위별 leveled + 임계 종착. → 우리 감도 부위.

4. **상속 인자(因子) 시스템** — 우마의 시그니처. 부모 트레잇/적성이 **인자**로 자식에게 계승. → 우리 **합체 계승 3경로**의 직계 원형. **색/인 매핑과 결합하면 우리만의 변형** 가능.

5. **전쟁의 안개 / 정보 공개 등급**: `종잡을수없음` 트레잇이 호감/애모를 **숨김** → `우마토커`(아이템)로 해제. `애정억제`→`호감도렌즈`, `무자각`→`뾰이렌즈`, `투시렌즈`=정보 최고 등급. → 우리 **미지분석·연구소·전서 발견**과 결합.

6. **名器 트레잇** (방탕한입술·명기·강철의지…): 영구 특수 보너스 트레잇. → 시그니처/환상 트레잇 자리.

7. **캐릭터 전용 status**(토카이테이오 다리부상, 루돌프 황제…): 고유 트레잇이 곧 캐릭터성. → 유닛 개별 정밀화.

## 4. 두 에라 직접 비교

| 항목 | 에라토호 | 에라우마 | 우리 현재 |
|---|---|---|---|

| 조교 깊이 | 커맨드 효과 보정 | **3층(기술/숙련/내성)** | 평면 효과 |
| 계승 | 변천(소질 변화) | **상속 인자** | 합체 3경로 |

## 5. 우리 식 변형 — 채택 후보 (항목별 결정 대기)

각 항목: 출처 → 우리 어디에 → 변형 포인트 → 권장도.

### A. 4층 정합 확인 (토호 4층 ↔ 우리 두 트랙) — 권장 ★★★
우리 두 트랙은 토호 Exp의 분화. **각인(Mark) 층은 메모리에만 있고 문서 미반영** → system_trait_synthesis.md에 각인 층을 4번째 트랙으로 정식 편입. 변형 포인트: 각인 = "1회 행위 중 sub 점수 폭증 시 찍히는 비휘발 도장"으로 정의 → 흑화/각성 트리거로 직결.

### B. 양극 축 트레잇 (우마) → personality sub 구조 — 권장 ★★ (검토 필요)

### C. 진행 사다리 트레잇 (토호 함락/음란) → 유닛 변성 사다리 + 각성 — 권장 ★★★

| 애착 | 연모 | 정서 귀속·초월 | 7-X |
| 예속 | 복종 | 완전 예속 | 7-X |

### D. 상속 인자 (우마) → 합체 계승 3경로 강화 — 권장 ★★★

#### D 설계 (2026-05-31 전개) — 유기적 기본 + 삼원질 단독 레버

> 전제: 상속 뼈대는 **이미 존재**(합체 계승 3경로 중 잠재력 계승 = 우마식 인자). D = 깊이 + 印·색 변형.

**채택**: 인자 = **印·색 본질 상속**. 트레잇 *형태*가 아니라 그것이 띤 印·색 씨앗이 넘어가 자식 세대에서 재발현 → **"본질 색 침투"의 세대판**. 잠재력 계승에 얹힘.

**상속 방식 = A(유기적) 기본**: 합체 시 넘어가는 인자 = *부모 둘의 印·색 + 3경로 판정*이 결정. 플레이어 선택 = "어떤 둘을 합치나"까지. 무엇이 넘어갈지는 결과로 드러남.

**방향 지정 = 삼원질(三原質) 단독 레버** (자유 방향지정 B 폐기 — *삼원질을 일부러 넣은 이유가 희석되므로*). 3경로 1:1 매핑:
- **염(體)** → 직접 계승 슬롯
- **수은(神)** → 합성 발동 완화
- **유황(魂)** → 잠재력 2배 = 印·색 씨앗을 더 멀리/강하게 (**인자 상속 핵심 레버**)
→ 삼원질 = 상속을 굽히는 **유일·희소·의도적 수단**. 정체성 보존 + 희소성이 곧 **파밍 차단선**.

**톤 정합**: 인자 상속 = 상실이 아니라 **연속성(이어짐)의 구현**(레티어스). 印·색이 세대로 누적돼 흐름 → 합체 톤(담백·발견)과 정합.

**미확정**: 印·색 씨앗 재발현 규칙(시점·확률·어느 칸) / 세대 누적 상한 / 잠재력 계승 ↔ 변용 루트(C) 상호작용(부모 변용 루트가 자식 印·색 편향?).

## 7. 수치(능력치) 이름 변형 — 진행 (2026-05-31)

> 정본 용어 점유: `텍스트기반의 게임만들기/연금술_용어은행.md`

### 확정
- **조교 글로벌5** (연모·복종·음란·공포·반감): **직접 표기 유지**. 선례 + 문법에 가까움.

### 발견 / 정리

### 결정 (2026-05-31, 레티어스) — 기력/체력 합침

## 8. 역가(力價) 층 = Abl(레벨업 숙련) — 전투·조교 공통 척추 (제안, 2026-05-31)

> 레티어스: Abl층 필수. 트레잇이 전투·조교 양쪽에 깊이 → 둘을 동시에 설계.

**정체**: 역가 = **행위 반복으로 레벨업되는 숙련 수치**. 트레잇(魂, 질적 ON/OFF)·경험치(固, HP)와 **별개의 제3 산출**. 앞서 "능력치 우산말"로 검토하던 역가를 이 층의 이름으로 통합.

**한 행위 → 三 산출** (에라 정석: Exp+소질발현+Abl 동시):
| 산출 | 결 | 용도 |
|---|---|---|
| 경험치 | 固 | HP |
| 휘기(揮氣) | 揮 | 트레잇 후보 (소비) |
| **역가(力價)** | 力 | **그 행위의 숙련** (레벨업) |
→ 셋 분담 명확, 겹침 없음.

**공방=장비 결정 보존**: 역가는 base 공/방/속도(=장비)를 **안 건드림**. **행동별 숙련 보정(배율/가산)**으로만 작동 → 깊이 추가 + 기존 골격 유지.

**두 얼굴 (병렬 구조)**:
- **전투 얼굴**: **속성별7(물리+6원소) 공격·방어 숙련** → 해당 행동 배율·명중·회피 보정. (base 공/방/속도=장비, 방어 프로필=7슬롯)
- **조교 얼굴** (우마 床技 차용): **받는 쪽만 유닛 역가 = 숙련(熟)·내성(耐)**(부위6). **기술(技, 주는)=도구**(조교 공방 제작·패시브) — AL은 조교자 누적 능력치 폐기. [정정 2026-05-31]

**역할 분담 (이층 구조)**: 트레잇(魂)=*어떤 행동이 열리나* / 역가(力)=*그 행동을 얼마나 잘하나*.

### 8-1. 교차 영향 — 첫 구상 핵심 (레티어스, 2026-05-31) ★

**"동시 설계"의 진짜 의미 = 두 영역의 교차 영향(선순환).** 조교/훈련으로 얻은 트레잇이 전투에 영향, 전투로 얻은 트레잇이 조교에 영향.

**비대칭 원칙**:
- **트레잇(魂, 질적) = 영역 교차.** 획득 출처(조교/전투)에 효과가 갇히지 않음. 성격·체질·각성 등 정체성은 어디서든 발현.
- **역가(力, 양적) = 영역 고정.** 전투 역가는 싸워서, 조교 역가는 조교해서만 오름. (칼 숙련 ≠ 조교 숙련)

**선순환 루프**: 조교 트레잇 → 전투 보정 → 전투 잘됨 → 전투 트레잇 → 조교 보정 → … (빌드 다양성 + 양쪽 다 할 동기)

예: 조교 「고통변환」→전투 피격 버서크 / 전투 「위기감지」→조교 역추 간파.

**구현 결**: 트레잇 카테고리(전투/성격/성인/신체)의 역할 = ① **습득의 결**(어디서 얻었나) ② **UI 가독성**(보기 편한 묶음) ③ **카테고리별 슬롯 상한**(총 트레잇 수 억제, 기능 핵심 — system_trait_synthesis.md 영역별 상한과 정합). **효과 영역은 가두지 않음**(교차 영향).
- 한 트레잇이 전투+조교 효과 필드 동시 보유 가능 → 둘 다 가진 게 **"다리(bridge) 트레잇"**.
- **1슬롯 2영역**: 다리 트레잇은 *획득 카테고리 슬롯 1칸*만 먹으면서 두 영역에 효과 → 효율 높음 = 빌드 핵심·귀한 자리. 그래서 **일부만 지정**이 밸런스적으로도 정합(전부 교차 시 출력 폭발).
- 기존 합성 카테고리 교차와 결 일치(교차 합성 + 교차 영향).

**미확정**: 역가 레벨 상한·곡선 / 휘기↔역가 분담 경계 재확인 / 침염(각인)과 역가의 관계 / C 변성 사다리와의 연동 / 조교 床技 3층의 부위6·글로벌5와 정합.
