## 1. 층 모델 — 한 행위 → 三 산출

| 층 | 결 | 휘발 | 역할 |
|---|---|---|---|
| 경험치 | 固 | 영구 | HP |
| 휘기(揮氣) | 揮 | 소비 | 트레잇 후보 진입(시간 누적) → **공작 꼬리**(후보 풀) |
| 트레잇 | 魂 | 영구 | 질적 정체성·**영역 교차** |
| 역가(力價) | 力 | 영구 | 행위 숙련·**영역 고정** (0~5) |
| 침염(浸染) | 固 | 영구 | 절정 스파이크 도장 → 변용 엔진 |
| 지식(知) | — | 영구 | 직업 지식 레벨(0~5)·가공/경영/탐사/시설 게이팅 |

**한 행위 → ① 경험치(固) ② 휘기(揮) ③ 역가(力)** 동시 누적.

## 2. 유닛 런타임 상태 (세이브 대상)

- **경험치**(→HP) · **휘기**(sub카테고리별) · **침염**(종류별 카운트) · **변용도**(루트별 0~4)
- **역가**: 조교=숙련/내성(부위6 각 0~5) · 전투=공격/방어숙련(속성7 각 0~5)
- **지식**: 종류별 0~5 (연금·조합·경영·魔物·역사·요리·예술·수영·낚시·농업)
- **상태**: 감도(부위6 0~100) · 글로벌5(연모·복종·음란·공포·반감 0~100) · 호감도(0~100,6단계) · 敵対心
- **장비 파생**: 공/방/속도, defense 7슬롯(물리·열·위·광·동·식·자)
- 보유 트레잇 id 목록 + 부위 조교완료 플래그

## 3. 카테고리 + 티어

- **4 카테고리**: 전투(CT)·성격(PT)·성인(AT)·신체(BT). 역할 = 습득결·UI·**카테고리별 슬롯 상한**(효과 영역은 안 가둠=교차).
- **티어**: T1 초기단일 / T2 육성단일 → **직접**(초기/후보풀) · T3 2베이스 합성 / T4 名器·변용깊은칸 / T5 특수인·변용종착 → **합성/시그니처**.
- 복합=합성 출력(직접 풀에서 제외).

---

## 4. 조교 엔진

1. 행위 = [조교자(플레이어)가 **도구(기법 T)**를 대상 **부위 P**에]. 기술(주는)=도구(공방 제작).
2. **쾌감 = 도구출력(20~40) × (감도P/100) × (1 + 숙련Lv_P × 0.1)**
3. 누적 ≥ **절정 임계(100 + 내성Lv_P × 20)** → 절정.
4. 절정/행위 결·트레잇 → 글로벌5 변동(절정 시 지배 +15·보조 +5).
5. 한 세션 글로벌5(또는 고통) **ΔS≥15 스파이크** → 그 종류 **침염 +1**(절정이 가속).
6. 三 산출 + 부위 경험 → 숙련/내성 레벨업. 부위 감도+숙련 최고 → **부위 시그니처(名器)** + 침염 트리거.

## 5. 변용 (4루트)

- **침염 종류 → 루트**: 연모→애착 / 복종→예속 / 음란→탐닉 / 공포+반감(합산)→붕괴.
- **도 상승 = 침염 임계(2/5/9/14) + 루트 보조(coReq)**:
  - 애착 +호감도단계 / 예속 +역가숙련 / 탐닉 +감도 / 붕괴 보조없음.
- 단방향·**수렴 잠금 도2**(타루트 잠금)·길항(섞이면 둔화).
- 칸=시그니처 트레잇(가지당 4). 종착(도4)=유닛 엔딩 **7-X**. (각성 9-C는 변용과 별개 라인=인 활성+호감도 사이클, 유닛별 authored. 루트에 안 묶음.)
- 데이터: variationRoutes.csv(16칸 ID·effects·다리·침염임계·coReq).

## 6. 전투 (자동전투)

- base **공/방/속도 = 장비**, 7슬롯 방어=장비. 비율식 데미지 ATK×(ATK/(ATK+DEF))×배율(스킬 ×0.8~1.5).
- **역가 속성7 공격/방어숙련** = 레벨당 +5% 배율·명중(최대 +25%). 장비 base 안 건드림(보정만).
- **AI 흐름**: ①조건부 오버라이드(트레잇+조건→행동 강제, 우선순위 변용종착>합성성격>성격) ②행동 유형 가중 추첨(성격base+다리+파티미세) ③AP 맞는 스킬(역가 우선) ④AP 소진 반복.
- **타겟 = 가중 추첨**: 피격가중 = **敵対心(base) × 성격보정**(잔혹→저HP/약점 ×2·신중→고위협 ×1.5·충의→주인노린적 ×2·호기심 ×1). 강제 도발=거대배율/override.
- **다리 5기제**: 오버라이드/가중치/수치/타겟/특수. 스택=수치 누적·가중 합산·오버라이드 우선순위·특수 독립. (변용 다리는 단일 루트라 충돌 적음.)
- 환경 엔진 폐기 → 파티 조합이 성격 AI 가중치 미세 보정만.

## 7. 합성 / 모순쌍

- **합성**: 보유 트레잇 조합 → 결과 트레잇(레시피). 5Tier, 카테고리 교차 허용.
- **모순쌍**(AT/PT/BT, CT 제외): 대립 2 트레잇 **공존 → 합성 발동**. 결과 통합형(음양합일)/분열형(붕괴 트리거), 레시피·조건이 가름. 공존 획득=합체·변용·이벤트.
- **상속(합체)**: 3경로(합성발동/직접계승/잠재력계승). 인자=印·색 본질 상속. 방향 지정=삼원질(염=직접/수은=합성/유황=잠재) 단독 레버.

## 11. 오써링 규칙 (2026-07-17 확정 — 트레잇 확장 시 항상 적용)

트레잇 수는 계속 늘어난다. 늘릴 때마다 지키는 다섯 가지:

1. **레지스트리 단일화** — 모든 트레잇은 `balance/traits.csv`가 유일 정본. 타 CSV(variationRoutes·contradictionPairs·partSignatures·traitSynthesis)는 id/이름 **참조만**, effects/bridges를 들지 않는다.
2. **피라미드 (끝→뿌리)** — 끝(변용 종착·名器·엔딩급)=소수 authored 확정 / 뿌리(T1~T2 베이스)=넓게 / 중간=**명시적 레시피로만** 연결. 자유 창발(비명시 조합) 없음 — 질적 트레잇은 창발해도 이름·결을 사람이 써야 하므로 authored를 피할 수 없다.
3. **고아 트레잇 금지 (2026-07-17 강화)** — **모든 T1/T2는 최소 T3+ 사다리에 참여해야 한다**(단독 완결 클래스 폐지 — 스킬·효과 보유도 재료 겸업, 합성 비소비라 본업 무손실). 예외: **변용 칸(acquire=변용)=상태 사다리 소속 면제**. 답이 없으면 수집벽 — 넣지 않는다.
4. **확정성** — 도달 가능한 모든 노드는 CSV 행이 존재한다. 새 규칙·조건은 기존 DSL(effects/bridges/condition) 어휘 확장으로 표현 — 새 문법·새 시스템 발명 금지 (모순쌍 splitWhen 방식이 선례).
5. **수치 잠정 허용** — 틀·몰드 먼저, 수치는 통합 밸런싱 패스에서 일괄. 단 잠정임을 표기(주석·문서)한다.
   - **기능성 배치 기울기(2026-07-17)**: 1층(T1/T2)=수치 위주+가벼운 해금(**기존 훅 어휘 내에서만** — unlock: 부위특수·하드반응·음란계·이벤트.*·지식.*·통행/special: 전투 리졸버 어휘) / 중간층=행위·행동 변화 / 열매=정체성 변혁. **새 훅이 필요한 기능은 T3+에서 시스템 배선과 함께** — 미배선 unlock 남발 금지(수치는 공짜, 기능은 훅 하나당 코드 소비처 필요). 미배선 훅 신설 시 주석 표기(명령계·약물반응·월말생산·수계통행 = 2026-07-17 신설 표기분).
8. **T4 영역 교차 의무** (2026-07-17, 레티어스 — 트리거 해피 초안이 원형) — **T4 열매 = 주 영역 효과 + 타 영역 파급 최소 1**(획득 카테고리·sub 결에서 유도, 파급은 주보다 약하게 ±10~20%·트레이드도 허용). T3 이하=단일 영역 허용. "조교로 빚은 기질이 전투를 먹여살린다"의 열매 층 실현.

7. **베이스 불가침** (2026-07-17, 레티어스) — **공격력·방어력·속도·HP의 base는 장비(+성장) 전속. 트레잇·역가는 배율(mult) 보정만** — `stat|ATK|add` 등 플랫 가산 금지(엔진도 add를 플랫으로 소비하므로 의미·원칙 이중 위반). add 허용 풀 = 분수 스탯(회피·敵対心·defense.슬롯 경감률). scaleBy 조건 보정도 분수 배율로 소비(엔진 반영 완료).

6. **체인 사다리 공식 v3 + 종착 규칙** (2026-07-17 최종, 레티어스) — **T2=T1+T1(또는 육성 직접, 병존) / T3=T2+T2 표준(T1 혼합 허용) / T4=T3+T2 표준·예외 T3+T3 허용(강대 열매 소수) / T5=합성 불가**. 종착: T3 이상 정당, **T2 산출은 허용하되 반드시 상위 소비처 필요**(막다른 골목 금지 — 감지기 상주). T1 산출 없음(티어다운 T1 26=선천 풀 확정).

> 선례: 레지스트리 단일화로 변용 16행 전투 브릿지 미작동 버그 발견·해소 (2026-07-17). 규칙이 버그를 먼저 잡는다.
