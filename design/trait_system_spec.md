## 1. 층 모델 — 한 행위 → 三 산출

| 층 | 결 | 휘발 | 역할 |
|---|---|---|---|
| 경험치 | 固 | 영구 | HP |
| 휘기(揮氣) | 揮 | 소비 | 트레잇 후보 진입(시간 누적) → **공작 꼬리**(후보 풀) |
| 트레잇 | 魂 | 영구 | 질적 정체성·**영역 교차** |
| 역가(力價) | 力 | 영구 | 행위 숙련·**영역 고정** (0~5) |
| 침염(浸染) | 固 | 영구 | 절정 스파이크 도장 → 변용 엔진 |
| 지식(知) | — | 영구 | 직업 지식 레벨(0~5)·가공/경영/탐사/시설 게이팅 |

**한 행위 → ① 경험치(固) ② 휘기(揮) ③ 역가(力)** 동시 누적.

## 2. 유닛 런타임 상태 (세이브 대상)

- **경험치**(→HP) · **휘기**(sub카테고리별) · **침염**(종류별 카운트) · **변용도**(루트별 0~4)
- **역가**: 조교=숙련/내성(부위6 각 0~5) · 전투=공격/방어숙련(속성7 각 0~5)
- **지식**: 종류별 0~5 (연금·조합·경영·魔物·역사·요리·예술·수영·낚시·농업)
- **상태**: 감도(부위6 0~100) · 글로벌5(연모·복종·음란·공포·반감 0~100) · 호감도(0~100,6단계) · 敵対心
- **장비 파생**: 공/방/속도, defense 7슬롯(물리·열·위·광·동·식·자)
- 보유 트레잇 id 목록 + 부위 조교완료 플래그

## 3. 카테고리 + 티어

- **4 카테고리**: 전투(CT)·성격(PT)·성인(AT)·신체(BT). 역할 = 습득결·UI·**카테고리별 슬롯 상한**(효과 영역은 안 가둠=교차).
- **티어**: T1 초기단일 / T2 육성단일 → **직접**(초기/후보풀) · T3 2베이스 합성 / T4 名器·변용깊은칸 / T5 특수인·변용종착 → **합성/시그니처**.
- 복합=합성 출력(직접 풀에서 제외).

---

## 4. 조교 엔진

1. 행위 = [조교자(플레이어)가 **도구(기법 T)**를 대상 **부위 P**에]. 기술(주는)=도구(공방 제작).
2. **쾌감 = 도구출력(20~40) × (감도P/100) × (1 + 숙련Lv_P × 0.1)**
3. 누적 ≥ **절정 임계(100 + 내성Lv_P × 20)** → 절정.
4. 절정/행위 결·트레잇 → 글로벌5 변동(절정 시 지배 +15·보조 +5).
5. 한 세션 글로벌5(또는 고통) **ΔS≥15 스파이크** → 그 종류 **침염 +1**(절정이 가속).
6. 三 산출 + 부위 경험 → 숙련/내성 레벨업. 부위 감도+숙련 최고 → **부위 시그니처(名器)** + 침염 트리거.

## 5. 변용 (4루트)

- **침염 종류 → 루트**: 연모→애착 / 복종→예속 / 음란→탐닉 / 공포+반감(합산)→붕괴.
- **도 상승 = 침염 임계(2/5/9/14) + 루트 보조(coReq)**:
  - 애착 +호감도단계 / 예속 +역가숙련 / 탐닉 +감도 / 붕괴 보조없음.
- 단방향·**수렴 잠금 도2**(타루트 잠금)·길항(섞이면 둔화).
- 칸=시그니처 트레잇(가지당 4). 종착(도4)=유닛 엔딩 **7-X**. 애착 종착=9-C 각성 feeder.
- 데이터: variationRoutes.csv(16칸 ID·effects·다리·침염임계·coReq).

## 6. 전투 (자동전투)

- base **공/방/속도 = 장비**, 7슬롯 방어=장비. 비율식 데미지 ATK×(ATK/(ATK+DEF))×배율(스킬 ×0.8~1.5).
- **역가 속성7 공격/방어숙련** = 레벨당 +5% 배율·명중(최대 +25%). 장비 base 안 건드림(보정만).
- **AI 흐름**: ①조건부 오버라이드(트레잇+조건→행동 강제, 우선순위 변용종착>합성성격>성격) ②행동 유형 가중 추첨(성격base+다리+파티미세) ③AP 맞는 스킬(역가 우선) ④AP 소진 반복.
- **타겟 = 가중 추첨**: 피격가중 = **敵対心(base) × 성격보정**(잔혹→저HP/약점 ×2·신중→고위협 ×1.5·충의→주인노린적 ×2·호기심 ×1). 강제 도발=거대배율/override.
- **다리 5기제**: 오버라이드/가중치/수치/타겟/특수. 스택=수치 누적·가중 합산·오버라이드 우선순위·특수 독립. (변용 다리는 단일 루트라 충돌 적음.)
- 환경 엔진 폐기 → 파티 조합이 성격 AI 가중치 미세 보정만.

## 7. 합성 / 모순쌍

- **합성**: 보유 트레잇 조합 → 결과 트레잇(레시피). 5Tier, 카테고리 교차 허용.
- **모순쌍**(AT/PT/BT, CT 제외): 대립 2 트레잇 **공존 → 합성 발동**. 결과 통합형(음양합일)/분열형(붕괴 트리거), 레시피·조건이 가름. 공존 획득=합체·변용·이벤트.
- **상속(합체)**: 3경로(합성발동/직접계승/잠재력계승). 인자=印·색 본질 상속. 방향 지정=삼원질(염=직접/수은=합성/유황=잠재) 단독 레버.
