# UI/인터페이스 설계 (v0.1)

> 상위 문서: game_blueprint.md
> 참조: system_economy.md (시간 구조), system_exploration.md (탐사), system_unit.md (유닛)
> 기반: 알파 빌드 현재 상태 (Electron + React)

---

## 설계 원칙

> **"ERA의 조작감을 Electron에서 재현한다."**

- **검은 배경 + 컬러 텍스트**: ERA 스타일의 텍스트 UI. 최소한의 그래픽
- **번호 선택 기본**: 메뉴 항목에 번호 부여, 클릭 또는 숫자 키 입력으로 선택
- **클릭 최소화**: 한 행동에 도달하기까지 클릭 수를 최대한 줄임
- **커맨드 보조**: 간단한 영어 단어/숫자로도 조작 가능 (키보드 유저 배려)
- **정보 밀도 조절**: 한 화면에 필요한 정보를 다 보여주되 과밀하지 않게

## 화면 구조

### 공통 레이아웃

```
┌─────────────────────────────────────┐
│ [헤더] 현재 위치 / 날짜 / 상태 수치  │
├─────────────────────────────────────┤
│                                     │
│ [본문 영역]                          │
│  환경 묘사 / 로그 / 정보 표시         │
│                                     │
├─────────────────────────────────────┤
│ [입력 영역]                          │
│  번호 메뉴 / 행동 선택지              │
│  (클릭 또는 숫자 키 입력)             │
└─────────────────────────────────────┘
```

- 전체 단일 컬럼 (좌우 분할 없음)
- 스크롤은 본문 영역에서 발생
- 입력 영역은 항상 하단에 고정

### 헤더 정보

```
【 현재 위치 】
N년 M월 D일  |  [메인 행동: 미사용 / 탐사 완료 / 교류 완료]
영혼력: 수치
```

- 위치명: 미궁 도시, 공방, 미궁 N층 등
- 날짜: 년/월/일 표시
- 메인 행동 상태: 오늘 메인 행동 사용 여부 표시
- 영혼력: 항상 헤더에 노출
- ~~스태미나~~: 폐기 (v0.7 행동 구조 개편, system_economy.md 참조)

## 화면별 구성

### 1. 메인 화면 (미궁 도시)

플레이어의 거점. 하루의 행동을 선택하는 허브.

```
【 미궁 도시 】

1년 1월 1일  |  [메인 행동: 미사용]
영혼력: 9194

도시의 중심 광장. 탐사자들이 분주히 오가고 있다.

  1. 탐사 준비    — 미궁에 진입한다
  2. 가공/연구    — 공방에서 가공·조합한다
  3. 유닛 관리    — 유닛을 확인/육성한다
  4. 조교소       — 유닛을 조교한다
  5. 도시 시설    — 시설을 관리한다
  6. 전서         — 유닛을 구매/등록한다
  7. 인벤토리     — 소지품을 확인한다
  t. 도구 관리    — 도구를 확인/업그레이드한다
  8. 하루 넘기기
  9. 저장
```

#### 메뉴 항목 분류

| 번호 | 메뉴 | 행동 유형 | 스태미나 소모 |
|------|------|----------|------------|
| 1 | 탐사 준비 | 메인 행동 | 하루 전체 |
| 2 | 가공/연구 | 자유 행동 | 없음 |
| 3 | 유닛 관리 | 자유 행동 | 없음 |
| 4 | 조교소 | 메인 행동 | 하루 전체 |
| 5 | 도시 시설 | 자유 행동 | 없음 |
| 6 | 전서 | 자유 행동 | 없음 |
| 7 | 인벤토리 | 자유 행동 | 없음 |
| t | 도구 관리 | 자유 행동 | 없음 |
| 8 | 하루 넘기기 | 시스템 | — |
| 9 | 저장 | 시스템 | — |

> **미결정**: 메인/자유 행동 이원 구조 반영 시, 메인 행동(탐사/조교) 선택 후 그 날은 자유 행동만 가능하도록 메뉴 상태 변경 필요. 메인 행동 선택 전/후의 메뉴 표시 차이를 어떻게 보여줄지. (메인 행동 항목 회색 처리? 별도 표시?)

#### 환경 묘사

- 메뉴 위에 한 줄 환경 묘사 출력
- 시즌/날씨/마일스톤/이벤트 상태에 따라 변화
- 유닛 코멘트도 여기에 출력 가능

### 2. 조교 화면

ERA식 조교 인터페이스. 수치 + 행위 선택. **한 화면 완결** 원칙.

#### 레이아웃 (v0.2 개편)

```
┌──────────────────────────────────────────┬──────────────────┐
│ 【 조교: 유닛명 】 Lv.N 인(印)            │  [사이드 패널]    │
│ 성인 특성: ○○○                            │  연금술사 상태    │
│                                          │  영혼력 / 날짜    │
│ [부위 감도 — 3열 압축]                     │                  │
│  입  0 [████····] 미개발  가슴 0 [████····] 미개발  V 0 [████····] 미개발 │  재료 현황     │
│  C   0 [████····] 미개발  애널 0 [████····] 미개발  피부0 [████····] 미개발 │                │
│                                          │  편성 파티       │
│ [상태 수치 — 3열 압축]                     │                  │
│  연모 0 [████····]  복종 0 [████····]  음란 0 [████····]      │                  │
│  공포 0 [████····]  반감 0 [████····]                        │                  │
│                                          │                  │
│ [경험치 — 접기/펼치기]                     │                  │
│  ▶ 경험치 (클릭하여 펼치기)                │                  │
│                                          │                  │
│ ─────────────────────────────             │                  │
│ [행위 선택 — 번호 입력]                    │                  │
│  1.머리쓰다듬기  2.포옹  3.손잡기          │                  │
│  4.가슴 애무     5.엉덩이 애무  6.전신 애무 │                  │
│  7.키스[X]       8.가슴 주무르기[X]  ...   │                  │
└──────────────────────────────────────────┴──────────────────┘
```

#### 압축 원칙

- **부위 감도**: 6부위를 **3열 × 2행** 배치. 바 그래프 폭을 줄여서 한 줄에 3부위. 부위 추가 시 3열 유지하며 행 추가
- **상태 수치**: 5종을 **3열 배치**. 연모/복종/음란 한 줄, 공포/반감 한 줄. 추가 시 3열 유지
- **경험치**: 기본 **접힌 상태**. 클릭/키 입력으로 펼치기. 조교 중 실시간으로 볼 필요가 적은 정보이므로 기본 숨김
- **행위 목록**: 본문에 번호 목록만 표시. ~~하단 버튼 중복 제거~~ — 본문 번호 클릭 또는 키 입력으로 통일. 하단 고정 영역은 시스템 버튼(돌아가기/인벤토리/유닛)만
- **사이드 패널**: 기존 오른쪽 패널 유지 (연금술사 상태/재료/파티). 조교 화면에서도 항상 표시

#### 확장 대응

- 행위 목록은 향후 추가될 항목을 고려하여 스크롤 가능 영역으로 설정
- 부위/상태 수치 추가 시 3열 구조 유지, 행만 늘어남
- 잠금 행위는 목록 하단에 배치 (해금된 것 먼저, 잠금 나중에)

#### 행위 잠금 표시

- `[X]` = 잠금 상태. 해금 조건 미충족 (호감도/도구/트레잇)
- 잠금 해제 시 `[X]` 제거, 번호 선택 가능
- 잠금 조건 표시 방식 (미결정: 호버? 별도 정보 화면?)

### 3. 탐사 화면 (던전 내)

```
[헤더]
  미궁 N층 — 구역명
  파티 상태 표시 (HP 바 등)

[본문]
  노드 묘사 / 전투 로그 / 채집 결과 / 조우 이벤트 텍스트

[입력]
  이동: 인접 노드 선택
  전투 중: 소비재 사용 / 철수
  조우: 대화 / 전투 / 도주
```

> 탐사 화면 구체 레이아웃은 미확정. 현재 알파에서 구현 중.

### 4. 가공/조합 화면

```
[헤더]
  공방

[본문]
  보유 재료 목록 / 설비 상태
  조합 결과 미리보기 (태그 합산 결과)

[입력]
  재료 선택 → 설비 선택 → 실행
```

> 구체 레이아웃은 미확정.

## 색상 체계

| 용도 | 색상 | 비고 |
|------|------|------|
| 일반 텍스트 | 흰색/밝은 회색 | 기본 |
| 위치/제목 | 파란색 계열 | 【미궁 도시】등 |
| 날짜/수치 | 초록색 계열 | 날짜, 경험치 |
| 핵심 자원 | 시안/밝은 파랑 | 스태미나, 영혼력 |
| 잠금 표시 | 보라색 | [X] 행위 |
| 수치 바 | 보라색 | 감도/상태 바 |
| 구분선 | 짙은 회색 | 섹션 분리 |
| 배경 | 검정 | 전체 |

> 색상은 현재 알파 기준. 확정 아님.

## 입력 방식

### 기본: 번호 클릭/키 입력

- 메뉴 항목에 숫자 번호 부여
- 화면의 번호를 클릭하거나 키보드로 해당 숫자 입력
- 영어 단문자 커맨드 보조 (예: `t` = 도구 관리)

### 조작 원칙

- **1클릭 1행동**: 메뉴 선택 → 즉시 해당 화면 전환
- **뒤로가기**: 항상 존재. ESC 또는 별도 번호
- **확인 요구**: 되돌릴 수 없는 행동(납품, 합체, 하루 넘기기)만 확인 요청
- **스크롤 최소화**: 한 화면에 필요한 정보가 다 보이도록 구성
