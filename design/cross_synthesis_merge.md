# 교차 합성 겹침 병합

> 1라운드 Claude 60 + Gemini 60 중 겹치는 레시피 병합
> 현재 전투 시스템 기준: AP/ATK/DEF/속성내성/데미지배율/범위(single|area)/버프배열
> 없는 것: 위치, 체급, 넉백, 상태이상 시스템 (상태이상은 향후 구현 예정)

---

## 겹침 1: 찌르기 + 각(뿔)

| | Claude | Gemini |
|---|--------|--------|
| 이름 | 관통충각 | 관통뿔 |
| Tier | T4 | T3 |
| 효과 | 방어 무시 관통. 위(危) 이중 적용(2회 판정) | 물리 방어 관통, 방어 높을수록 추가 데미지 |

**병합 → 관통충각 (T3)**
- 위(危) 속성 공격. 대상 DEF의 50% 무시 + DEF 비례 추가 데미지 (def×0.3)
- 구현: calcDamage에서 defValue 절반 적용 + def 비율 보너스
- T3으로 내림 — T4는 이걸 재료로 쓰는 상위 합성에 배정

---

## 겹침 2: 돌진 + 대체형

| | Claude | Gemini |
|---|--------|--------|
| 이름 | 거신돌파 | 관통돌 |
| Tier | T3 | T3 |
| 효과 | 체급 비례 +50%, 밀치기+경직 | 대열 관통, 모든 적 충격 |

**병합 → 거신돌파 (T3)**
- 동(動) 속성 area 공격. 데미지 배율 1.5배. HP 비례 추가 보정 (maxHp×0.1을 ATK에 가산)
- "밀치기/경직" 삭제 → 대신 area 전환으로 돌진이 범위기로 변화
- 구현: target:'area', damageMultiplier:1.5, 특수 보정 로직(HP→ATK 임시가산)

---

## 겹침 3: 질풍 + 유익(날개)

| | Claude | Gemini |
|---|--------|--------|
| 이름 | 폭풍기동 | 질풍날개 |
| Tier | T3 | T4 |
| 효과 | 회피+40%, 동 공격력+20% | 속도 2배, 한 턴 2번 행동 |

**병합 → 폭풍기동 (T3)**
- 동(動) 속성. SPD 기반 AP 보정 +1. 동 속성 데미지 배율 1.2배
- "2번 행동" 대신 AP +1이 실질적 추가 행동 (현재 AP 시스템과 호환)
- 회피는 현재 시스템에 없으므로 삭제 → SPD 보정으로 대체

---

## 겹침 4: 질풍 + 쾌활 (Gemini만) vs 질풍 재료 중복

| | Claude | Gemini |
|---|--------|--------|
| 이름 | (질풍은 폭풍기동에 사용) | 유격병 |
| Tier | — | T3 |
| 효과 | — | 회피 시마다 공격 속도 5% 중첩 |

**판정: 겹침 아님 — 재료가 다름 (질풍+날개 vs 질풍+쾌활)**
- 유격병은 Gemini 독자 레시피로 유지
- 단, "회피 시마다" 효과는 현재 회피 시스템 없으므로 수정 필요
- **수정 → 유격병 (T3)**: 동(動) 속성. 라운드 경과마다 ATK +5% 누적 (최대 +25%). SPD 보정 +2
- 컨셉: 오래 살아남을수록 강해지는 속도전 빌드

## 겹침 5: 흡수 + 쾌감부정

| | Claude | Gemini |
|---|--------|--------|
| 이름 | 감각차폐 | 금욕적 섭취 |
| Tier | T4 | T3 |
| 효과 | 쾌감→HP 변환. 붕괴 시 영구변화 | 쾌감 소모→체력 회복 |

**병합 → 감각차폐 (T4) + 금욕적 섭취 (T3 재료용)**
- 금욕적 섭취를 T1~T2로 내려서 감각차폐의 하위 재료로 편입
- 금욕적 섭취 (T2): 쾌감 수치 일부를 HP 회복으로 전환. 단순 변환
- 감각차폐 (T4): 쾌감 누적 불가 + HP 변환. 붕괴 시 영구 체질 변화
- 2단계 합성 경로: 흡수 + 쾌감부정 → 금욕적 섭취(T2) → + 다른 재료 → 감각차폐(T4)

## 애매한 겹침 (같은 재료, 다른 방향 — 둘 다 유지)

### 냉기방사 + 점액체
- Claude: **동결점액** (CT, T3) — 접촉 적 SPD 디버프, 열 속성 추가 데미지
- Gemini: **부식 방벽** (BT, T3) — 적 물리 방어 녹임

→ **둘 다 유지.** 결과 카테고리도 다르고(CT vs BT) 방향이 다름.
단, 같은 재료 2개 합성인데 결과가 갈리는 건 "합성 분기" 시스템으로 처리 가능:
플레이어가 선택하거나, 합성 시점의 조건(시설 배치 여부 등)으로 분기.

### 업화 + 용해체질
- Claude: **열융해** (AT, T4) — 감도 3배, 가마 배치 효율 +30%
- Gemini: **마그마 코어** (CT, T4) — 전투 특화

→ **Claude(열융해)만 유지.** 시설 연동이 이 게임의 핵심 방향성에 부합.
마그마 코어의 "KO 시 아군 부활"은 부활 시스템 자체가 없으므로 삭제.
