## 개념

- **모순쌍** = 대립 관계의 트레잇 2개. 유닛은 보통 **한 극만** 보유. **공존 시 → 합성 발동**.
- **결과**: **통합형**(모순을 끌어안아 상위 트레잇 — 음양합일) / **분열형**(찢겨 불안정 → 변용 붕괴 트리거). 레시피·조건이 가름.
- **공존 획득**: 합체(상속 섞임)·변용(상태가 반대 발현)·이벤트·조교. 귀한 자리.
- **메타 정합**: 마그눔 모순→통합/와해, 메르쿠리우스 음양합일, 9-Ω 분리↔통합.

### 적용 범위 ★ (레티어스)
- **모순쌍 = 유닛 "존재"의 모순** → **AT(조교)·PT(성격)·BT(신체)** 적용.
- **CT(전투) 제외**: 전투는 "행위/스킬" 위주 → 모순쌍 거의 없음. (존재엔 모순, 행위엔 없음.)
- **관찰**: 통합형 결과가 *기존 트레잇*인 경우 많음(변태·변환자재 등) → 모순쌍 = 그 상위 트레잇의 **획득 경로**.

## 발동 규칙 v1 (2026-07-17 — 수치 잠정, 구현 완료)

**체크 시점**: 두 극 공존이 생기는 순간 (현행 구현 = 합체 executeFusion. 변용·이벤트 획득 훅은 추후).

**방향 판정 우선순위**:
1. 통합형 `-` 쌍 (근면↔게으름) → **항상 분열**.
2. 수은 주입 → **통합 강제** (삼원질 수은=합성 발동 레버, 기존 결정 계승).
3. `splitWhen`(쌍별 컬럼, condition DSL `stat:cmp:value`) 또는 기본 조건 **[붕괴 변용도 ≥1 OR 침염(공포+반감) ≥3]** 참 → **분열**.
4. 그 외 → **통합**.

> 결: 무너진 마음에 모순이 얹히면 찢어지고, 안정된 그릇은 모순을 끌어안는다.

**결과 적용**: 통합 = 두 극 소거 + 통합 트레잇 부여 / 분열 = 두 극 유지 + 분열 트레잇 부여 + **공포 침염 +1** (붕괴 feeder).

**결과 트레잇 = traits.csv 레지스트리 행** (이름으로 조회 — 레지스트리 단일화 규칙): 재활용 2 (변태=AT_DUAL_TASTE·변환자재=BT_SHAPESHIFT) + 신규 29 (subMain=모순, subSub=통합/분열, acquire=모순합성, T3, effects 잠정).

**구현**: `synthesisEngine.decideContradiction` + `unit.js executeFusion` 적용부. splitWhen 복합 조건(AND/OR)은 밸런싱 패스에서 필요 시 확장.
